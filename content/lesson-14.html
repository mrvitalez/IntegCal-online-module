11.6Absolute Convergence and the Ratio and Root Tests

In Module 13, the alternating harmonic series converged even though \(\sum 1/n\) does not. So, is there a difference between a series that converges "by luck of the signs" and one that converges no matter what the signs are? Yes. Given any series \(\sum a_n\), we can look at the series of absolute values \(\sum |a_n|\). We say \(\sum a_n\) is absolutely convergent if \(\sum |a_n|\) converges, and conditionally convergent if \(\sum a_n\) converges but \(\sum |a_n|\) does not. The alternating harmonic series is the standard conditionally convergent series: it converges (Alternating Series Test) but \(\sum 1/n\) diverges.

Theorem If a series is absolutely convergent, then it is convergent.

This is useful for series whose signs are irregular, like \(\sum \dfrac{\cos n}{n^2}\): since \(\left|\dfrac{\cos n}{n^2}\right| \le \dfrac1{n^2}\), the series of absolute values converges by comparison, so the original converges too. Absolute convergence is the "strong" kind: an absolutely convergent series can be rearranged without changing its sum, while a conditionally convergent one can be rearranged to add up to any number we like.

The Ratio Test Let \(L = \displaystyle\lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right|\).
If \(L < 1\), \(\sum a_n\) is absolutely convergent. If \(L > 1\) (or \(L = \infty\)), it diverges. If \(L = 1\), the test is inconclusive.

What is the idea? If the ratio of consecutive terms settles at \(L < 1\), the series eventually behaves like a geometric series with ratio about \(L\). Take note: the ratio test is the tool of choice whenever we see factorials or exponentials like \(5^n\), because those simplify beautifully in \(a_{n+1}/a_n\). For example, with \(a_n = n^2/2^n\), the ratio is \(\left(\frac{n+1}{n}\right)^2 \cdot \frac12 \to \frac12\) (Figure 14.1), so \(\sum n^2/2^n\) converges absolutely.

The Root Test Let \(L = \displaystyle\lim_{n\to\infty}\sqrt[n]{|a_n|}\). The conclusions are the same as for the ratio test: \(L < 1\) absolutely convergent, \(L > 1\) divergent, \(L = 1\) no conclusion.

The root test is natural when \(a_n\) is an \(n\)th power, e.g. \(\sum \left(\dfrac{2n+1}{3n-1}\right)^n\): here \(\sqrt[n]{a_n} = \dfrac{2n+1}{3n-1} \to \dfrac23 < 1\), so it converges.

Common mistake \(L = 1\) does not mean "converges" or "diverges". For every p-series the ratio limit is 1, yet \(\sum 1/n\) diverges and \(\sum 1/n^2\) converges. If we get \(L = 1\), we switch to a comparison, integral or alternating series test.
Key equations
\[ L=\lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right| \quad\text{or}\quad L=\lim_{n\to\infty}\sqrt[n]{|a_n|} \]
\[ L\lt 1:\ \text{absolutely convergent};\quad L\gt 1:\ \text{divergent};\quad L=1:\ \text{inconclusive} \]

11.7Strategy for Testing Series

We now have many tests. And honestly, the hard part on an exam is not carrying one out; it is choosing which one to use. So, how do we choose? We group series by their form. Before we compute anything, we look at the general term and ask ourselves the questions below, roughly in this order.

  1. Do the terms go to 0? If \(\lim a_n \ne 0\) is obvious, stop: the series diverges by the Test for Divergence. Example: \(\sum \dfrac{n^2}{3n^2+1}\).
  2. Is it a p-series or a geometric series? \(\sum 1/n^p\) converges iff \(p > 1\); \(\sum ar^{n-1}\) converges iff \(|r| < 1\). Constants in front do not matter.
  3. Is it "almost" one of those? If \(a_n\) is a rational or algebraic expression in \(n\) (powers and roots only), compare with a p-series, usually by the Limit Comparison Test after keeping dominant terms. Example: \(\sum \dfrac{\sqrt n}{n^2+4}\) behaves like \(1/n^{3/2}\).
  4. Is it alternating? Try the Alternating Series Test, and also check \(\sum |a_n|\) to decide between absolute and conditional convergence.
  5. Factorials or \(c^n\)? Use the Ratio Test. (Do not use it on plain rational functions; we will get \(L = 1\).)
  6. An \(n\)th power such as \((b_n)^n\)? Use the Root Test.
  7. Is \(a_n = f(n)\) with \(\int_1^\infty f(x)\,dx\) easy? Use the Integral Test (check that \(f\) is positive and decreasing). Typical cases: \(\dfrac{1}{n\ln n}\), \(n e^{-n^2}\).

Logarithms grow more slowly than any power, so terms like \(\dfrac{\ln n}{n^2}\) can be handled by comparison: since \(\ln n \le \sqrt n\), we get \(\dfrac{\ln n}{n^2} \le \dfrac{1}{n^{3/2}}\) (Figure 14.2), and the series converges.

Note Several tests may work for the same series; any valid argument is acceptable. What matters is that we state which test we use, check its conditions, and write a clear conclusion.
Common mistake Students often write "\(a_n \to 0\), so the series converges." That is never a valid reason. Another frequent slip is using the Comparison Test with the inequality pointing the wrong way.
Key equations
\[ \sum \frac{1}{n^p}:\ p\gt 1 \qquad \sum ar^{n-1}:\ |r|\lt 1 \]
\[ \ln n \le \sqrt{n} \;\Longrightarrow\; \frac{\ln n}{n^2} \le \frac{1}{n^{3/2}} \]

11.8Power Series

So far, our series were made of numbers. What if we put a variable inside? A power series is a series with a variable in it:

\[ \sum_{n=0}^{\infty} c_n (x-a)^n = c_0 + c_1(x-a) + c_2(x-a)^2 + \cdots \]

The numbers \(c_n\) are the coefficients and \(a\) is the center. Think of it as a "polynomial with infinitely many terms". For each value of \(x\) we get an ordinary series of numbers, which may converge or diverge; where it converges, it defines a function of \(x\). (We use the convention \((x-a)^0 = 1\), even when \(x = a\).)

The simplest example is the geometric series \(\sum x^n = 1 + x + x^2 + \cdots\), which converges to \(\dfrac{1}{1-x}\) exactly when \(-1 < x < 1\).

Theorem For a power series \(\sum c_n(x-a)^n\) exactly one of these holds:
(i) it converges only at \(x = a\) (radius \(R = 0\));
(ii) it converges for all \(x\) (\(R = \infty\));
(iii) there is a number \(R > 0\), the radius of convergence, such that it converges absolutely if \(|x-a| < R\) and diverges if \(|x-a| > R\).

So, how do we find \(R\)? We apply the Ratio Test (or Root Test) to the absolute values, treating \(x\) as a constant. For \(\sum_{n=1}^\infty \dfrac{x^n}{n\,2^n}\):

\[ \left|\frac{a_{n+1}}{a_n}\right| = \frac{n}{n+1}\cdot\frac{|x|}{2} \;\to\; \frac{|x|}{2}, \]

which is less than 1 when \(|x| < 2\). So \(R = 2\).

The ratio test says nothing at the endpoints \(x = a \pm R\) (there \(L = 1\)), so we must test them separately with the earlier tests. At \(x = 2\) the series becomes \(\sum 1/n\), which diverges; at \(x = -2\) it is \(\sum (-1)^n/n\), which converges. The interval of convergence is therefore \([-2, 2)\). Figure 14.3 shows partial sums of this series hugging its sum, \(-\ln(1 - x/2)\), inside the interval and flying away outside it.

Common mistake Forgetting the endpoints, or assuming both behave the same. An interval of convergence can be open, closed, or half-open; each endpoint needs its own check.
Key equations
\[ \sum_{n=0}^{\infty} c_n (x-a)^n \]
\[ \lim_{n\to\infty}\left|\frac{c_{n+1}(x-a)^{n+1}}{c_n(x-a)^n}\right| \lt 1 \;\Longrightarrow\; |x-a|\lt R \]

11.9Representations of Functions as Power Series

In §11.8 a power series gave us a function. Now we go the other way: start with a function and write it as a power series. Why would we want to replace a simple formula by an infinite sum? Because polynomials are the easiest functions there are: we can evaluate them with only additions and multiplications, and we can differentiate and integrate them term by term without any tricks. A power series lets us treat many complicated functions as if they were polynomials. The master key is the geometric series

\[ \frac{1}{1-x} = \sum_{n=0}^{\infty} x^n, \qquad |x| < 1. \]

By substituting for \(x\) and multiplying by powers of \(x\), we can get series for many related functions. For example, replace \(x\) by \(-x^2\):

\[ \frac{1}{1+x^2} = \sum_{n=0}^{\infty} (-1)^n x^{2n} = 1 - x^2 + x^4 - \cdots, \qquad |x| < 1. \]

For \(\dfrac{1}{4 - x}\), factor first to get the form \(\dfrac{1}{1 - (\text{something})}\): \(\dfrac{1}{4-x} = \dfrac14\cdot\dfrac{1}{1 - x/4} = \sum_{n=0}^\infty \dfrac{x^n}{4^{n+1}}\), valid when \(|x/4| < 1\), i.e. \(R = 4\). The general rule: after a substitution, the new series converges exactly when the expression we substituted has absolute value less than 1, so we can read off the radius without a separate ratio test. Multiplying by \(x^3\) shifts every power: \(\dfrac{x^3}{4-x} = \sum \dfrac{x^{n+3}}{4^{n+1}}\), same radius.

Term-by-term calculus If \(f(x) = \sum c_n (x-a)^n\) has radius \(R > 0\), then on \((a-R, a+R)\)
\(f'(x) = \sum n c_n (x-a)^{n-1}\) and \(\int f(x)\,dx = C + \sum \dfrac{c_n}{n+1}(x-a)^{n+1}\),
and both new series have the same radius \(R\).

This opens up many more functions. Differentiating the geometric series gives \(\dfrac{1}{(1-x)^2} = \sum_{n=1}^\infty n x^{n-1}\). Integrating \(\dfrac{1}{1+x}\) gives

\[ \ln(1+x) = x - \frac{x^2}{2} + \frac{x^3}{3} - \cdots = \sum_{n=1}^\infty (-1)^{n-1}\frac{x^n}{n}, \]

and integrating \(\dfrac{1}{1+x^2}\) gives \(\tan^{-1} x = x - \dfrac{x^3}{3} + \dfrac{x^5}{5} - \cdots\) (Figure 14.4). In each case find the constant \(C\) by putting \(x = 0\): here \(\ln 1 = 0\) and \(\tan^{-1} 0 = 0\), so \(C = 0\).

Common mistake The radius stays the same under differentiation and integration, but the behavior at the endpoints can change. The geometric series diverges at \(x = 1\), yet the series for \(\ln(1+x)\) converges there (to \(\ln 2\)).

Power series also let us integrate functions with no elementary antiderivative, such as \(\int \dfrac{dx}{1+x^7}\), term by term.

Key equations
\[ \frac{1}{1-x}=\sum_{n=0}^{\infty}x^n,\quad |x|\lt 1 \]
\[ f'(x)=\sum_{n=1}^{\infty} n c_n (x-a)^{n-1},\qquad \int f(x)\,dx = C+\sum_{n=0}^{\infty}\frac{c_n (x-a)^{n+1}}{n+1} \]
\[ \ln(1+x)=\sum_{n=1}^{\infty}(-1)^{n-1}\frac{x^n}{n},\qquad \tan^{-1}x=\sum_{n=0}^{\infty}(-1)^n\frac{x^{2n+1}}{2n+1} \]

11.10Taylor and Maclaurin Series

Now, here is the big question: which power series, if any, represents a given function \(f\)? Let's find out. Suppose \(f(x) = \sum c_n (x-a)^n\). Putting \(x = a\) gives \(c_0 = f(a)\); differentiating and putting \(x = a\) again gives \(c_1 = f'(a)\), then \(2c_2 = f''(a)\), and in general \(c_n = f^{(n)}(a)/n!\). So the series is forced to be the Taylor series of \(f\) at \(a\):

\[ f(x) = \sum_{n=0}^{\infty} \frac{f^{(n)}(a)}{n!}(x-a)^n. \]

When \(a = 0\) it is called a Maclaurin series. The partial sum of degree \(n\), \(T_n(x)\), is the \(n\)th-degree Taylor polynomial, and \(R_n(x) = f(x) - T_n(x)\) is the remainder. The series equals \(f(x)\) exactly when \(R_n(x) \to 0\). The tool for proving this is

Taylor's Inequality If \(|f^{(n+1)}(x)| \le M\) for \(|x-a| \le d\), then \(|R_n(x)| \le \dfrac{M}{(n+1)!}|x-a|^{n+1}\) for \(|x-a| \le d\).

For \(f(x) = e^x\) every derivative is \(e^x\), so \(c_n = 1/n!\). Taylor's inequality, together with \(\lim \dfrac{x^n}{n!} = 0\) for every \(x\), shows that \(e^x\) equals its Maclaurin series for all \(x\). Here are the series we should know by heart:

FunctionMaclaurin seriesRadius
\(\dfrac{1}{1-x}\)\(1 + x + x^2 + x^3 + \cdots\)1
\(e^x\)\(1 + x + \dfrac{x^2}{2!} + \dfrac{x^3}{3!} + \cdots\)\(\infty\)
\(\sin x\)\(x - \dfrac{x^3}{3!} + \dfrac{x^5}{5!} - \cdots\)\(\infty\)
\(\cos x\)\(1 - \dfrac{x^2}{2!} + \dfrac{x^4}{4!} - \cdots\)\(\infty\)
\(\tan^{-1} x\)\(x - \dfrac{x^3}{3} + \dfrac{x^5}{5} - \cdots\)1
\(\ln(1+x)\)\(x - \dfrac{x^2}{2} + \dfrac{x^3}{3} - \cdots\)1
\((1+x)^k\)\(1 + kx + \dfrac{k(k-1)}{2!}x^2 + \cdots\)1

The last row is the binomial series \(\sum \binom{k}{n} x^n\), where \(\binom{k}{n} = \dfrac{k(k-1)\cdots(k-n+1)}{n!}\). It works for any real \(k\); for example \(\sqrt{1+x} = 1 + \tfrac12 x - \tfrac18 x^2 + \tfrac1{16}x^3 - \cdots\).

Two remarks on using the table. First, every entry comes from the coefficient formula (or from §11.9), so if we forget one we can always rebuild it by computing a few derivatives at 0 and looking for the pattern. Second, the radius column matters: the series for \(\sin x\), \(\cos x\) and \(e^x\) work for every real number, while the others are only valid for \(|x| < 1\) (plus possibly an endpoint).

From the table we can build new series by substitution and multiplication instead of computing derivatives: \(e^{-x^2} = \sum \dfrac{(-1)^n x^{2n}}{n!}\), and \(x\sin x = x^2 - \dfrac{x^4}{3!} + \cdots\). Figure 14.5 shows Taylor polynomials of \(\sin x\) wrapping around the curve over wider and wider intervals.

Common mistake Forgetting the factorials: the coefficient is \(f^{(n)}(a)/n!\), not \(f^{(n)}(a)\).
Key equations
\[ f(x)=\sum_{n=0}^{\infty}\frac{f^{(n)}(a)}{n!}(x-a)^n \]
\[ |R_n(x)|\le\frac{M}{(n+1)!}|x-a|^{n+1} \]
\[ (1+x)^k=\sum_{n=0}^{\infty}\binom{k}{n}x^n,\quad |x|\lt 1 \]

11.11Applications of Taylor Polynomials

In practice we rarely need the whole Taylor series; we use a Taylor polynomial \(T_n(x)\) as a cheap, accurate stand-in for \(f(x)\) near \(a\). Calculators, physics formulas and numerical methods all rely on this. The key questions are: how good is the approximation? and how large must \(n\) be? We have three ways to answer.

  1. Taylor's Inequality: bound \(|f^{(n+1)}|\) by some \(M\) on the interval and use \(|R_n(x)| \le \dfrac{M}{(n+1)!}|x-a|^{n+1}\).
  2. Alternating Series Estimation: if the series at the given \(x\) is alternating with decreasing terms, the error is at most the first omitted term.
  3. Graphing \(|R_n(x)|\) on the interval and reading off its maximum.

Example. Approximate \(e^{0.2}\) by \(T_3(x) = 1 + x + \dfrac{x^2}{2} + \dfrac{x^3}{6}\): \(T_3(0.2) \approx 1.221333\). On \([0, 0.2]\), \(f^{(4)}(x) = e^x \le e^{0.2} < 1.25\), so

\[ |R_3(0.2)| \le \frac{1.25}{4!}(0.2)^4 \approx 0.000083. \]

The true value is \(1.221403\), so the actual error, \(0.000069\), is indeed below the bound.

A physics application: relativistic kinetic energy. This one is for us in astronomy, since we deal with particles and objects moving close to the speed of light. In special relativity, an object of rest mass \(m\) moving at speed \(v\) has kinetic energy

\[ K = mc^2\left[\left(1 - \frac{v^2}{c^2}\right)^{-1/2} - 1\right], \]

where \(c\) is the speed of light. Expand with the binomial series, \(k = -\tfrac12\) and \(x = -v^2/c^2\): \((1 - v^2/c^2)^{-1/2} = 1 + \dfrac12\dfrac{v^2}{c^2} + \dfrac38\dfrac{v^4}{c^4} + \cdots\). Therefore

\[ K = \frac12 mv^2 + \frac38 \frac{mv^4}{c^2} + \cdots. \]

The first term is exactly the classical kinetic energy from Newtonian physics. When \(v\) is small compared with \(c\), the other terms are tiny, which explains why Newton's formula works so well in everyday life. The relative size of the correction is about \(\tfrac34 (v/c)^2\): at \(v = 0.1c\) the classical formula is off by roughly \(0.75\%\) (Figure 14.6).

Common mistake In Taylor's inequality the bound \(M\) is for the \((n+1)\)st derivative, and it must hold on the whole interval between \(a\) and \(x\), not just at \(a\).
Key equations
\[ f(x)\approx T_n(x)=\sum_{i=0}^{n}\frac{f^{(i)}(a)}{i!}(x-a)^i \]
\[ K = mc^2\left[\left(1-\frac{v^2}{c^2}\right)^{-1/2}-1\right] = \frac12 mv^2+\frac38\frac{mv^4}{c^2}+\cdots \]

★Key takeaways

  • Absolute convergence implies convergence; the Ratio and Root Tests give absolute convergence when L < 1 and say nothing when L = 1.
  • Pick a test from the form of the terms: factorials and exponentials suggest the Ratio Test, rational expressions suggest comparison with a p-series.
  • A power series converges inside a radius R found by the Ratio Test; the endpoints must always be tested separately.
  • Power series can be differentiated and integrated term by term with the same radius of convergence.
  • The Taylor coefficients are c_n = f^(n)(a)/n!; memorize the basic Maclaurin series and build others from them.
  • Taylor polynomials give practical approximations, and the error can be bounded with Taylor's Inequality or the alternating series estimate.

Example 14.1 Absolutely convergent by the Ratio Test

Show that \(\displaystyle\sum_{n=1}^{\infty} (-1)^n \frac{n^2}{3^n}\) is absolutely convergent.

(Similar to Stewart §11.6, Example 4)
Show solution (try it first)

Given: \(a_n = (-1)^n \dfrac{n^2}{3^n}\). Find: show \(\sum |a_n|\) converges.

Plan: The exponential \(3^n\) suggests the Ratio Test, which works with absolute values automatically.

Step 1. Write the ratio of consecutive terms in absolute value (the \((-1)^n\) disappears):

\[ \left|\frac{a_{n+1}}{a_n}\right| = \frac{(n+1)^2}{3^{n+1}}\cdot\frac{3^n}{n^2}. \]

Step 2. Simplify, using \(\frac{3^n}{3^{n+1}} = \frac13\):

\[ \left|\frac{a_{n+1}}{a_n}\right| = \frac13\cdot\frac{(n+1)^2}{n^2} = \frac13\left(1 + \frac1n\right)^2. \]

Step 3. Take the limit: \(L = \frac13(1 + 0)^2 = \frac13\).

Step 4. Since \(L = \frac13 \lt 1\), the Ratio Test says the series is absolutely convergent, and hence convergent.

Answer: \(\boxed{L = \tfrac13 \lt 1,\ \text{absolutely convergent}}\). That is our answer.

Check: The actual sum is \(-\frac{3}{32} = -0.09375\), a finite number. Notice the Alternating Series Test would only give "convergent"; the Ratio Test gives the stronger conclusion.

Example 14.2 Radius and interval of convergence

Find the radius and interval of convergence of \(\displaystyle\sum_{n=1}^{\infty} \frac{(x-2)^n}{n\,4^n}\).

(Similar to Stewart §11.8, Example 5)
Show solution (try it first)

Given: a power series centred at \(a = 2\). Find: \(R\) and the interval of convergence.

Plan: Ratio Test with \(x\) held fixed gives \(R\); then test the two endpoints separately with earlier tests.

Step 1. Set up the ratio:

\[ \left|\frac{a_{n+1}}{a_n}\right| = \frac{|x-2|^{n+1}}{(n+1)4^{n+1}}\cdot\frac{n\,4^n}{|x-2|^n} = \frac{n}{n+1}\cdot\frac{|x-2|}{4}. \]

Step 2. Take the limit: \(\frac{n}{n+1} \to 1\), so \(L = \frac{|x-2|}{4}\).

Step 3. Require \(L \lt 1\): \(|x - 2| \lt 4\), so \(R = 4\) and the series converges absolutely on \((-2, 6)\).

Step 4. Right endpoint \(x = 6\): the series becomes \(\sum \dfrac{4^n}{n\,4^n} = \sum \dfrac1n\), the harmonic series, which diverges.

Step 5. Left endpoint \(x = -2\): the series becomes \(\sum \dfrac{(-4)^n}{n\,4^n} = \sum \dfrac{(-1)^n}{n}\), which converges by the Alternating Series Test (\(\frac1n\) decreases to 0).

Answer: \(\boxed{R = 4,\ \text{interval } [-2, 6)}\). That is our answer.

Check: The centre is 2 and the interval extends 4 units each way. ✓ Half-open intervals are normal when one endpoint gives a harmonic-type series.

Example 14.3 A power series from the geometric series

Find a power series representation for \(f(x) = \dfrac{x}{9 + x^2}\) and its radius of convergence.

(Similar to Stewart §11.9, Examples 2–3)
Show solution (try it first)

Given: \(f(x) = \dfrac{x}{9+x^2}\). Find: \(\sum c_n x^n\) and \(R\).

Plan: Rewrite \(f\) in the form \(\dfrac{1}{1 - (\text{something})}\), substitute into the geometric series, then multiply by the leftover factors.

Step 1. Factor 9 out of the denominator:

\[ \frac{1}{9 + x^2} = \frac19\cdot\frac{1}{1 + x^2/9} = \frac19\cdot\frac{1}{1 - \left(-\frac{x^2}{9}\right)}. \]

Step 2. Recall \(\frac{1}{1-u} = \sum_{n=0}^\infty u^n\) for \(|u| \lt 1\). Substitute \(u = -\frac{x^2}{9}\):

\[ \frac{1}{9+x^2} = \frac19\sum_{n=0}^{\infty}\left(-\frac{x^2}{9}\right)^n = \sum_{n=0}^{\infty}\frac{(-1)^n x^{2n}}{9^{n+1}}. \]

Step 3. Multiply by \(x\), which shifts every power up by 1:

\[ \frac{x}{9+x^2} = \sum_{n=0}^{\infty}\frac{(-1)^n x^{2n+1}}{9^{n+1}} = \frac{x}{9} - \frac{x^3}{81} + \frac{x^5}{729} - \cdots \]

Step 4. Radius: the geometric series needs \(|u| = \frac{x^2}{9} \lt 1\), that is \(|x| \lt 3\).

Answer: \(\boxed{\dfrac{x}{9+x^2} = \sum_{n=0}^{\infty}\dfrac{(-1)^n x^{2n+1}}{9^{n+1}},\quad R = 3}\). That is our answer.

Check: At \(x = 1\): \(f(1) = \frac1{10} = 0.1\), and \(\frac19 - \frac1{81} + \frac1{729} \approx 0.1001\). ✓

Example 14.4 A Taylor series from the coefficient formula

Find the Taylor series of \(f(x) = e^x\) centred at \(a = 2\), and its radius of convergence.

(Similar to Stewart §11.10, Example 4)
Show solution (try it first)

Given: \(f(x) = e^x\), \(a = 2\). Find: \(\sum c_n (x-2)^n\) and \(R\).

Plan: Use \(c_n = \frac{f^{(n)}(a)}{n!}\), then the Ratio Test for the radius.

Step 1. Differentiate: every derivative of \(e^x\) is \(e^x\), so \(f^{(n)}(2) = e^2\) for all \(n\).

Step 2. The coefficients are \(c_n = \dfrac{e^2}{n!}\), so

\[ e^x = \sum_{n=0}^{\infty}\frac{e^2}{n!}(x-2)^n = e^2\left[1 + (x-2) + \frac{(x-2)^2}{2!} + \frac{(x-2)^3}{3!} + \cdots\right]. \]

Step 3. Radius by the Ratio Test:

\[ \left|\frac{a_{n+1}}{a_n}\right| = \frac{e^2|x-2|^{n+1}}{(n+1)!}\cdot\frac{n!}{e^2|x-2|^n} = \frac{|x-2|}{n+1} \to 0 \lt 1 \text{ for every } x. \]

Answer: \(\boxed{e^x = \displaystyle\sum_{n=0}^{\infty}\frac{e^2}{n!}(x-2)^n,\quad R = \infty}\). That is our answer.

Check: Another way: \(e^x = e^2\cdot e^{x-2}\), and the Maclaurin series of \(e^u\) with \(u = x - 2\) gives exactly the same series. ✓

Example 14.5 Approximating a non-elementary integral

Use a Maclaurin series to approximate \(\displaystyle\int_0^{1/2} e^{-x^2}\,dx\) with error less than 0.0005.

(Similar to Stewart §11.10, Example 11)
Show solution (try it first)

Given: \(\int_0^{1/2} e^{-x^2}dx\), error \(\lt 0.0005\). Find: an approximation.

Plan: \(e^{-x^2}\) has no elementary antiderivative. Substitute \(-x^2\) into the series for \(e^x\), integrate term by term, and use the alternating series error bound.

Step 1. From \(e^u = 1 + u + \frac{u^2}{2!} + \frac{u^3}{3!} + \cdots\) with \(u = -x^2\):

\[ e^{-x^2} = 1 - x^2 + \frac{x^4}{2!} - \frac{x^6}{3!} + \cdots \quad \text{for all } x. \]

Step 2. Integrate term by term from 0 to \(\frac12\):

\[ \int_0^{1/2} e^{-x^2}dx = \left[x - \frac{x^3}{3} + \frac{x^5}{10} - \frac{x^7}{42} + \cdots\right]_0^{1/2} = \frac12 - \frac1{24} + \frac1{320} - \frac1{5376} + \cdots \]

Step 3. This is an alternating series with decreasing terms, so the error is at most the first omitted term. The fourth term is \(\frac{1}{5376} \approx 0.000186 \lt 0.0005\), so the first three terms are enough.

Step 4. Add them: \(\frac12 - \frac1{24} + \frac1{320} = \frac{480 - 40 + 3}{960} = \frac{443}{960}\).

Answer: \(\boxed{\displaystyle\int_0^{1/2} e^{-x^2}dx \approx \frac{443}{960} \approx 0.46146}\). That is our answer.
