7.5Strategy for Integration

By now we have a full toolbox: the basic formulas, substitution, integration by parts, trigonometric integrals, trigonometric substitution and partial fractions. So, what is the hard part now? It is no longer carrying out a method. It is deciding which method to use when an integral arrives without a section heading. That is the first goal of this whole topic: to identify and classify the type of integral and choose the right technique. Stewart §7.5 suggests a checklist. Let's go through it in order, and do not be afraid to drop an attempt that is getting worse.

Strategy checklist
  1. Simplify the integrand if possible. Expand, cancel, split a fraction, or use an identity. For example, \(\int(\sin x + \cos x)^2\,dx = \int(1 + \sin 2x)\,dx = x - \tfrac12\cos 2x + C\).
  2. Look for an obvious substitution. Is there a piece \(u = g(x)\) whose derivative \(g'(x)\) (up to a constant) also appears? In \(\int\frac{x}{x^2 - 1}\,dx\), let \(u = x^2 - 1\): the answer is \(\tfrac12\ln|x^2 - 1| + C\). No partial fractions needed.
  3. Classify the integrand by its form.
    • Products of powers of \(\sin, \cos, \tan, \sec\): trigonometric integrals, §7.2.
    • Rational function: partial fractions, §7.4.
    • A polynomial times a transcendental function, or a lone \(\ln x\) or \(\tan^{-1}x\): integration by parts with LIATE, §7.1.
    • \(\sqrt{a^2 - x^2}\), \(\sqrt{a^2 + x^2}\) or \(\sqrt{x^2 - a^2}\): trigonometric substitution, §7.3.
    • \(\sqrt[n]{ax + b}\) or \(\sqrt{x}\): try \(u = \sqrt[n]{ax + b}\).
  4. Try again. Try a less obvious substitution, try parts with a different \(u\), manipulate the integrand (multiply by a clever form of 1, use an identity), relate the problem to one you have done, or combine several methods in a row.

Recall \(\int\frac{x}{\sqrt{x^2 - 7}}\,dx\) from §7.3. We solved it with \(x = \sqrt7\sec\theta\), but step 2 of the checklist finds it in one line: \(u = x^2 - 7\) gives \(\sqrt{x^2 - 7} + C\). Take note that a longer method is not a better method.

Here is a manipulation that turns a hopeless-looking integral into an easy one. For \(\int\frac{dx}{1 + e^x}\), multiply the top and bottom by \(e^{-x}\): \(\int\frac{e^{-x}}{e^{-x} + 1}\,dx = -\ln(1 + e^{-x}) + C\), with \(u = e^{-x} + 1\).

Many integrals need two methods in a row. In \(\int e^{\sqrt{x}}\,dx\), the root suggests \(w = \sqrt{x}\), so \(x = w^2\) and \(dx = 2w\,dw\). The new integral \(\int 2we^{w}\,dw\) is a job for parts, and the answer is \(2(\sqrt x - 1)e^{\sqrt x} + C\).

Can every integral be done? No. Every continuous function has an antiderivative (by the Fundamental Theorem of Calculus), but for functions such as \(e^{x^2}\), \(\sin(x^2)\), \(\frac{e^x}{x}\) and \(\sqrt{1 + x^3}\), that antiderivative is not an elementary function: it cannot be written as a finite combination of polynomials, roots, exponentials, logarithms and trigonometric functions. The area under \(y = e^{-x^2}\) in Figure 8.1 is a perfectly good number (about 0.747). We just cannot find it with the methods of this chapter, so we estimate it numerically.

Common mistake Starting a long method without checking step 2. Many integrals that look like partial fractions or trigonometric substitution fall to a one-line \(u\)-substitution.
Key equations
\[ \text{1. Simplify} \;\to\; \text{2. Obvious substitution} \;\to\; \text{3. Classify by form} \;\to\; \text{4. Try again} \]
\[ \int\frac{dx}{1 + e^x} = \int\frac{e^{-x}}{e^{-x} + 1}\,dx = -\ln(1 + e^{-x}) + C \]

7.8Improper Integrals

An improper integral is an integral that involves infinite limits of integration, where the interval goes on to \(+\infty\) or \(-\infty\), or an unbounded integrand somewhere in the interval. In these cases, the normal definite integral does not directly apply, because either we are integrating over an infinite interval, or the function "blows up" (goes to infinity) somewhere in the domain. So, how do we handle them? With a limit. For this discussion, we will dive into the two types of improper integrals (Stewart §7.8): infinite intervals and discontinuous integrands.

Type 1: Infinite intervals. We replace \(\infty\) by a number \(b\), integrate as usual, and let \(b\) go to infinity:

\[\int_a^{\infty} f(x)\,dx = \lim_{b\to\infty}\int_a^b f(x)\,dx.\]

If the limit is a finite number, we say the integral converges. This means that the area under the curve, even though it is over an infinite range, adds up to a finite number. For example, \(\int_1^{\infty}\frac{dx}{x^2} = \lim_{b\to\infty}\left(1 - \frac1b\right) = 1\). The opposite is when the integral diverges, which means the limit is infinite (or does not exist): \(\int_1^{\infty}\frac{dx}{x} = \lim_{b\to\infty}\ln b = \infty\), and there is no finite area under the curve. The two curves look alike in Figure 8.2, yet one region has finite area and the other does not. Integrals \(\int_{-\infty}^{b}\) are defined the same way. For \(\int_{-\infty}^{\infty}\), split at any point \(a\); it converges only if both pieces converge. For instance, \(\int_{-\infty}^{\infty}\frac{dx}{1 + x^2} = \frac{\pi}{2} + \frac{\pi}{2} = \pi\).

Type 2: Discontinuous integrands. If \(f\) blows up at the left end \(x = a\), define \(\int_a^b f(x)\,dx = \lim_{t\to a^+}\int_t^b f(x)\,dx\), and similarly with \(t \to b^-\) at the right end. For example, \(\frac{1}{\sqrt x}\) becomes infinite at \(x = 0\), yet \(\int_0^1\frac{dx}{\sqrt x} = \lim_{t\to0^+}(2 - 2\sqrt t) = 2\) (Figure 8.3). But \(\int_0^1\frac{dx}{x} = \lim_{t\to0^+}(\ln 1 - \ln t) = \infty\) diverges. If the discontinuity is at an interior point \(c\), split there: \(\int_a^b = \int_a^c + \int_c^b\), and both pieces must converge.

Convergence criteria (p-integrals) At infinity, \(\displaystyle\int_1^{\infty}\frac{dx}{x^p}\) converges (to \(\frac{1}{p-1}\)) if \(p \gt 1\) and diverges if \(p \le 1\). Near 0 (or another discontinuity), \(\displaystyle\int_0^{1}\frac{dx}{x^p}\) converges (to \(\frac{1}{1-p}\)) if \(p \lt 1\) and diverges if \(p \ge 1\).

Comparison Test. When we cannot find an antiderivative, we can still decide convergence. Suppose \(f(x) \ge g(x) \ge 0\) for \(x \ge a\). If \(\int_a^{\infty} f\,dx\) converges, so does \(\int_a^{\infty} g\,dx\) (smaller than finite is finite). If \(\int_a^{\infty} g\,dx\) diverges, so does \(\int_a^{\infty} f\,dx\) (bigger than infinite is infinite). For \(x \ge 1\), \(e^{-x^2} \le e^{-x}\), and \(\int_1^{\infty}e^{-x}\,dx = e^{-1}\) converges, so \(\int_1^{\infty}e^{-x^2}\,dx\) converges too (Figure 8.4). Take note that the test says nothing if the larger integral diverges or the smaller one converges.

Now the question is, why does it matter? We focus on convergence because it tells us whether a problem has a finite answer, whether an integral can be used in a model in physics, and whether a Laplace or Fourier transform (Module 9) is well-defined.

Common mistake Ignoring an interior discontinuity. \(\int_{-1}^{1}\frac{dx}{x^2}\) is not \(\big[-\frac1x\big]_{-1}^{1} = -2\); a negative answer for a positive integrand is a red flag. Since \(\int_0^1\frac{dx}{x^2}\) diverges, the whole integral diverges.
Key equations
\[ \int_a^{\infty} f(x)\,dx = \lim_{b\to\infty}\int_a^b f(x)\,dx \]
\[ \int_a^b f(x)\,dx = \lim_{t\to a^+}\int_t^b f(x)\,dx \quad (f \text{ discontinuous at } a) \]
\[ \int_1^{\infty}\frac{dx}{x^p} = \frac{1}{p-1}\ (p \gt 1), \qquad \text{divergent if } p \le 1 \]
\[ \int_0^{1}\frac{dx}{x^p} = \frac{1}{1-p}\ (p \lt 1), \qquad \text{divergent if } p \ge 1 \]
\[ 0 \le g(x) \le f(x):\ \int_a^\infty f \text{ converges} \Rightarrow \int_a^\infty g \text{ converges} \]

★Key takeaways

  • Before choosing a method, simplify the integrand and look for an obvious substitution; only then classify it by its form.
  • Many integrals need two methods in a row, and some (like ∫e^{x²} dx) have no elementary antiderivative at all.
  • An improper integral is a limit of ordinary definite integrals: it converges if the limit is a finite number and diverges otherwise.
  • At infinity, ∫₁^∞ dx/x^p converges exactly when p > 1; near 0, ∫₀¹ dx/x^p converges exactly when p < 1.
  • Always check for a discontinuity inside the interval; split there, and require every piece to converge.
  • The Comparison Test decides convergence by bounding the integrand above by something convergent or below by something divergent.

Example 8.1 Simplify first with an identity

Evaluate \(\displaystyle\int\sin^2 x\cos^2 x\,dx\).

(Instr. Vitalez's notes, Trigonometric Integrals, Problem Set No. 2)
Show solution (try it first)
Given
  • Both powers are even, so no factor can be saved for a substitution.
  • Find: \(\int\sin^2 x\cos^2 x\,dx\).
Step 1: Simplify with identity (6)

Step 1 of the checklist says simplify. Since \(\sin x\cos x = \tfrac12\sin 2x\):

\[\sin^2 x\cos^2 x = (\sin x\cos x)^2 = \left(\tfrac12\sin 2x\right)^2 = \tfrac14\sin^2 2x\]

Step 2: Use the half-angle identity

With \(\sin^2\theta = \tfrac12(1 - \cos 2\theta)\) and \(\theta = 2x\):

\[\tfrac14\sin^2 2x = \tfrac14\cdot\tfrac12(1 - \cos 4x) = \tfrac18(1 - \cos 4x)\]

Step 3: Integrate

\[\int\tfrac18(1 - \cos 4x)\,dx = \tfrac18x - \tfrac18\cdot\tfrac14\sin 4x + C\]

\[= \frac{x}{8} - \frac{\sin 4x}{32} + C\]

Answer

\[\int\sin^2 x\cos^2 x\,dx = \frac{x}{8} - \frac{\sin 4x}{32} + C\]

Check

Differentiate: \(\tfrac18 - \tfrac{4\cos 4x}{32} = \tfrac18(1 - \cos 4x) = \tfrac14\sin^2 2x = \sin^2 x\cos^2 x\). ✓

Example 8.2 An obvious substitution

Evaluate \(\displaystyle\int(1 - \tan^2 x)\sec^2 x\,dx\).

(Instr. Vitalez's notes, Trigonometric Integrals, Problem Set No. 4)
Show solution (try it first)
Given
  • The integrand contains \(\tan x\) and its derivative \(\sec^2 x\).
  • Find: \(\int(1 - \tan^2 x)\sec^2 x\,dx\).
Step 1: Spot the substitution

Step 2 of the checklist: \(\frac{d}{dx}\tan x = \sec^2 x\), and \(\sec^2 x\,dx\) is sitting right there. So let \(u = \tan x\).

\[u = \tan x \quad\Rightarrow\quad du = \sec^2 x\,dx\]

Step 2: Substitute

\[\int(1 - \tan^2 x)\sec^2 x\,dx = \int(1 - u^2)\,du\]

Step 3: Integrate

\[= u - \frac{u^3}{3} + C\]

Step 4: Substitute back u = tan x

\[= \tan x - \frac{\tan^3 x}{3} + C\]

Answer

\[\int(1 - \tan^2 x)\sec^2 x\,dx = \tan x - \frac{\tan^3 x}{3} + C\]

Check

Differentiate: \(\sec^2 x - \tan^2 x\sec^2 x = (1 - \tan^2 x)\sec^2 x\). ✓ Expanding the integrand and using the secant strategies of §7.2 would also work, but it takes much longer.

Example 8.3 Type 1: one converges, one diverges

Decide whether each integral converges or diverges, and find its value if it converges: (a) \(\displaystyle\int_1^{\infty}\frac{dx}{x^2}\); (b) \(\displaystyle\int_1^{\infty}\frac{dx}{x}\).

(Instr. Vitalez's notes, Improper Integrals, Examples 19 and 20)
Show solution (try it first)
Given
  • Both upper limits are \(\infty\): Type 1 improper integrals.
  • The integrands \(\frac1{x^2}\) and \(\frac1x\) are continuous on \([1, \infty)\).
Step 1: Write (a) as a limit

As we can see, the upper limit is \(\infty\), so we define it using a limit.

\[\int_1^{\infty}\frac{dx}{x^2} = \lim_{b\to\infty}\int_1^b\frac{dx}{x^2}\]

Step 2: Integrate (a) on [1, b]

Recall that we evaluate with \(F(b) - F(a)\).

\[\int_1^b x^{-2}\,dx = \Big[-\frac1x\Big]_1^b = -\frac1b - \left(-\frac11\right) = 1 - \frac1b\]

Step 3: Take the limit for (a)

\[\lim_{b\to\infty}\left(1 - \frac1b\right) = 1 - 0 = 1\]

The integral converges to 1.

Step 4: Do the same for (b)

\[\int_1^b\frac{dx}{x} = \Big[\ln x\Big]_1^b = \ln b - \ln 1 = \ln b\]

\[\lim_{b\to\infty}\ln b = \infty\]

The integral diverges: there is no finite area under the curve.

Answer

(a) \(\int_1^{\infty}\frac{dx}{x^2}\) converges to 1. (b) \(\int_1^{\infty}\frac{dx}{x}\) diverges.

Check

This matches the p-integral rule: \(p = 2 \gt 1\) converges to \(\frac{1}{p-1} = 1\), while \(p = 1\) diverges (Figure 8.2).

Example 8.4 Type 2: one converges, one diverges

Decide whether each integral converges or diverges, and find its value if it converges: (a) \(\displaystyle\int_0^{1}\frac{dx}{\sqrt x}\); (b) \(\displaystyle\int_0^{1}\frac{dx}{x}\).

(Instr. Vitalez's notes, Improper Integrals, Examples 21 and 22)
Show solution (try it first)
Given
  • Both integrands become infinite at \(x = 0\), the left endpoint: Type 2 improper integrals.
  • Both are continuous on \((0, 1]\).
Step 1: Write (a) as a limit

Observe the integrand: it becomes infinite at \(x = 0\), so we handle it with a limit.

\[\int_0^1\frac{dx}{\sqrt x} = \lim_{a\to0^+}\int_a^1 x^{-1/2}\,dx\]

Step 2: Integrate (a) on [a, 1]

\[\int_a^1 x^{-1/2}\,dx = \Big[2\sqrt x\Big]_a^1 = 2 - 2\sqrt a\]

Step 3: Take the limit for (a)

\[\lim_{a\to0^+}\left(2 - 2\sqrt a\right) = 2 - 0 = 2\]

The integral converges to 2.

Step 4: Do the same for (b)

When \(x = 0\), this integrand blows up too, so again we take the limit.

\[\int_a^1\frac{dx}{x} = \Big[\ln x\Big]_a^1 = \ln 1 - \ln a = -\ln a\]

As \(a \to 0^+\), \(\ln a \to -\infty\), so

\[\lim_{a\to0^+}(-\ln a) = \infty\]

The integral diverges.

Answer

(a) \(\int_0^{1}\frac{dx}{\sqrt x}\) converges to 2. (b) \(\int_0^{1}\frac{dx}{x}\) diverges.

Check

Near 0 the rule flips: \(\frac{1}{\sqrt x} = \frac{1}{x^{1/2}}\) has \(p = \tfrac12 \lt 1\), so it converges to \(\frac{1}{1-p} = 2\); \(p = 1\) diverges.

Example 8.5 A Type 1 integral that needs parts

Determine whether \(\displaystyle\int_1^{\infty}\frac{\ln x}{x^2}\,dx\) converges, and if so find its value.

(Similar to Stewart §7.8, Example 4)
Show solution (try it first)
Given
  • Upper limit \(\infty\): a Type 1 improper integral.
  • The integrand is a logarithm times an algebraic function, so we need parts.
Step 1: Write it as a limit

\[\int_1^{\infty}\frac{\ln x}{x^2}\,dx = \lim_{b\to\infty}\int_1^b\frac{\ln x}{x^2}\,dx\]

Step 2: Choose u and dv with LIATE

L comes before A, so \(u = \ln x\).

\[u = \ln x \quad\Rightarrow\quad du = \frac1x\,dx\]

\[dv = x^{-2}\,dx \quad\Rightarrow\quad v = -\frac1x\]

Step 3: Integrate by parts on [1, b]

\[\int_1^b\frac{\ln x}{x^2}\,dx = \Big[-\frac{\ln x}{x}\Big]_1^b + \int_1^b\frac{dx}{x^2}\]

\[= \left(-\frac{\ln b}{b} + 0\right) + \left(1 - \frac1b\right)\]

Step 4: Take the limit

\(\frac1b \to 0\). For \(\frac{\ln b}{b}\), both parts go to \(\infty\), so use l'Hospital's Rule:

\[\lim_{b\to\infty}\frac{\ln b}{b} = \lim_{b\to\infty}\frac{1/b}{1} = 0\]

\[\lim_{b\to\infty}\left(-\frac{\ln b}{b} + 1 - \frac1b\right) = 0 + 1 - 0 = 1\]

Answer

The integral converges, and \(\displaystyle\int_1^{\infty}\frac{\ln x}{x^2}\,dx = 1\).

Check

The integrand is positive, so a positive answer makes sense. Also \(\ln x \le \sqrt x\) for \(x \ge 1\), so \(\frac{\ln x}{x^2} \le \frac{1}{x^{3/2}}\), a convergent p-integral (\(p = \tfrac32\)): the Comparison Test agrees.

Example 8.6 A discontinuity inside the interval

Evaluate \(\displaystyle\int_0^{3}\frac{dx}{(x - 1)^{2/3}}\) or show that it diverges.

(Similar to Stewart §7.8, Example 8)
Show solution (try it first)
Given
  • The integrand is infinite at \(x = 1\), which lies inside \([0, 3]\).
  • An antiderivative of \((x - 1)^{-2/3}\) is \(3(x - 1)^{1/3}\).
Step 1: Split at the discontinuity

\[\int_0^3\frac{dx}{(x - 1)^{2/3}} = \int_0^1\frac{dx}{(x - 1)^{2/3}} + \int_1^3\frac{dx}{(x - 1)^{2/3}}\]

Both pieces must converge.

Step 2: Left piece

\[\lim_{t\to1^-}\Big[3(x - 1)^{1/3}\Big]_0^t = \lim_{t\to1^-}\left(3(t - 1)^{1/3} - 3(-1)^{1/3}\right)\]

\[= 0 - 3(-1) = 3\]

Step 3: Right piece

\[\lim_{t\to1^+}\Big[3(x - 1)^{1/3}\Big]_t^3 = \lim_{t\to1^+}\left(3\sqrt[3]{2} - 3(t - 1)^{1/3}\right)\]

\[= 3\sqrt[3]{2} - 0 = 3\sqrt[3]{2}\]

Step 4: Add the pieces

Both pieces converge, so

\[\int_0^3\frac{dx}{(x - 1)^{2/3}} = 3 + 3\sqrt[3]{2} \approx 3 + 3.780 = 6.780\]

Answer

The integral converges, and \(\displaystyle\int_0^{3}\frac{dx}{(x - 1)^{2/3}} = 3 + 3\sqrt[3]{2} \approx 6.780\).

Check

Each piece is like \(\int_0^1\frac{du}{u^{2/3}}\), a p-integral with \(p = \tfrac23 \lt 1\), so convergence is expected. With \(\frac{1}{(x - 1)^2}\) instead, the same careless one-step calculation would give a finite answer for a divergent integral.
