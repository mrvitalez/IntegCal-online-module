7.5Strategy for Integration

By now you have a toolbox: basic formulas, substitution, integration by parts, trigonometric integrals, trigonometric substitution and partial fractions. The hard part is no longer carrying out a method; it is deciding which method to use when an integral arrives without a section heading. Stewart §7.5 suggests a checklist. Work through it in order, and do not be afraid to abandon an attempt that is getting worse.

Strategy checklist
  1. Simplify the integrand if possible. Expand, cancel, split a fraction, or use an identity. Example: \(\int(\sin x + \cos x)^2\,dx = \int(1 + \sin 2x)\,dx = x - \tfrac12\cos 2x + C\).
  2. Look for an obvious substitution. Is some piece \(u = g(x)\) whose derivative \(g'(x)\) (up to a constant) also appears? In \(\int\frac{x}{x^2 - 1}\,dx\), let \(u = x^2 - 1\): the answer is \(\tfrac12\ln|x^2 - 1| + C\). No partial fractions needed.
  3. Classify the integrand by its form.
    • Products of powers of \(\sin, \cos, \tan, \sec\): use §7.2.
    • Rational function: partial fractions, §7.4.
    • Product of a polynomial and a transcendental function, or a lone \(\ln x\) or \(\tan^{-1}x\): integration by parts, §7.1.
    • \(\sqrt{\pm x^2 \pm a^2}\): trigonometric substitution, §7.3.
    • \(\sqrt[n]{ax + b}\) or \(\sqrt{x}\): try \(u = \sqrt[n]{ax + b}\).
  4. Try again. Try a less obvious substitution, try parts with a different \(u\), manipulate the integrand (multiply by a clever form of 1, use an identity), relate the problem to one you have done, or combine several methods in sequence.

Here is a manipulation that turns a hopeless-looking integral into an easy one. For \(\int\frac{dx}{1 + e^x}\), multiply top and bottom by \(e^{-x}\): \(\int\frac{e^{-x}}{e^{-x} + 1}\,dx = -\ln(1 + e^{-x}) + C\), with \(u = e^{-x} + 1\).

Many integrals need two methods in a row. In \(\int e^{\sqrt{x}}\,dx\), the root suggests \(w = \sqrt{x}\), so \(x = w^2\) and \(dx = 2w\,dw\); the new integral \(\int 2we^{w}\,dw\) is a job for parts (Example 1).

Can every integral be done? No. Every continuous function has an antiderivative (by the Fundamental Theorem of Calculus), but for functions such as \(e^{x^2}\), \(\sin(x^2)\), \(\frac{e^x}{x}\) and \(\sqrt{1 + x^3}\) that antiderivative is not an elementary function: it cannot be written as a finite combination of polynomials, roots, exponentials, logarithms and trig functions. The area under \(y = e^{-x^2}\) in Figure 8.1 is a perfectly good number; you just cannot find it with the methods of this chapter, and must estimate it numerically.

Common mistake Starting a long method without checking step 2. Many integrals that look like partial fractions or trigonometric substitution fall to a one-line \(u\)-substitution.
Key equations
\[ \text{1. Simplify} \;\to\; \text{2. Obvious substitution} \;\to\; \text{3. Classify by form} \;\to\; \text{4. Try again} \]
\[ \int\frac{dx}{1 + e^x} = \int\frac{e^{-x}}{e^{-x} + 1}\,dx = -\ln(1 + e^{-x}) + C \]

7.8Improper Integrals

The definite integral \(\int_a^b f(x)\,dx\) was defined for a finite interval and a bounded function. Stewart §7.8 extends it to two situations where one of these fails. The tool in both cases is a limit.

Type 1: infinite intervals. If \(\int_a^t f(x)\,dx\) exists for every \(t \ge a\), define

\[\int_a^{\infty} f(x)\,dx = \lim_{t\to\infty}\int_a^t f(x)\,dx.\]

If the limit exists as a finite number, the improper integral converges; otherwise it diverges. For example, \(\int_1^{\infty}\frac{dx}{x^2} = \lim_{t\to\infty}\big(1 - \frac1t\big) = 1\), while \(\int_1^{\infty}\frac{dx}{x} = \lim_{t\to\infty}\ln t = \infty\) diverges. The two curves look alike in Figure 8.2, yet one region has finite area and the other does not. Integrals \(\int_{-\infty}^{b}\) are defined the same way. For \(\int_{-\infty}^{\infty}\), split at any convenient point \(a\); the integral converges only if both \(\int_{-\infty}^{a}\) and \(\int_a^{\infty}\) converge. For instance, \(\int_{-\infty}^{\infty}\frac{dx}{1 + x^2} = \frac{\pi}{2} + \frac{\pi}{2} = \pi\).

Why should an infinitely long region ever have finite area? Because the height can shrink fast enough. Over each interval \([n, n+1]\) the area under \(1/x^2\) is about \(1/n^2\), and these pieces add up to a finite total; under \(1/x\) the pieces are about \(1/n\), and they keep adding up without bound. Exponential decay is faster still: \(\int_0^{\infty}e^{-x}\,dx = \lim_{t\to\infty}(1 - e^{-t}) = 1\). Integrals like this appear whenever a quantity is spread over an unlimited range, such as total drug eliminated from the body or the total probability of a waiting time.

p-integrals \(\displaystyle\int_1^{\infty}\frac{dx}{x^p}\) converges to \(\dfrac{1}{p - 1}\) if \(p \gt 1\) and diverges if \(p \le 1\). Also \(\displaystyle\int_0^{1}\frac{dx}{x^p}\) converges to \(\dfrac{1}{1 - p}\) if \(p \lt 1\) and diverges if \(p \ge 1\).

Type 2: discontinuous integrands. If \(f\) is continuous on \([a, b)\) but blows up at \(b\), define \(\int_a^b f(x)\,dx = \lim_{t\to b^-}\int_a^t f(x)\,dx\); similarly at the left end, \(\lim_{t\to a^+}\int_t^b\). Example: \(\int_0^1\frac{dx}{\sqrt{x}} = \lim_{t\to 0^+}\big(2 - 2\sqrt{t}\big) = 2\) (Figure 8.3). If the discontinuity is at an interior point \(c\), split there: \(\int_a^b = \int_a^c + \int_c^b\), and both pieces must converge.

Common mistake Ignoring an interior discontinuity. \(\int_{-1}^{1}\frac{dx}{x^2}\) is not \(\big[-\frac1x\big]_{-1}^{1} = -2\) (a negative answer for a positive integrand is a red flag). Since \(\int_0^1\frac{dx}{x^2}\) diverges, the whole integral diverges.

Comparison test. When you cannot find an antiderivative, you can still decide convergence. Suppose \(f\) and \(g\) are continuous with \(f(x) \ge g(x) \ge 0\) for \(x \ge a\).

  • If \(\int_a^{\infty} f(x)\,dx\) converges, then \(\int_a^{\infty} g(x)\,dx\) converges (smaller than finite is finite).
  • If \(\int_a^{\infty} g(x)\,dx\) diverges, then \(\int_a^{\infty} f(x)\,dx\) diverges (bigger than infinite is infinite).

For \(x \ge 1\), \(x^2 \ge x\), so \(e^{-x^2} \le e^{-x}\). Since \(\int_1^{\infty}e^{-x}\,dx = e^{-1}\) converges, so does \(\int_1^{\infty}e^{-x^2}\,dx\), even though you cannot evaluate it in closed form (Figure 8.4). Be careful: the test says nothing if the larger integral diverges or the smaller one converges.

Key equations
\[ \int_a^{\infty} f(x)\,dx = \lim_{t\to\infty}\int_a^t f(x)\,dx \]
\[ \int_a^b f(x)\,dx = \lim_{t\to b^-}\int_a^t f(x)\,dx \quad (f \text{ discontinuous at } b) \]
\[ \int_1^{\infty}\frac{dx}{x^p} = \frac{1}{p-1}\ (p \gt 1), \qquad \text{divergent if } p \le 1 \]
\[ 0 \le g(x) \le f(x):\ \int_a^\infty f \text{ converges} \Rightarrow \int_a^\infty g \text{ converges} \]

★Key takeaways

  • Before choosing a method, simplify the integrand and look for an obvious substitution; only then classify it by form.
  • Many integrals need two methods in a row, and some (like ∫e^{x²} dx) have no elementary antiderivative at all.
  • An improper integral is a limit of ordinary definite integrals; it converges if the limit is a finite number and diverges otherwise.
  • ∫₁^∞ dx/x^p converges exactly when p > 1, and ∫₀¹ dx/x^p converges exactly when p < 1.
  • Always check for discontinuities inside the interval; split there, and require every piece to converge.
  • The Comparison Test decides convergence by bounding the integrand above by something convergent or below by something divergent.

Example 8.1 Two methods in a row

Find \(\displaystyle\int e^{\sqrt{x}}\,dx\).

(Similar to Stewart §7.5, Example 6)
Show solution (try it first)

Strategy:

Step 1 (simplify) and step 2 (obvious substitution) do not finish it: there is no \(\frac{1}{2\sqrt x}\) factor to pair with \(\sqrt{x}\). Step 3 says a root suggests \(w = \sqrt{x}\). After that, a polynomial times an exponential calls for parts.

Solution:

Let \(w = \sqrt{x}\), so \(x = w^2\) and \(dx = 2w\,dw\):

\[\int e^{\sqrt x}\,dx = \int 2w e^{w}\,dw.\]

Parts with \(u = 2w\), \(dv = e^w\,dw\): \(\int 2we^w\,dw = 2we^w - \int 2e^w\,dw = 2we^w - 2e^w + C\). Back to \(x\):

\[\int e^{\sqrt x}\,dx = 2(\sqrt{x} - 1)e^{\sqrt{x}} + C.\]

Check:

Differentiate: \(2\cdot\frac{1}{2\sqrt x}e^{\sqrt x} + 2(\sqrt x - 1)e^{\sqrt x}\cdot\frac{1}{2\sqrt x} = \frac{e^{\sqrt x}}{\sqrt x}\big(1 + \sqrt x - 1\big) = e^{\sqrt x}\). Correct.

Example 8.2 A Type 1 integral that needs parts

Determine whether \(\displaystyle\int_1^{\infty}\frac{\ln x}{x^2}\,dx\) converges, and if so find its value.

(Similar to Stewart §7.8, Example 4)
Show solution (try it first)

Strategy:

Replace \(\infty\) by \(t\), evaluate the ordinary integral by parts (LIATE: \(u = \ln x\)), then let \(t \to \infty\).

Solution:

With \(u = \ln x\), \(dv = x^{-2}\,dx\), \(du = \frac1x\,dx\), \(v = -\frac1x\):

\[\int_1^t\frac{\ln x}{x^2}\,dx = \Big[-\frac{\ln x}{x}\Big]_1^t + \int_1^t\frac{dx}{x^2} = -\frac{\ln t}{t} + 1 - \frac1t.\]

As \(t \to \infty\), \(\frac1t \to 0\), and by l'Hospital's Rule \(\lim_{t\to\infty}\frac{\ln t}{t} = \lim_{t\to\infty}\frac{1/t}{1} = 0\). Therefore the integral converges and

\[\int_1^{\infty}\frac{\ln x}{x^2}\,dx = 1.\]

Check:

The integrand is positive, so a positive answer makes sense. Also, \(\ln x \le \sqrt{x}\) for \(x \ge 1\), so \(\frac{\ln x}{x^2} \le \frac{1}{x^{3/2}}\), a convergent p-integral with \(p = \tfrac32\): the Comparison Test agrees that it converges.

Example 8.3 A discontinuity inside the interval

Evaluate \(\displaystyle\int_0^{3}\frac{dx}{(x - 1)^{2/3}}\) or show that it diverges.

(Similar to Stewart §7.8, Example 8)
Show solution (try it first)

Strategy:

The integrand is infinite at \(x = 1\), which lies inside \([0, 3]\). Split there and treat each piece as a Type 2 integral. The antiderivative of \((x-1)^{-2/3}\) is \(3(x - 1)^{1/3}\).

Solution:

Left piece: \(\displaystyle\lim_{t\to 1^-}\Big[3(x-1)^{1/3}\Big]_0^t = \lim_{t\to 1^-}\big(3(t-1)^{1/3} - 3(-1)\big) = 3\).

Right piece: \(\displaystyle\lim_{t\to 1^+}\Big[3(x-1)^{1/3}\Big]_t^3 = 3\sqrt[3]{2} - 0 = 3\sqrt[3]{2}\).

Both pieces converge, so

\[\int_0^{3}\frac{dx}{(x-1)^{2/3}} = 3 + 3\sqrt[3]{2} \approx 6.780.\]

Check:

Each piece is like \(\int_0^1\frac{du}{u^{2/3}}\), a p-integral with \(p = \tfrac23 \lt 1\), so convergence is expected. Here the careless calculation \(\big[3(x-1)^{1/3}\big]_0^3\) happens to give the same number, but only because both pieces converge; with \(\frac{1}{(x-1)^2}\) it would give a wrong finite answer for a divergent integral.
