7.5Strategy for Integration

Up to now, every integral came with a hint: the section title told us whether to use parts, trigonometric substitution or partial fractions. In an exam, or in a real physics problem, nobody tells you the method. So the question for this section is: when we face an integral cold, how do we decide what to do?

First, take note that integration is harder than differentiation. Every elementary function has a derivative that we can compute by rules, but there is no rule that always works for integrals. What we can have is a strategy, and a good table of basic formulas in our head.

Strategy for integration 1. Simplify the integrand if possible. Use algebra or identities first. For example, \(\int\sqrt{x}(1 + \sqrt x)\,dx = \int(x^{1/2} + x)\,dx\), and \(\int\frac{\tan\theta}{\sec^2\theta}\,d\theta = \int\sin\theta\cos\theta\,d\theta = \frac12\int\sin2\theta\,d\theta\).
2. Look for an obvious substitution. Find some \(u = g(x)\) whose differential \(du = g'(x)\,dx\) appears in the integrand, apart from a constant. Recall: if the numerator is the derivative of the denominator, let \(u\) be the denominator.
3. Classify the integrand by its form. (a) Trigonometric functions: powers of \(\sin\), \(\cos\), \(\tan\), \(\sec\) → strategies of §7.2. (b) Rational functions → partial fractions (§7.4). (c) Products of different types (polynomial × exponential, logarithm × power) → integration by parts (§7.1). (d) Radicals: \(\sqrt{\pm x^2 \pm a^2}\) → trigonometric substitution (§7.3); \(\sqrt[n]{ax + b}\) → let \(u = \sqrt[n]{ax + b}\).
4. Try again. If the first three steps do not work, try another substitution, try parts, manipulate the integrand (multiply by a conjugate, use an identity), relate it to a problem you have done before, or use several methods one after another.

Step 4 sounds vague, but it is how real problems are solved. For example, in \(\int e^{\sqrt x}\,dx\) no single method works directly. But if we let \(w = \sqrt x\) (a radical substitution, step 3d), then \(x = w^2\), \(dx = 2w\,dw\), and the integral becomes \(\int 2we^{w}\,dw\), which is a textbook case for integration by parts. Two methods, one after the other. You will see the full solution in Example 8.1.

Can we integrate every function? No. Some continuous functions, such as \(e^{-x^2}\), \(\frac{\sin x}{x}\), \(\sqrt{1 + x^3}\) and \(\frac{1}{\ln x}\), have antiderivatives that cannot be written with the elementary functions we know. The integrals still exist (Figure 8.1 shows the area under \(e^{-x^2}\) from 0 to 1, about 0.747); we just compute them numerically or with series. So if you have tried everything and nothing works, the problem may not have an elementary answer at all.

Common mistake Jumping straight to a complicated method. Before doing partial fractions on \(\int\frac{x}{x^2 + 1}\,dx\), notice that the numerator is half the derivative of the denominator: the answer is \(\frac12\ln(x^2 + 1) + C\) in one line. Always check steps 1 and 2 first.
Key equations
\[ \int\frac{g'(x)}{g(x)}\,dx = \ln|g(x)| + C \]
\[ \sqrt[n]{ax + b}:\ \text{let } u = \sqrt[n]{ax + b} \]

7.8Improper Integrals

An improper integral is an integral that involves infinite limits of integration, where your interval goes on to \(+\infty\) or \(-\infty\), or an unbounded integrand somewhere in the interval. In these cases the normal definite integral does not directly apply, because either we are integrating over an infinite interval, or the function "blows up" (goes to infinity) somewhere in the domain. The trick in both cases is the same: replace the troublesome endpoint by a variable, integrate normally, then take a limit.

For this discussion, we will dive into the two types of improper integrals: infinite intervals and discontinuous integrands.

TYPE 1: Infinite intervals \[\int_a^{\infty}f(x)\,dx = \lim_{b\to\infty}\int_a^{b}f(x)\,dx,\qquad \int_{-\infty}^{b}f(x)\,dx = \lim_{a\to-\infty}\int_a^{b}f(x)\,dx\] If the limit exists (and is a finite number), the integral is convergent; otherwise it is divergent. For \(\int_{-\infty}^{\infty}\), split at any point \(c\): \(\int_{-\infty}^{\infty} = \int_{-\infty}^{c} + \int_c^{\infty}\), and both pieces must converge.

To better understand this, let's take \(\int_1^\infty\frac{1}{x^2}\,dx\). As we can see, the upper limit is \(\infty\), so we define it using a limit. Solving the ordinary integral first, \(\int_1^b\frac{dx}{x^2} = \Big[-\frac1x\Big]_1^b = -\frac1b + 1\). And if we take the limit as \(b\to\infty\), \(-\frac1b\to0\), so the integral converges to 1. What does "converges" mean here? It means that the area under the curve, even though it is over an infinite range, adds up to a finite number (Figure 8.2).

The opposite is when the integral diverges, which means that the integral goes to infinity (or the limit does not exist). For \(\int_1^\infty\frac1x\,dx\): \(\int_1^b\frac1x\,dx = \ln b - \ln 1 = \ln b\), and \(\ln b\to\infty\). There is no finite area under \(\frac1x\), even though the curve looks almost the same as \(\frac1{x^2}\) in Figure 8.2. The difference is how fast each curve goes to zero.

TYPE 2: Discontinuous integrands If \(f\) is continuous on \((a, b]\) but blows up at \(a\), then \(\int_a^bf(x)\,dx = \lim_{t\to a^+}\int_t^bf(x)\,dx\). If it blows up at \(b\), use \(\lim_{t\to b^-}\int_a^t\). If it blows up at a point \(c\) inside \((a, b)\), split: \(\int_a^b = \int_a^c + \int_c^b\), and both must converge.

Observe the integrand of \(\int_0^1\frac{dx}{\sqrt x}\). It becomes infinite at \(x = 0\), so we handle it with a limit: \(\int_t^1x^{-1/2}\,dx = \big[2\sqrt x\big]_t^1 = 2 - 2\sqrt t\to 2\) as \(t\to0^+\). The integral converges to 2, even though the region is infinitely tall (Figure 8.3). But \(\int_0^1\frac{dx}{x}\) gives \(\ln1 - \ln t = -\ln t\to\infty\): it diverges.

With these four examples, we can generalize the convergence criteria into the following (the \(p\)-integrals):

IntegralConverges whenDiverges whenValue if convergent
\(\int_1^\infty\frac{dx}{x^p}\) (at infinity)\(p \gt 1\)\(p \le 1\)\(\frac{1}{p - 1}\)
\(\int_0^1\frac{dx}{x^p}\) (near 0)\(p \lt 1\)\(p \ge 1\)\(\frac{1}{1 - p}\)

The Comparison Test. Sometimes we cannot evaluate the integral at all, like \(\int_1^\infty e^{-x^2}\,dx\). We can still decide convergence by comparing with a simpler function. Suppose \(0 \le g(x) \le f(x)\) for \(x \ge a\). If \(\int_a^\infty f\) converges, then \(\int_a^\infty g\) converges (a smaller area under a finite area is finite). If \(\int_a^\infty g\) diverges, then \(\int_a^\infty f\) diverges (a bigger area over an infinite area is infinite). For \(x \ge 1\), \(x^2 \ge x\), so \(e^{-x^2} \le e^{-x}\), and \(\int_1^\infty e^{-x}\,dx = e^{-1}\) is finite. Therefore \(\int_1^\infty e^{-x^2}\,dx\) converges (Figure 8.4).

Now the question is, why does it matter? We actually want to focus on the convergence of an integral because it tells us whether a problem has a finite answer at all: whether the escape energy of a rocket is finite, whether a probability density really adds up to 1, or whether a Laplace or Fourier transform (Module 9) is well-defined.

Common mistake Missing a hidden discontinuity. \(\int_{-1}^{2}\frac{dx}{x^2}\) looks like an ordinary definite integral, and blindly computing \(\big[-\frac1x\big]_{-1}^2 = -\frac12 - 1 = -\frac32\) gives a negative area for a positive function, which is impossible. The integrand blows up at \(x = 0\) inside the interval, and \(\int_0^2\frac{dx}{x^2}\) diverges, so the whole integral diverges. Always check the integrand on the whole interval first.
Key equations
\[ \int_a^{\infty}f(x)\,dx = \lim_{b\to\infty}\int_a^{b}f(x)\,dx,\qquad \int_a^{b}f(x)\,dx = \lim_{t\to a^+}\int_t^{b}f(x)\,dx \]
\[ \int_1^\infty\frac{dx}{x^p}\ \text{converges} \iff p \gt 1,\qquad \int_0^1\frac{dx}{x^p}\ \text{converges} \iff p \lt 1 \]

★Key takeaways

  • There is no single rule for integrals. Use the strategy: simplify, look for an obvious substitution, classify the form, and if needed try again with a combination of methods.
  • Some integrals, like \(\int e^{-x^2}\,dx\), have no elementary antiderivative; they are computed numerically.
  • An improper integral has an infinite limit (Type 1) or an integrand that blows up (Type 2). Replace the bad endpoint with a variable and take a limit.
  • Converges means the limit is a finite number; diverges means it is infinite or does not exist.
  • \(\int_1^\infty x^{-p}\,dx\) converges only for \(p \gt 1\); \(\int_0^1 x^{-p}\,dx\) converges only for \(p \lt 1\).
  • The Comparison Test decides convergence without evaluating: smaller than convergent converges, bigger than divergent diverges.
  • Always check for a discontinuity inside the interval before evaluating a definite integral.

Example 8.1 Two methods in a row

Evaluate \(\displaystyle\int e^{\sqrt x}\,dx\).

(Strategy for integration, step 4)
Show solution (try it first)

Given: \(\int e^{\sqrt x}\,dx\). No basic formula applies, and there is no obvious \(du\).

Plan: The radical suggests the substitution \(w = \sqrt x\) (strategy step 3d). That turns the integral into \(\int 2we^w\,dw\), which we finish with integration by parts.

Step 1. Let \(w = \sqrt x\). Then \(x = w^2\) and \(dx = 2w\,dw\).

\[\int e^{\sqrt x}\,dx = \int e^{w}\cdot 2w\,dw = 2\int we^{w}\,dw\]

Step 2. Integrate by parts. By LIATE, the algebraic \(w\) comes before the exponential, so \(u = w\), \(du = dw\), \(dv = e^w\,dw\), \(v = e^w\).

\[2\int we^w\,dw = 2\left(we^w - \int e^w\,dw\right) = 2\left(we^w - e^w\right) + C = 2e^w(w - 1) + C\]

Step 3. Go back to \(x\) with \(w = \sqrt x\).

\[= 2e^{\sqrt x}\left(\sqrt x - 1\right) + C\]

Answer: \(\boxed{\displaystyle\int e^{\sqrt x}\,dx = 2e^{\sqrt x}(\sqrt x - 1) + C}\). That is our answer.

Check: Differentiate: \(\frac{d}{dx}\left[2e^{\sqrt x}(\sqrt x - 1)\right] = 2e^{\sqrt x}\cdot\frac{1}{2\sqrt x}(\sqrt x - 1) + 2e^{\sqrt x}\cdot\frac{1}{2\sqrt x} = \frac{e^{\sqrt x}}{\sqrt x}(\sqrt x - 1 + 1) = e^{\sqrt x}\). ✓

Example 8.2 Type 1: converges or diverges?

Evaluate (a) \(\displaystyle\int_1^{\infty}\frac{1}{x^2}\,dx\) and (b) \(\displaystyle\int_1^{\infty}\frac{1}{x}\,dx\), or show that they diverge.

(From the instructor's module)
Show solution (try it first)

Given: Two improper integrals with an infinite upper limit (Type 1).

Plan: Replace \(\infty\) by \(b\), integrate normally, evaluate with \(F(b) - F(a)\), and then let \(b\to\infty\).

Step 1. (a) Write the integral as a limit.

\[\int_1^\infty\frac{dx}{x^2} = \lim_{b\to\infty}\int_1^b x^{-2}\,dx\]

Step 2. Integrate and use \(F(b) - F(1)\).

\[\int_1^b x^{-2}\,dx = \left[-\frac1x\right]_1^b = -\frac1b - \left(-\frac11\right) = 1 - \frac1b\]

Step 3. Take the limit. As \(b\to\infty\), \(\frac1b\to0\).

\[\lim_{b\to\infty}\left(1 - \frac1b\right) = 1\]

Step 4. (b) Do the same for \(\frac1x\). Its antiderivative is \(\ln x\).

\[\int_1^b\frac{dx}{x} = \ln b - \ln 1 = \ln b \quad\Longrightarrow\quad \lim_{b\to\infty}\ln b = \infty\]

Answer: (a) \(\boxed{\int_1^\infty x^{-2}\,dx = 1}\), the integral converges to 1. (b) \(\boxed{\text{diverges}}\): there is no finite area under \(y = \frac1x\) on \([1, \infty)\).

Check: Both agree with the \(p\)-integral rule: \(p = 2 \gt 1\) converges to \(\frac1{p-1} = 1\), and \(p = 1\) diverges. ✓

Example 8.3 Type 2: an integrand that blows up at 0

Evaluate (a) \(\displaystyle\int_0^{1}\frac{1}{\sqrt x}\,dx\) and (b) \(\displaystyle\int_0^{1}\frac{1}{x}\,dx\), or show that they diverge.

(From the instructor's module)
Show solution (try it first)

Given: Both integrands become infinite at \(x = 0\), the lower limit (Type 2).

Plan: Replace 0 by \(a\), integrate from \(a\) to 1, and let \(a\to0^+\) (from the right, since we stay inside the interval).

Step 1. (a) Write as a limit and integrate: \(\int x^{-1/2}\,dx = 2x^{1/2}\).

\[\int_0^1\frac{dx}{\sqrt x} = \lim_{a\to0^+}\int_a^1x^{-1/2}\,dx = \lim_{a\to0^+}\Big[2\sqrt x\Big]_a^1\]

Step 2. Evaluate with \(f(b) - f(a)\), then take the limit; \(\sqrt a\to0\).

\[= \lim_{a\to0^+}\left(2 - 2\sqrt a\right) = 2\]

Step 3. (b) The same steps with \(\int\frac{dx}{x} = \ln x\).

\[\int_a^1\frac{dx}{x} = \ln 1 - \ln a = -\ln a,\qquad \lim_{a\to0^+}(-\ln a) = +\infty\]

Answer: (a) \(\boxed{\int_0^1\frac{dx}{\sqrt x} = 2}\), it converges. (b) \(\boxed{\text{diverges}}\).

Check: The \(p\)-rule near 0: \(p = \frac12 \lt 1\) converges to \(\frac{1}{1 - p} = 2\) ✓; \(p = 1\) diverges ✓.

Example 8.4 Both limits infinite

Evaluate \(\displaystyle\int_{-\infty}^{\infty}\frac{dx}{1 + x^2}\).

(Similar to Stewart §7.8, Example 3)
Show solution (try it first)

Given: An integral with both limits infinite; the integrand is even.

Plan: Split at \(c = 0\) into two Type 1 integrals. Each must converge on its own. Use \(\int\frac{dx}{1+x^2} = \tan^{-1}x\).

Step 1. Split at 0.

\[\int_{-\infty}^{\infty}\frac{dx}{1 + x^2} = \int_{-\infty}^{0}\frac{dx}{1 + x^2} + \int_0^{\infty}\frac{dx}{1 + x^2}\]

Step 2. Right half. Recall \(\tan^{-1}b\to\frac\pi2\) as \(b\to\infty\).

\[\int_0^\infty\frac{dx}{1+x^2} = \lim_{b\to\infty}\big[\tan^{-1}x\big]_0^b = \lim_{b\to\infty}\tan^{-1}b - 0 = \frac\pi2\]

Step 3. Left half. \(\tan^{-1}a\to-\frac\pi2\) as \(a\to-\infty\).

\[\int_{-\infty}^0\frac{dx}{1+x^2} = \lim_{a\to-\infty}\big[\tan^{-1}x\big]_a^0 = 0 - \left(-\frac\pi2\right) = \frac\pi2\]

Step 4. Both halves converge, so add them.

\[\frac\pi2 + \frac\pi2 = \pi\]

Answer: \(\boxed{\pi}\). The infinitely long region under \(y = \frac{1}{1+x^2}\) has finite area \(\pi\).

Check: The function is even, so the two halves must be equal, and they are (\(\frac\pi2\) each). ✓ This is also why \(f(x) = \frac{1}{\pi(1 + x^2)}\) is a probability density (Module 10).

Example 8.5 Comparison Test

Show that \(\displaystyle\int_1^{\infty}e^{-x^2}\,dx\) converges.

(Similar to Stewart §7.8, Example 9)
Show solution (try it first)

Given: \(e^{-x^2}\) has no elementary antiderivative, so we cannot evaluate the limit directly.

Plan: Find a simpler function that is bigger than \(e^{-x^2}\) on \([1, \infty)\) and whose integral converges. Then the Comparison Test does the rest.

Step 1. Compare the exponents. For \(x \ge 1\), multiplying \(x \ge 1\) by \(x \gt 0\) gives \(x^2 \ge x\), so \(-x^2 \le -x\). Since \(e^t\) is increasing:

\[0 \lt e^{-x^2} \le e^{-x}\quad\text{for } x \ge 1\]

Step 2. Show the bigger integral converges.

\[\int_1^\infty e^{-x}\,dx = \lim_{b\to\infty}\Big[-e^{-x}\Big]_1^b = \lim_{b\to\infty}\left(-e^{-b} + e^{-1}\right) = \frac1e\]

Step 3. Apply the Comparison Test: the smaller nonnegative function has a smaller area, and \(\frac1e\) is finite.

Answer: \(\boxed{\int_1^\infty e^{-x^2}\,dx \text{ converges}}\) (and its value is less than \(\frac1e \approx 0.368\)).

Check: Numerically, \(\int_1^\infty e^{-x^2}\,dx \approx 0.1394\), which is indeed less than 0.368. ✓ (Figure 8.4)
