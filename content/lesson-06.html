7.1Integration by Parts

In our past modules, every rule of differentiation gave us a rule of integration. The Chain Rule gave us the substitution rule. So the natural question is: what does the Product Rule give us? The answer is integration by parts.

Recall the Product Rule: \(\frac{d}{dx}\big[f(x)g(x)\big] = f'(x)g(x) + f(x)g'(x)\). If we integrate both sides and move one term to the other side, we get the formula for integration by parts:

Integration by parts\[\int f(x)\,g'(x)\,dx = f(x)\,g(x) - \int g(x)\,f'(x)\,dx \qquad (1)\] However, it is easier to remember if we let \(u = f(x)\) and \(v = g(x)\). Their differentials are \(du = f'(x)\,dx\) and \(dv = g'(x)\,dx\). Therefore, equation (1) becomes \[\int u\,dv = uv - \int v\,du \qquad (2)\]

What does this formula actually do for us? It is a trade. We give up the integral \(\int u\,dv\), which we cannot do, in exchange for \(\int v\,du\), which we hope is easier. The trade is only worth it if the new integral is simpler than the old one.

Example Let's evaluate \(\int x e^{2x}\,dx\) with \(u = x\) and \(dv = e^{2x}\,dx\). Then \(du = dx\) and \(v = \tfrac12 e^{2x}\). Using equation (2), our integral becomes \[\int x e^{2x}\,dx = \tfrac12 x e^{2x} - \int \tfrac12 e^{2x}\,dx = \tfrac12 x e^{2x} - \tfrac14 e^{2x} + C.\] Notice that the \(x\) disappeared in the new integral. That is exactly why the trade worked.

How do we choose \(u\)? In choosing your \(u\), you need to remember the LIATE acronym. Go down the list, and the first type of function you see becomes your \(u\); everything else (including \(dx\)) is your \(dv\).

LIATE Logarithmic function (\(\ln x\)) → Inverse (trigonometric) function (\(\tan^{-1}x\), \(\sin^{-1}x\)) → Algebraic function (\(x\), \(x^2+1\)) → Trigonometric function (\(\sin x\), \(\cos 5x\)) → Exponential function (\(e^{2x}\)).

In the example above, we have an \(x\), which is an algebraic function, and \(e^{2x}\), which is an exponential function. Since A comes before E, we let \(u = x\). Why does LIATE work? Functions near the top of the list become simpler when we differentiate them (the derivative of \(\ln t\) is \(1/t\)), while functions near the bottom are easy to integrate (\(e^{2x}\) stays an exponential). Take note that LIATE is a guide, not a law. For \(\int \ln x\,dx\) there is only one factor, so we take \(u = \ln x\) and \(dv = dx\): \(\int \ln x\,dx = x\ln x - \int x\cdot\tfrac1x\,dx = x\ln x - x + C\) (Figure 6.2).

Repeated parts and the tabular method. Sometimes one round is not enough. For \(\int x^2 e^{x}\,dx\), the first round leaves \(\int 2x e^{x}\,dx\), so we integrate by parts again. A neat way to keep track is the tabular method: list \(u\) and its derivatives in one column (\(x^2,\ 2x,\ 2,\ 0\)) and \(dv\) and its antiderivatives in another (\(e^x,\ e^x,\ e^x,\ e^x\)), then multiply along the diagonals with alternating signs \(+,-,+\): \(\int x^2e^x\,dx = e^x(x^2 - 2x + 2) + C\).

When the integral comes back. If we try \(I = \int e^x\sin x\,dx\), two rounds of parts give us \(I = e^x\sin x - e^x\cos x - I\). We do not go around in circles. We just solve for \(I\): \(2I = e^x(\sin x - \cos x)\), so \(I = \tfrac12 e^x(\sin x - \cos x) + C\).

Definite integrals and reduction formulas. For definite integrals, evaluate the \(uv\) part at the limits too: \(\int_a^b u\,dv = \big[uv\big]_a^b - \int_a^b v\,du\). For example, \(\int_0^2 xe^{-x}\,dx = \big[-xe^{-x}\big]_0^2 + \int_0^2 e^{-x}\,dx = 1 - 3e^{-2}\) (Figure 6.1). Integration by parts can also lower a power by one each time. Using \(u = \sin^{n-1}x\) and \(dv = \sin x\,dx\), we get the reduction formula \[\int \sin^n x\,dx = -\frac1n\cos x\,\sin^{n-1}x + \frac{n-1}{n}\int \sin^{n-2}x\,dx,\] and on the interval \([0, \pi/2]\) the first term vanishes, so \(\int_0^{\pi/2}\sin^n x\,dx = \frac{n-1}{n}\int_0^{\pi/2}\sin^{n-2}x\,dx\). You will use this in Example 6.5.

Common mistake Forgetting the minus sign in \(uv - \int v\,du\), or forgetting to evaluate \(uv\) at the limits in a definite integral. Another one: choosing \(u = e^{2x}\) in \(\int xe^{2x}\,dx\). Try it and you will see that the new integral \(\int \tfrac12 x^2 \cdot 2e^{2x}\,dx\) is worse than the old one.
Key equations
\[ \int u\,dv = uv - \int v\,du \]
\[ \int_a^b u\,dv = \Big[uv\Big]_a^b - \int_a^b v\,du \]
\[ \int_0^{\pi/2}\sin^n x\,dx = \frac{n-1}{n}\int_0^{\pi/2}\sin^{n-2}x\,dx \quad (n \ge 2) \]

7.2Trigonometric Integrals

Now, what if our integrand is made of powers of trigonometric functions, like \(\int \cos^5 x\sin^2 x\,dx\)? None of our basic formulas apply directly. The trick is to use trigonometric identities so that a substitution \(u = \sin x\) or \(u = \cos x\) (or \(u = \tan x\), \(u = \sec x\)) works.

Strategy for evaluating \(\int \sin^m x\cos^n x\,dx\).

Strategy for sine and cosine (a) If the power of cosine is odd \((n = 2k+1)\), save one cosine factor and use \(\cos^2 x = 1 - \sin^2 x\) to express the remaining factors in terms of sine: \[\int \sin^m x\cos^{2k+1}x\,dx = \int \sin^m x\,(1 - \sin^2 x)^k\cos x\,dx \qquad (3)\] Then substitute \(u = \sin x\).
(b) If the power of sine is odd \((m = 2k+1)\), save one sine factor and use \(\sin^2 x = 1 - \cos^2 x\): \[\int \sin^{2k+1}x\cos^n x\,dx = \int (1 - \cos^2 x)^k\cos^n x\,\sin x\,dx \qquad (4)\] Then substitute \(u = \cos x\). If both powers are odd, either (a) or (b) can be used.
(c) If the powers of both are even, use the half-angle identities \[\sin^2 x = \tfrac12(1 - \cos 2x),\qquad \cos^2 x = \tfrac12(1 + \cos 2x) \qquad (5)\] It is sometimes helpful to use \(\sin x\cos x = \tfrac12\sin 2x\) (6).
Example Let's evaluate \(\int \sin^5 x\cos^2 x\,dx\). The power of sine is odd, so we save one \(\sin x\) and write \(\sin^4 x = (\sin^2 x)^2 = (1 - \cos^2 x)^2\). With \(u = \cos x\), \(du = -\sin x\,dx\): \[\int (1 - \cos^2 x)^2\cos^2 x\,\sin x\,dx = -\int (1-u^2)^2u^2\,du = -\int (u^2 - 2u^4 + u^6)\,du = -\frac{\cos^3 x}{3} + \frac{2\cos^5 x}{5} - \frac{\cos^7 x}{7} + C.\]

Now what if both powers are even? Let's take \(\int \sin^2 x\,dx\). Rewriting \(\sin^2 x\) as \(1 - \cos^2 x\) will not help us at all, because we just traded one even power for another. However, if we use the half-angle identity, then \[\int \sin^2 x\,dx = \frac12\int(1 - \cos 2x)\,dx = \frac12 x - \frac14\sin 2x + C.\] Figure 6.4 shows why this works: \(\sin^2 x\) is just a cosine wave of double frequency that oscillates around the value \(\tfrac12\).

Strategy for evaluating \(\int \tan^m x\sec^n x\,dx\). The same idea works, with the identity \(\sec^2 x = 1 + \tan^2 x\) and the derivatives \(\frac{d}{dx}\tan x = \sec^2 x\), \(\frac{d}{dx}\sec x = \sec x\tan x\).

Strategy for tangent and secant (a) If the power of secant is even \((n = 2k,\ k \ge 2)\), save a factor of \(\sec^2 x\) and use \(\sec^2 x = 1 + \tan^2 x\) to express the remaining factors in terms of \(\tan x\). Then substitute \(u = \tan x\).
(b) If the power of tangent is odd \((m = 2k+1)\), save a factor of \(\sec x\tan x\) and use \(\tan^2 x = \sec^2 x - 1\): \[\int \tan^{2k+1}x\sec^n x\,dx = \int (\sec^2 x - 1)^k\sec^{n-1}x\,\sec x\tan x\,dx \qquad (7)\] Then substitute \(u = \sec x\), \(du = \sec x\tan x\,dx\).
Example For \(\int \tan^3 x\sec x\,dx\), the power of tangent is odd. We rewrite the integrand as \(\tan^2 x\,(\sec x\tan x) = (\sec^2 x - 1)\sec x\tan x\). With \(u = \sec x\): \[\int (u^2 - 1)\,du = \frac{u^3}{3} - u + C = \frac13\sec^3 x - \sec x + C.\]

Some important notes. Two integrals come up again and again, so keep them in your notes: \(\int \tan x\,dx = \ln|\sec x| + C\) and \(\int \sec x\,dx = \ln|\sec x + \tan x| + C\). For products with different angles, use the product-to-sum identities:

Key equations
\[ \sin A\cos B = \tfrac12\big[\sin(A - B) + \sin(A + B)\big] \]
\[ \sin A\sin B = \tfrac12\big[\cos(A - B) - \cos(A + B)\big] \]
\[ \cos A\cos B = \tfrac12\big[\cos(A - B) + \cos(A + B)\big] \]
\[ \int \tan x\,dx = \ln|\sec x| + C,\qquad \int \sec x\,dx = \ln|\sec x + \tan x| + C \]
Common mistake Substituting \(u = \sin x\) without saving a factor of \(\cos x\,dx\). The substitution only works when \(du\) is actually present in the integrand. Also, when you substitute \(u = \cos x\), remember that \(du = -\sin x\,dx\); the minus sign is easy to lose.

★Key takeaways

  • Integration by parts comes from the Product Rule: \(\int u\,dv = uv - \int v\,du\). It trades one integral for another, so the new one must be simpler.
  • Use LIATE (Logarithmic, Inverse, Algebraic, Trigonometric, Exponential) to choose \(u\); the rest is \(dv\).
  • For a polynomial times \(e^{ax}\), \(\sin ax\) or \(\cos ax\), repeat parts (or use the tabular method) until the polynomial is gone.
  • If the original integral comes back after two rounds, solve the equation for it.
  • For \(\sin^m x\cos^n x\): save one factor of the odd power and substitute; if both powers are even, use the half-angle identities.
  • For \(\tan^m x\sec^n x\): even secant → save \(\sec^2 x\), \(u = \tan x\); odd tangent → save \(\sec x\tan x\), \(u = \sec x\).
  • Products with different angles, like \(\sin 3x\cos x\), become sums with the product-to-sum identities.

Example 6.1 Integration by parts with a trigonometric factor

Evaluate \(\displaystyle\int x\cos 5x\,dx\).

(From the instructor's module)
Show solution (try it first)

Given: \(\int x\cos 5x\,dx\), a product of an algebraic function and a trigonometric function.

Plan: Following LIATE, the algebraic function \(x\) comes before the trigonometric function, so we let \(u = x\) and \(dv = \cos 5x\,dx\). Then we use \(\int u\,dv = uv - \int v\,du\).

Step 1. Identify \(u\), \(du\), \(dv\) and \(v\). To integrate \(\cos 5x\), let \(t = 5x\), \(dt = 5\,dx\), so \(dx = \tfrac15 dt\) and \(\int \cos 5x\,dx = \tfrac15\int\cos t\,dt = \tfrac15\sin 5x\).

\[u = x,\quad du = dx,\qquad dv = \cos 5x\,dx,\quad v = \tfrac15\sin 5x\]

Step 2. Substitute into equation (2).

\[\int x\cos 5x\,dx = x\cdot\tfrac15\sin 5x - \int \tfrac15\sin 5x\,dx\]

Step 3. Integrate the remaining integral the same way we obtained \(v\): \(\int \sin 5x\,dx = -\tfrac15\cos 5x\). Be careful with the two minus signs.

\[= \tfrac{x}{5}\sin 5x - \tfrac15\left(-\tfrac15\cos 5x\right) + C = \tfrac{x}{5}\sin 5x + \tfrac{1}{25}\cos 5x + C\]

Answer: \(\boxed{\displaystyle\int x\cos 5x\,dx = \frac{x}{5}\sin 5x + \frac{1}{25}\cos 5x + C}\). That is our answer.

Check: Differentiate the answer: \(\frac{d}{dx}\left[\tfrac{x}{5}\sin 5x\right] = \tfrac15\sin 5x + x\cos 5x\) and \(\frac{d}{dx}\left[\tfrac1{25}\cos 5x\right] = -\tfrac15\sin 5x\). The sine terms cancel, leaving \(x\cos 5x\). ✓

Example 6.2 A logarithm times a power

Evaluate \(\displaystyle\int t^4\ln t\,dt\).

(From the instructor's module)
Show solution (try it first)

Given: \(\int t^4\ln t\,dt\): a logarithmic function times an algebraic function.

Plan: L comes first in LIATE, so we let \(u = \ln t\). This is also the only sensible choice, because we do not know how to integrate \(\ln t\) yet, but we can easily integrate \(t^4\).

Step 1. Identify the parts.

\[u = \ln t,\quad du = \tfrac1t\,dt,\qquad dv = t^4\,dt,\quad v = \tfrac15 t^5\]

Step 2. Substitute into \(\int u\,dv = uv - \int v\,du\).

\[\int t^4\ln t\,dt = \tfrac15 t^5\ln t - \int \tfrac15 t^5\cdot\tfrac1t\,dt\]

Step 3. Simplify the new integrand: \(t^5\cdot\frac1t = t^4\). The logarithm is gone, so this integral is easy.

\[= \tfrac15 t^5\ln t - \tfrac15\int t^4\,dt = \tfrac15 t^5\ln t - \tfrac15\cdot\tfrac15 t^5 + C\]

Answer: \(\boxed{\displaystyle\int t^4\ln t\,dt = \frac15 t^5\ln t - \frac1{25}t^5 + C}\).

Check: \(\frac{d}{dt}\left[\tfrac15t^5\ln t - \tfrac1{25}t^5\right] = t^4\ln t + \tfrac15t^4 - \tfrac15t^4 = t^4\ln t\). ✓

Example 6.3 Odd power of cosine

Evaluate \(\displaystyle\int\cos^5 x\sin^2 x\,dx\).

(From the instructor's module)
Show solution (try it first)

Given: \(\int\cos^5x\sin^2x\,dx\): the power of cosine (5) is odd.

Plan: Use strategy (a): save one \(\cos x\), turn the remaining \(\cos^4 x\) into sines with \(\cos^2 x = 1 - \sin^2 x\), then let \(u = \sin x\).

Step 1. Split off one cosine factor and rewrite \(\cos^4 x = (\cos^2 x)^2\).

\[\int\cos^5x\sin^2x\,dx = \int(\cos^2x)^2\sin^2x\,\cos x\,dx = \int(1-\sin^2x)^2\sin^2x\,\cos x\,dx\]

Step 2. Let \(u = \sin x\), so \(du = \cos x\,dx\). The saved \(\cos x\,dx\) is exactly \(du\).

\[= \int(1-u^2)^2u^2\,du\]

Step 3. Expand \((1-u^2)^2 = 1 - 2u^2 + u^4\) and multiply by \(u^2\).

\[= \int(u^2 - 2u^4 + u^6)\,du\]

Step 4. Integrate term by term with the power rule.

\[= \frac{u^3}{3} - \frac{2u^5}{5} + \frac{u^7}{7} + C\]

Step 5. Substitute back \(u = \sin x\).

\[= \frac{\sin^3x}{3} - \frac{2\sin^5x}{5} + \frac{\sin^7x}{7} + C\]

Answer: \(\boxed{\displaystyle\int\cos^5x\sin^2x\,dx = \frac{\sin^3x}{3} - \frac{2\sin^5x}{5} + \frac{\sin^7x}{7} + C}\).

Check: Differentiating gives \(\cos x\,(\sin^2x - 2\sin^4x + \sin^6x) = \cos x\sin^2x(1-\sin^2x)^2 = \cos^5x\sin^2x\). ✓

Example 6.4 Even power of secant

Evaluate \(\displaystyle\int\tan^6x\sec^4x\,dx\).

(From the instructor's module)
Show solution (try it first)

Given: \(\int\tan^6x\sec^4x\,dx\): the power of secant (4) is even.

Plan: Save a factor of \(\sec^2x\) (it will become \(du\)), write the other \(\sec^2x\) as \(1 + \tan^2x\), and let \(u = \tan x\).

Step 1. Save \(\sec^2 x\) and use \(\sec^2x = 1 + \tan^2x\) on the rest.

\[\int\tan^6x\sec^4x\,dx = \int\tan^6x\,\sec^2x\,\sec^2x\,dx = \int\tan^6x\,(1+\tan^2x)\,\sec^2x\,dx\]

Step 2. Let \(u = \tan x\), \(du = \sec^2x\,dx\).

\[= \int u^6(1+u^2)\,du = \int(u^6 + u^8)\,du\]

Step 3. Integrate and substitute back.

\[= \frac{u^7}{7} + \frac{u^9}{9} + C = \frac{\tan^7x}{7} + \frac{\tan^9x}{9} + C\]

Answer: \(\boxed{\displaystyle\int\tan^6x\sec^4x\,dx = \frac{\tan^7x}{7} + \frac{\tan^9x}{9} + C}\).

Check: The derivative is \((\tan^6x + \tan^8x)\sec^2x = \tan^6x(1+\tan^2x)\sec^2x = \tan^6x\sec^4x\). ✓

Example 6.5 Using the reduction formula for sine

Use \(\displaystyle\int_0^{\pi/2}\sin^n x\,dx = \frac{n-1}{n}\int_0^{\pi/2}\sin^{n-2}x\,dx\) to evaluate (a) \(\displaystyle\int_0^{\pi/2}\sin^3x\,dx\) and (b) \(\displaystyle\int_0^{\pi/2}\sin^5x\,dx\).

(From the instructor's module)
Show solution (try it first)

Given: The reduction formula on \([0,\pi/2]\), valid for integers \(n \ge 2\).

Plan: Apply the formula repeatedly until the power is 1, then use \(\int_0^{\pi/2}\sin x\,dx = \big[-\cos x\big]_0^{\pi/2} = 0 - (-1) = 1\).

Step 1. (a) Use the formula with \(n = 3\).

\[\int_0^{\pi/2}\sin^3x\,dx = \frac{2}{3}\int_0^{\pi/2}\sin x\,dx = \frac23(1) = \frac23\]

Step 2. (b) Use the formula with \(n = 5\). This lowers the power to 3.

\[\int_0^{\pi/2}\sin^5x\,dx = \frac45\int_0^{\pi/2}\sin^3x\,dx\]

Step 3. Now use the result of part (a).

\[= \frac45\cdot\frac23 = \frac{8}{15}\]

Answer: (a) \(\boxed{\tfrac23}\) and (b) \(\boxed{\tfrac{8}{15}}\). Notice the pattern \(\frac{2}{3}\), \(\frac{2\cdot4}{3\cdot5}\): for odd powers, \(\int_0^{\pi/2}\sin^{2n+1}x\,dx = \frac{2\cdot4\cdot6\cdots2n}{3\cdot5\cdot7\cdots(2n+1)}\).

Check: For (a) we can also use strategy (b): \(\int_0^{\pi/2}(1-\cos^2x)\sin x\,dx = \big[-\cos x + \tfrac13\cos^3x\big]_0^{\pi/2} = 0 - \left(-1 + \tfrac13\right) = \tfrac23\). ✓ Both answers are less than 1, which makes sense because \(0 \le \sin^n x \le 1\) on an interval of length \(\pi/2 \approx 1.57\).
