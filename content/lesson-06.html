7.1Integration by Parts

Every differentiation rule gives you an integration rule. The Chain Rule gave you substitution; the Product Rule gives you integration by parts. Start from \((fg)' = f'g + fg'\), integrate both sides and rearrange: \(\int f(x)g'(x)\,dx = f(x)g(x) - \int g(x)f'(x)\,dx\). With \(u = f(x)\) and \(dv = g'(x)\,dx\) this becomes the compact form in Stewart §7.1:

\[\int u\,dv = uv - \int v\,du.\]

The idea is a trade: you give up the integral of \(u\,dv\) in exchange for the integral of \(v\,du\). The trade is worth it only when the new integral is simpler. For \(\int x\cos 3x\,dx\), take \(u = x\) (so \(du = dx\)) and \(dv = \cos 3x\,dx\) (so \(v = \tfrac13\sin 3x\)). Then \(\int x\cos 3x\,dx = \tfrac13 x\sin 3x - \int \tfrac13\sin 3x\,dx = \tfrac13 x\sin 3x + \tfrac19\cos 3x + C\). The power of \(x\) disappeared, which is exactly what you wanted.

LIATE rule To choose \(u\), go down the list Logarithmic (\(\ln x\)), Inverse trigonometric (\(\tan^{-1}x\), \(\sin^{-1}x\)), Algebraic (\(x^2\), \(3x+1\)), Trigonometric (\(\sin x\), \(\cos x\)), Exponential (\(e^{x}\)). The factor that appears first becomes \(u\); the rest is \(dv\). Functions near the top get simpler when differentiated; functions near the bottom are easy to integrate.

LIATE is a guide, not a law, but it explains some surprises. In \(\int \ln x\,dx\) there is only one factor, so take \(u = \ln x\) and \(dv = dx\): you get \(x\ln x - \int x\cdot\tfrac1x\,dx = x\ln x - x + C\).

Repeated parts and the tabular method. For \(\int x^2 e^{x}\,dx\) one round of parts leaves \(\int 2x e^{x}\,dx\), so you apply parts again. A neat bookkeeping device is the tabular method: list \(u\) and its derivatives down one column (\(x^2,\ 2x,\ 2,\ 0\)) and \(dv\) and its antiderivatives down another (\(e^x,\ e^x,\ e^x,\ e^x\)). Multiply along diagonals with alternating signs \(+,-,+\): \(\int x^2e^x\,dx = e^x(x^2 - 2x + 2) + C\). It works whenever \(u\) is a polynomial that eventually differentiates to zero.

When the integral comes back. For \(\int e^x\sin x\,dx\), two rounds of parts return the original integral \(I\) with a minus sign: \(I = e^x\sin x - e^x\cos x - I\). Do not keep going in circles; solve the equation for \(I\): \(I = \tfrac12 e^x(\sin x - \cos x) + C\).

Definite integrals. Evaluate the \(uv\) part between the limits too: \(\int_a^b u\,dv = \big[uv\big]_a^b - \int_a^b v\,du\). For instance, \(\int_0^2 xe^{-x}\,dx = \big[-xe^{-x}\big]_0^2 + \int_0^2 e^{-x}\,dx = 1 - 3e^{-2}\) (Figure 6.1).

Reduction formulas. Sometimes parts lowers a power by one, giving a formula you can reuse. With \(u = (\ln x)^n\) and \(dv = dx\), \(\int(\ln x)^n\,dx = x(\ln x)^n - n\int(\ln x)^{n-1}\,dx\). Apply it again and again until the power reaches zero.

Common mistake Forgetting the minus sign in \(uv - \int v\,du\), or forgetting to evaluate \(uv\) at the limits in a definite integral.
Key equations
\[ \int u\,dv = uv - \int v\,du \]
\[ \int_a^b f(x)g'(x)\,dx = \Big[f(x)g(x)\Big]_a^b - \int_a^b g(x)f'(x)\,dx \]
\[ \int (\ln x)^n\,dx = x(\ln x)^n - n\int (\ln x)^{n-1}\,dx \]

7.2Trigonometric Integrals

Stewart §7.2 handles integrals built from powers of trigonometric functions. The plan is always the same: use an identity so that the integral becomes a polynomial in one function multiplied by that function's derivative, then substitute.

Powers of sine and cosine, \(\int \sin^m x\cos^n x\,dx\).

  • Power of cosine odd: save one \(\cos x\) factor for \(du\), write the remaining even power with \(\cos^2 x = 1 - \sin^2 x\), and let \(u = \sin x\). Example: \(\int \sin^2 x\cos^3 x\,dx = \int \sin^2 x(1-\sin^2 x)\cos x\,dx = \tfrac13\sin^3 x - \tfrac15\sin^5 x + C\).
  • Power of sine odd: save one \(\sin x\), use \(\sin^2 x = 1 - \cos^2 x\), and let \(u = \cos x\) (watch the sign, since \(du = -\sin x\,dx\)). Example: \(\int_0^{\pi}\sin^3 x\,dx = 4/3\) (Figure 6.2).
  • Both powers even: no factor can be spared, so lower the powers with the half-angle identities \(\sin^2 x = \tfrac12(1-\cos 2x)\), \(\cos^2 x = \tfrac12(1+\cos 2x)\), and \(\sin x\cos x = \tfrac12\sin 2x\). Example: \(\int_0^{\pi}\sin^2 x\,dx = \int_0^{\pi}\tfrac12(1-\cos 2x)\,dx = \pi/2\).

Why does this work? Because \(\sin x\) and \(\cos x\) are each other's derivatives (up to sign), so one spare factor is exactly the \(du\) a substitution needs. If both powers are odd, either choice works; pick the one with the smaller odd power to save work. And when the half-angle identity leaves you with \(\cos^2 2x\), simply apply it a second time: \(\cos^4 x = \tfrac14(1+\cos 2x)^2\) leads to \(\int\cos^4 x\,dx = \tfrac38x + \tfrac14\sin 2x + \tfrac1{32}\sin 4x + C\).

Powers of tangent and secant, \(\int \tan^m x\sec^n x\,dx\). Here the useful facts are \(\tfrac{d}{dx}\tan x = \sec^2 x\), \(\tfrac{d}{dx}\sec x = \sec x\tan x\) and \(\tan^2 x = \sec^2 x - 1\).

  • Power of secant even (\(n \ge 2\)): save \(\sec^2 x\), convert the rest to tangents, and let \(u = \tan x\).
  • Power of tangent odd: save \(\sec x\tan x\), convert the remaining even power of tangent to secants, and let \(u = \sec x\). Example: \(\int\tan^3 x\sec^3 x\,dx = \int(\sec^2 x - 1)\sec^2 x\,(\sec x\tan x)\,dx = \tfrac15\sec^5 x - \tfrac13\sec^3 x + C\).

If neither pattern fits, for example \(\int\tan^2 x\,dx\) or \(\int\tan^4 x\,dx\), use \(\tan^2 x = \sec^2 x - 1\) to peel off pieces you can integrate: \(\int\tan^2 x\,dx = \int(\sec^2 x - 1)\,dx = \tan x - x + C\). Odd powers of secant alone, such as \(\int\sec^3 x\,dx\), are handled by integration by parts from §7.1. Keep two results handy: \(\int\tan x\,dx = \ln|\sec x| + C\) and \(\int\sec x\,dx = \ln|\sec x + \tan x| + C\).

Products with different angles. For \(\int\sin 5x\cos 2x\,dx\) use a product-to-sum identity:

  • \(\sin A\cos B = \tfrac12[\sin(A-B) + \sin(A+B)]\)
  • \(\sin A\sin B = \tfrac12[\cos(A-B) - \cos(A+B)]\)
  • \(\cos A\cos B = \tfrac12[\cos(A-B) + \cos(A+B)]\)

So \(\int\sin 5x\cos 2x\,dx = \tfrac12\int(\sin 3x + \sin 7x)\,dx = -\tfrac16\cos 3x - \tfrac1{14}\cos 7x + C\). You do not need to memorise these three: each one comes from adding or subtracting two addition formulas, such as \(\sin(A+B) = \sin A\cos B + \cos A\sin B\) and \(\sin(A-B) = \sin A\cos B - \cos A\sin B\).

Common mistake Writing \(\int\sin^2 x\,dx = \tfrac13\sin^3 x + C\). That would need a \(\cos x\) factor that is not there. Use the half-angle identity instead.
Key equations
\[ \sin^2 x = \tfrac12(1 - \cos 2x), \qquad \cos^2 x = \tfrac12(1 + \cos 2x) \]
\[ \tan^2 x = \sec^2 x - 1 \]
\[ \int \sec x\,dx = \ln|\sec x + \tan x| + C \]
\[ \sin A\cos B = \tfrac12[\sin(A-B) + \sin(A+B)] \]

★Key takeaways

  • Integration by parts, ∫u dv = uv − ∫v du, is the Product Rule run backwards; use it when the new integral ∫v du is simpler than the original.
  • LIATE (Logarithmic, Inverse trig, Algebraic, Trigonometric, Exponential) tells you which factor to choose as u.
  • For a polynomial times e^x, sin x or cos x, the tabular method organises repeated integration by parts; if the original integral reappears, solve for it algebraically.
  • For sin^m x cos^n x, save one factor of the odd power and substitute; if both powers are even, use half-angle identities.
  • For tan^m x sec^n x, save sec²x when the secant power is even, or save sec x tan x when the tangent power is odd.
  • Products such as sin 5x cos 2x become sums with the product-to-sum identities.

Example 6.1 A logarithm times a power, over [1, e]

Evaluate \(\displaystyle\int_1^{e} x^2\ln x\,dx\).

(Similar to Stewart §7.1, Example 5)
Show solution (try it first)

Strategy:

LIATE puts the logarithm first, so let \(u = \ln x\) and \(dv = x^2\,dx\). Then \(du = \dfrac{1}{x}\,dx\) and \(v = \dfrac{x^3}{3}\). Choosing \(u = x^2\) instead would force you to integrate \(\ln x\) times something, which is worse.

Solution:

\[\int_1^e x^2\ln x\,dx = \Big[\frac{x^3}{3}\ln x\Big]_1^e - \int_1^e \frac{x^3}{3}\cdot\frac{1}{x}\,dx = \frac{e^3}{3} - 0 - \frac13\int_1^e x^2\,dx.\]

The remaining integral is \(\tfrac13\cdot\tfrac{e^3-1}{3} = \tfrac{e^3-1}{9}\). So the answer is

\[\frac{e^3}{3} - \frac{e^3 - 1}{9} = \frac{2e^3 + 1}{9} \approx 4.575.\]

Check:

The antiderivative is \(F(x) = \tfrac13x^3\ln x - \tfrac19x^3\). Differentiate: \(F'(x) = x^2\ln x + \tfrac13x^2 - \tfrac13x^2 = x^2\ln x\). Also, on \([1,e]\) the integrand lies between 0 and \(e^2 \approx 7.4\), and the interval has length about 1.7, so a value near 4.6 is reasonable.

Example 6.2 The integral that comes back

Find \(\displaystyle\int e^{2x}\cos x\,dx\).

(Similar to Stewart §7.1, Example 4)
Show solution (try it first)

Strategy:

Neither factor gets simpler when differentiated, so parts will not finish in one step. Apply parts twice, keeping the same type of choice (\(u\) = trigonometric each time), and the original integral \(I\) will reappear. Then solve for \(I\).

Solution:

Let \(I = \int e^{2x}\cos x\,dx\). First round: \(u = \cos x\), \(dv = e^{2x}\,dx\), so \(du = -\sin x\,dx\), \(v = \tfrac12e^{2x}\):

\[I = \tfrac12e^{2x}\cos x + \tfrac12\int e^{2x}\sin x\,dx.\]

Second round: \(u = \sin x\), \(dv = e^{2x}\,dx\): \(\int e^{2x}\sin x\,dx = \tfrac12e^{2x}\sin x - \tfrac12 I\). Substituting,

\[I = \tfrac12e^{2x}\cos x + \tfrac14e^{2x}\sin x - \tfrac14 I.\]

Add \(\tfrac14 I\) to both sides: \(\tfrac54 I = \tfrac14e^{2x}(2\cos x + \sin x)\), so

\[\int e^{2x}\cos x\,dx = \frac{e^{2x}(2\cos x + \sin x)}{5} + C.\]

Check:

Differentiate: \(\tfrac15\big[2e^{2x}(2\cos x + \sin x) + e^{2x}(-2\sin x + \cos x)\big] = \tfrac15e^{2x}(5\cos x) = e^{2x}\cos x\). Note: if you switch to \(u = e^{2x}\) in the second round, you undo the first round and get the useless identity \(I = I\).

Example 6.3 Tangent and secant over [0, π/4]

Evaluate \(\displaystyle\int_0^{\pi/4}\tan^2 x\sec^4 x\,dx\).

(Similar to Stewart §7.2, Example 5)
Show solution (try it first)

Strategy:

The power of secant is even, so save \(\sec^2 x\) as \(du\) for \(u = \tan x\) and turn the other \(\sec^2 x\) into \(1 + \tan^2 x\).

Solution:

\[\int_0^{\pi/4}\tan^2 x\,(1 + \tan^2 x)\sec^2 x\,dx.\]

With \(u = \tan x\), \(du = \sec^2 x\,dx\); the limits change from \(x = 0, \pi/4\) to \(u = 0, 1\):

\[\int_0^1 (u^2 + u^4)\,du = \Big[\frac{u^3}{3} + \frac{u^5}{5}\Big]_0^1 = \frac13 + \frac15 = \frac{8}{15}.\]

Check:

The integrand is 0 at \(x = 0\) and \(1\cdot 4 = 4\) at \(x = \pi/4 \approx 0.785\), rising steeply at the end, so the area should be well below \(4 \times 0.785/2 \approx 1.6\). The value \(8/15 \approx 0.533\) fits. Remember to change the limits when you substitute, or else substitute back before evaluating.
