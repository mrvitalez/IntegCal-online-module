11.1Sequences

A sequence is an infinite list of numbers written in a definite order: \(a_1, a_2, a_3, \ldots\). We write it as \(\{a_n\}\) or \(\{a_n\}_{n=1}^{\infty}\). Very often a sequence is given by a formula for its general term, such as \(a_n = \dfrac{2n+1}{n+3}\), whose first terms are \(\tfrac34, 1, \tfrac76, \tfrac97, \ldots\). You can think of a sequence as a function whose domain is the positive integers, so its graph is a set of isolated dots, not a curve (Figure 13.1).

Definition The sequence \(\{a_n\}\) has limit \(L\), written \(\lim_{n\to\infty} a_n = L\), if the terms \(a_n\) can be made as close to \(L\) as we like by taking \(n\) large enough. If the limit exists, the sequence converges; otherwise it diverges.

How do you actually compute such limits? The most useful fact (Stewart §11.1) is this: if \(f\) is a function with \(\lim_{x\to\infty} f(x) = L\) and \(f(n) = a_n\) for every integer \(n\), then \(\lim_{n\to\infty} a_n = L\). This lets you use all your tools for functions, including l'Hospital's Rule. For example, to find \(\lim \dfrac{\ln n}{\sqrt n}\), look at \(\dfrac{\ln x}{\sqrt x}\); l'Hospital gives \(\dfrac{1/x}{1/(2\sqrt x)} = \dfrac{2}{\sqrt x} \to 0\), so the sequence converges to 0.

The usual limit laws (sums, products, quotients, constant multiples) work for sequences, and so does the Squeeze Theorem: if \(b_n \le a_n \le c_n\) and both \(b_n\) and \(c_n\) approach \(L\), then so does \(a_n\). A handy consequence: if \(\lim |a_n| = 0\), then \(\lim a_n = 0\). This handles sequences like \(\dfrac{(-1)^n}{n^2}\) or \(\dfrac{\cos n}{n}\), which jump back and forth while shrinking.

A very important family is \(\{r^n\}\). It converges to 0 when \(-1 < r < 1\), converges to 1 when \(r = 1\), and diverges for every other \(r\). You will meet \(r^n\) again in every geometric series.

A sequence is increasing if \(a_n < a_{n+1}\) for all \(n\), decreasing if \(a_n > a_{n+1}\), and monotonic if it is one or the other. It is bounded if there are numbers \(m\) and \(M\) with \(m \le a_n \le M\) for all \(n\). The Monotonic Sequence Theorem says that every bounded, monotonic sequence converges. It is the reason many recursively defined sequences have limits even when we cannot write a formula for \(a_n\).

Common mistake Do not confuse a sequence with a series. The sequence \(a_n = \tfrac1n\) converges (to 0), but adding its terms, \(1 + \tfrac12 + \tfrac13 + \cdots\), gives a series that diverges. Section 11.2 explains why.
Key equations
\[ \lim_{x\to\infty} f(x) = L \text{ and } f(n)=a_n \;\Longrightarrow\; \lim_{n\to\infty} a_n = L \]
\[ \lim_{n\to\infty} r^n = 0 \quad \text{if } -1 \lt r \lt 1 \]
\[ \lim_{n\to\infty}\left(1+\frac{c}{n}\right)^n = e^{c} \]

11.2Series

If you add the terms of a sequence you get an infinite series, \(\sum_{n=1}^{\infty} a_n = a_1 + a_2 + a_3 + \cdots\). You cannot literally add infinitely many numbers, so we define the sum through the partial sums \(s_n = a_1 + a_2 + \cdots + a_n\). If the sequence \(\{s_n\}\) converges to \(s\), the series converges and its sum is \(s\). If \(\{s_n\}\) diverges, so does the series. In short: a series is a limit of a sequence of partial sums.

Geometric series. The series \(\sum_{n=1}^{\infty} a r^{n-1} = a + ar + ar^2 + \cdots\) (with \(a \ne 0\)) has partial sums \(s_n = \dfrac{a(1-r^n)}{1-r}\). Because \(r^n \to 0\) exactly when \(|r| < 1\), the series converges to \(\dfrac{a}{1-r}\) when \(|r| < 1\) and diverges when \(|r| \ge 1\). Remember: \(a\) is the first term, whatever the starting index. For instance \(\sum_{n=1}^{\infty} 3\left(\tfrac25\right)^{n-1}\) has \(a = 3\), \(r = \tfrac25\), and sum \(\dfrac{3}{1 - 2/5} = 5\) (Figure 13.2).

Telescoping series. Sometimes partial fractions turn each term into a difference, and almost everything cancels. Since \(\dfrac{1}{n(n+1)} = \dfrac1n - \dfrac{1}{n+1}\), the partial sum is \(s_n = 1 - \dfrac{1}{n+1}\), so \(\sum \dfrac{1}{n(n+1)} = 1\). Always write out a few terms to see which pieces survive.

The harmonic series \(\sum \dfrac1n\) diverges, even though its terms go to 0. Grouping terms shows why: \(\tfrac13 + \tfrac14 > \tfrac12\), \(\tfrac15 + \cdots + \tfrac18 > \tfrac12\), and so on, so the partial sums eventually pass any number.

Test for Divergence If \(\lim_{n\to\infty} a_n\) does not exist or is not 0, then \(\sum a_n\) diverges. (Equivalently: if \(\sum a_n\) converges, then \(a_n \to 0\).)
Common mistake The converse is false. \(a_n \to 0\) does not prove convergence; the harmonic series is the standard counterexample. The Test for Divergence can only ever tell you "diverges".

Finally, convergent series can be added, subtracted and multiplied by constants term by term: \(\sum (c\,a_n + b_n) = c\sum a_n + \sum b_n\) when both series converge. Changing or deleting finitely many terms never changes whether a series converges (though it changes the sum).

Key equations
\[ s_n = \sum_{i=1}^{n} a_i, \qquad \sum_{n=1}^{\infty} a_n = \lim_{n\to\infty} s_n \]
\[ \sum_{n=1}^{\infty} a r^{n-1} = \frac{a}{1-r}, \quad |r|\lt 1 \]
\[ \lim_{n\to\infty} a_n \ne 0 \;\Longrightarrow\; \sum a_n \text{ diverges} \]

11.3The Integral Test and Estimates of Sums

For most series we cannot find a formula for \(s_n\), so we need tests that decide convergence without computing the sum. The first one connects series to improper integrals. Picture the terms \(a_n = f(n)\) as rectangles of width 1. If \(f\) is decreasing, the rectangles for \(a_2, a_3, \ldots\) sit under the curve \(y = f(x)\) from \(x = 1\) onward (Figure 13.3), and the rectangles for \(a_1, a_2, \ldots\) placed one step to the left sit above it. So the series and the integral are trapped together.

The Integral Test Suppose \(f\) is continuous, positive and decreasing on \([1, \infty)\) and \(a_n = f(n)\). Then \(\sum_{n=1}^{\infty} a_n\) converges if and only if \(\int_1^{\infty} f(x)\,dx\) converges.

Check all three conditions before you use the test. "Decreasing" only needs to hold eventually (for \(x\) larger than some number), and you usually verify it with \(f'(x) < 0\). Notice the test does not say the sum equals the integral; it only says they converge or diverge together.

p-series. Applying the test to \(f(x) = 1/x^p\) gives one of the most-used facts in the chapter: \(\sum \dfrac{1}{n^p}\) converges if \(p > 1\) and diverges if \(p \le 1\). So \(\sum 1/n^{3}\) and \(\sum 1/n^{1.1}\) converge, while \(\sum 1/\sqrt n\) and the harmonic series diverge.

Estimating the sum. If you stop at \(s_n\), the error is the remainder \(R_n = s - s_n = a_{n+1} + a_{n+2} + \cdots\). The same rectangle picture, started at \(n\), gives

\[ \int_{n+1}^{\infty} f(x)\,dx \;\le\; R_n \;\le\; \int_{n}^{\infty} f(x)\,dx. \]

Adding \(s_n\) to each part traps the true sum: \(s_n + \int_{n+1}^{\infty} f \le s \le s_n + \int_n^{\infty} f\). For \(\sum 1/n^3\) with \(n = 5\): \(s_5 \approx 1.18566\), \(\int_5^\infty x^{-3}dx = \tfrac{1}{50}\) and \(\int_6^\infty x^{-3}dx = \tfrac{1}{72}\), so \(1.1996 \le s \le 1.2057\). Using the midpoint of this interval gives \(s \approx 1.2026\), already very close to the true value \(1.20206\ldots\).

Common mistake The lower limit of the remainder integral is \(n\) (where you stopped), not 1. Using \(\int_1^\infty\) gives a bound for the whole sum, not for the error.
Key equations
\[ \sum_{n=1}^{\infty}\frac{1}{n^p} \text{ converges} \iff p\gt 1 \]
\[ \int_{n+1}^{\infty} f(x)\,dx \le R_n \le \int_{n}^{\infty} f(x)\,dx \]
\[ s_n + \int_{n+1}^{\infty} f(x)\,dx \le s \le s_n + \int_{n}^{\infty} f(x)\,dx \]

11.4The Comparison Tests

The idea of comparison is common sense: a positive series that is smaller than a convergent one must converge, and one that is bigger than a divergent one must diverge. To use it you need a stock of "known" series to compare with, mainly p-series \(\sum 1/n^p\) and geometric series \(\sum ar^{n-1}\).

The Comparison Test Suppose \(a_n \ge 0\) and \(b_n \ge 0\).
(i) If \(\sum b_n\) converges and \(a_n \le b_n\) for all \(n\), then \(\sum a_n\) converges.
(ii) If \(\sum b_n\) diverges and \(a_n \ge b_n\) for all \(n\), then \(\sum a_n\) diverges.

Example: \(\dfrac{1}{n^2 + n} < \dfrac{1}{n^2}\), and \(\sum 1/n^2\) is a convergent p-series, so \(\sum \dfrac{1}{n^2+n}\) converges (Figure 13.4). Likewise \(\dfrac{\ln n}{n} > \dfrac1n\) for \(n \ge 3\), so \(\sum \dfrac{\ln n}{n}\) diverges by comparison with the harmonic series. Bounded factors like \(\sin^2 n\) or \(2 + \cos n\) are also easy to compare away.

Common mistake The inequality has to point the right way. Knowing \(a_n \le b_n\) with \(\sum b_n\) divergent tells you nothing. For example, \(\dfrac{1}{n^2 - 1}\) is slightly larger than \(\dfrac{1}{n^2}\), so the direct comparison with \(\sum 1/n^2\) fails, even though the series does converge.

Cases like that are why we have a second version. To guess the right comparison series, keep only the dominant terms of the numerator and denominator: \(\dfrac{3n^2 + 5}{n^4 - n + 2}\) behaves like \(\dfrac{3n^2}{n^4} = \dfrac{3}{n^2}\) for large \(n\).

The Limit Comparison Test Suppose \(a_n > 0\), \(b_n > 0\) and \(\displaystyle\lim_{n\to\infty} \frac{a_n}{b_n} = c\) where \(c\) is a finite number with \(c > 0\). Then either both series converge or both diverge.

The limit comparison test does not care about the direction of the inequality, only about the long-run ratio. For \(\sum \dfrac{1}{n^2 - 1}\) (starting at \(n = 2\)) take \(b_n = 1/n^2\): the ratio \(\dfrac{n^2}{n^2-1} \to 1\), which is positive and finite, so the series converges. For \(\sum \dfrac{1}{2n + 7}\) take \(b_n = 1/n\): the ratio tends to \(\tfrac12\), so the series diverges with the harmonic series.

Comparison also helps with estimates: if \(a_n \le b_n\), the remainder of \(\sum a_n\) is at most the remainder of \(\sum b_n\), which you can bound with the integral test or a geometric sum.

Key equations
\[ 0 \le a_n \le b_n,\; \sum b_n \text{ converges} \;\Longrightarrow\; \sum a_n \text{ converges} \]
\[ \lim_{n\to\infty}\frac{a_n}{b_n} = c,\; 0\lt c\lt \infty \;\Longrightarrow\; \text{both converge or both diverge} \]

11.5Alternating Series

So far all the terms were positive. An alternating series has terms that switch sign: \(\sum (-1)^{n-1} b_n = b_1 - b_2 + b_3 - b_4 + \cdots\) with every \(b_n > 0\). The classic example is the alternating harmonic series \(1 - \tfrac12 + \tfrac13 - \tfrac14 + \cdots\).

Alternating Series Test If \(b_n > 0\), the terms are decreasing (\(b_{n+1} \le b_n\) for all \(n\)) and \(\lim_{n\to\infty} b_n = 0\), then \(\sum (-1)^{n-1} b_n\) converges.

Why does it work? Each step goes the other way by a smaller amount. Start at \(s_1 = b_1\); subtract \(b_2\), add back a little less, subtract a little less again. The partial sums zigzag, the odd ones coming down and the even ones going up, and since the steps shrink to 0, they close in on a single number (Figure 13.5). Applied to the alternating harmonic series, the test shows it converges, even though the harmonic series itself diverges. (Its sum turns out to be \(\ln 2\), as you will see in Module 14.)

To check "decreasing" you can compare \(b_{n+1}\) and \(b_n\) directly or show \(f'(x) < 0\) where \(b_n = f(n)\). If the limit of \(b_n\) is not 0, do not use this test at all: the Test for Divergence already says the series diverges.

Error estimate. The zigzag picture gives a bonus. The true sum \(s\) always lies between two consecutive partial sums, so the error after \(n\) terms is no bigger than the next step:

\[ |R_n| = |s - s_n| \le b_{n+1}. \]

This is the easiest error bound in the whole chapter: the error is at most the first term you left out. For example, to estimate \(\sum_{n=1}^{\infty} \dfrac{(-1)^{n-1}}{n^4}\) with error less than 0.001, you need \(b_{n+1} = \dfrac{1}{(n+1)^4} < 0.001\), that is \((n+1)^4 > 1000\). Since \(5^4 = 625\) and \(6^4 = 1296\), take \(n + 1 = 6\): five terms are enough, and \(s_5 \approx 0.9475\). The sign of the first omitted term also tells you whether \(s_n\) is too big or too small.

Common mistake The bound \(|R_n| \le b_{n+1}\) is only for alternating series that satisfy the test's conditions. For a positive series, use the integral test bounds from §11.3 instead.
Key equations
\[ b_{n+1}\le b_n,\ \lim_{n\to\infty} b_n = 0 \;\Longrightarrow\; \sum_{n=1}^{\infty} (-1)^{n-1} b_n \text{ converges} \]
\[ |R_n| = |s - s_n| \le b_{n+1} \]

★Key takeaways

  • A sequence converges if its terms approach one number; a series converges if its partial sums do.
  • A geometric series converges to a/(1 − r) exactly when |r| < 1; a p-series converges exactly when p > 1.
  • If the terms do not go to 0 the series diverges, but terms going to 0 never proves convergence (think of the harmonic series).
  • For positive series, compare with p-series or geometric series, directly or through the limit of the ratio a_n/b_n.
  • The integral test bounds the remainder of a positive decreasing series; for an alternating series the error is at most the first omitted term.

Example 13.1 A telescoping sum

Show that \(\displaystyle\sum_{n=1}^{\infty} \frac{4}{n^2 + 4n + 3}\) converges and find its sum.

(Similar to Stewart §11.2, Example 7)
Show solution (try it first)

Strategy:

The terms are rational functions with a factorable denominator, so try partial fractions and look for cancellation in \(s_n\).

Solution:

Factor: \(n^2 + 4n + 3 = (n+1)(n+3)\), and \(\dfrac{4}{(n+1)(n+3)} = \dfrac{2}{n+1} - \dfrac{2}{n+3}\). Write out the partial sum:

\[ s_n = \left(\tfrac22 - \tfrac24\right) + \left(\tfrac23 - \tfrac25\right) + \left(\tfrac24 - \tfrac26\right) + \cdots + \left(\tfrac{2}{n+1} - \tfrac{2}{n+3}\right). \]

Each negative piece cancels a positive piece two steps later, so only the first two positive pieces and the last two negative pieces survive:

\[ s_n = 1 + \frac23 - \frac{2}{n+2} - \frac{2}{n+3}. \]

As \(n \to \infty\) the last two fractions go to 0, so \(s_n \to \dfrac53\). The series converges and its sum is \(\dfrac53\).

Check:

\(s_1 = \tfrac48 = 0.5\), and the formula gives \(\tfrac53 - \tfrac23 - \tfrac12 = 0.5\). Adding terms numerically gives \(s_{50} \approx 1.5905\) and \(s_{500} \approx 1.6587\), creeping up toward \(5/3 \approx 1.6667\), just as the formula predicts.

Example 13.2 Choosing a comparison

Determine whether \(\displaystyle\sum_{n=1}^{\infty} \frac{n+5}{\sqrt{n^5+2}}\) converges or diverges.

(Similar to Stewart §11.4, Example 4)
Show solution (try it first)

Strategy:

Keep the dominant terms: the numerator behaves like \(n\) and the denominator like \(\sqrt{n^5} = n^{5/2}\). So \(a_n\) behaves like \(n / n^{5/2} = 1/n^{3/2}\), a convergent p-series (\(p = \tfrac32 > 1\)). A direct inequality is awkward because of the \(+5\), so use the Limit Comparison Test.

Solution:

Let \(b_n = \dfrac{1}{n^{3/2}}\). Then

\[ \lim_{n\to\infty}\frac{a_n}{b_n} = \lim_{n\to\infty} \frac{(n+5)\,n^{3/2}}{\sqrt{n^5+2}} = \lim_{n\to\infty} \frac{1 + 5/n}{\sqrt{1 + 2/n^5}} = 1, \]

after dividing top and bottom by \(n^{5/2}\). The limit is finite and positive, and \(\sum b_n\) converges, so \(\sum \dfrac{n+5}{\sqrt{n^5+2}}\) converges.

Check:

All terms are positive, as the test requires. If you had compared with \(1/n\) instead, the ratio would go to 0, and the test would give no conclusion; that is a sign of a poor choice of \(b_n\), not of divergence.

Example 13.3 How many terms for a given accuracy?

Consider \(\displaystyle\sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n\,3^n}\). (a) Show that it converges. (b) How many terms are needed to guarantee an error smaller than 0.0005? Give the estimate.

(Similar to Stewart §11.5, Example 4)
Show solution (try it first)

Strategy:

This is alternating with \(b_n = \dfrac{1}{n\,3^n}\). Check the two conditions of the Alternating Series Test, then use \(|R_n| \le b_{n+1}\).

Solution:

(a) \(b_{n+1} = \dfrac{1}{(n+1)3^{n+1}} < \dfrac{1}{n\,3^n} = b_n\) because both factors in the denominator grow, and \(b_n \to 0\). So the series converges.

(b) We need the first omitted term to be below 0.0005. Compute: \(b_5 = \dfrac{1}{5\cdot 243} \approx 0.000823\) (too big) and \(b_6 = \dfrac{1}{6 \cdot 729} \approx 0.000229\) (small enough). So stopping at \(n = 5\) works: \(|R_5| \le b_6 < 0.0005\). Five terms are needed:

\[ s_5 = \frac13 - \frac1{18} + \frac1{81} - \frac1{324} + \frac1{1215} \approx 0.28786. \]

Check:

In Module 14 you will see that this sum is exactly \(\ln\tfrac43 \approx 0.28768\). The actual error is about 0.00018, which is indeed less than \(b_6 \approx 0.00023\). The first omitted term \(-b_6\) is negative, so \(s_5\) is slightly too big, as observed.
