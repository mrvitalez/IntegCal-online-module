7.3Trigonometric Substitution

Let's start with a question. What is the area of a circle of radius \(a\)? We all know it is \(\pi a^2\), but can we prove it with integration? The upper half of the circle is \(y = \sqrt{a^2 - x^2}\), so we need \(\int \sqrt{a^2 - x^2}\,dx\). A simple \(u\)-substitution does not work here, because there is no \(x\) outside the root to give us \(du\). This is where trigonometric substitution comes in.

The idea is to let \(x\) be a trigonometric function of a new variable \(\theta\), chosen so that an identity removes the square root. Shown in Table 1 is the summary of the expressions with their substitutions and the identity to use.

ExpressionSubstitutionIdentity
\(\sqrt{a^2 - x^2}\)\(x = a\sin\theta,\ -\frac\pi2 \le \theta \le \frac\pi2\)\(1 - \sin^2\theta = \cos^2\theta\)
\(\sqrt{a^2 + x^2}\)\(x = a\tan\theta,\ -\frac\pi2 \lt \theta \lt \frac\pi2\)\(1 + \tan^2\theta = \sec^2\theta\)
\(\sqrt{x^2 - a^2}\)\(x = a\sec\theta,\ 0 \le \theta \lt \frac\pi2\) or \(\pi \le \theta \lt \frac{3\pi}2\)\(\sec^2\theta - 1 = \tan^2\theta\)

Table 1. Standard trigonometric substitutions.

For example, with \(x = a\sin\theta\) we get \(a^2 - x^2 = a^2 - a^2\sin^2\theta = a^2(1 - \sin^2\theta) = a^2\cos^2\theta\), so \(\sqrt{a^2 - x^2} = a\cos\theta\) (positive, because \(\cos\theta \ge 0\) on \([-\frac\pi2, \frac\pi2]\)). The root is gone!

Example The area under \(y = \sqrt{9 - x^2}\) from 0 to 3 is a quarter circle (Figure 7.1). Let \(x = 3\sin\theta\), \(dx = 3\cos\theta\,d\theta\). When \(x = 0\), \(\theta = 0\); when \(x = 3\), \(\theta = \frac\pi2\). Then \[\int_0^3\sqrt{9 - x^2}\,dx = \int_0^{\pi/2}3\cos\theta\cdot3\cos\theta\,d\theta = 9\int_0^{\pi/2}\cos^2\theta\,d\theta = \frac92\Big[\theta + \tfrac12\sin2\theta\Big]_0^{\pi/2} = \frac{9\pi}{4},\] which is exactly \(\frac14\pi(3)^2\). So the formula we memorized in grade school is correct.

Going back to \(x\). For an indefinite integral, our answer will come out in terms of \(\theta\), but the question was asked in terms of \(x\). We go back using a reference triangle. If \(x = 3\sin\theta\), then \(\sin\theta = \frac x3 = \frac{\text{opp}}{\text{hyp}}\), so we draw a right triangle with opposite side \(x\) and hypotenuse 3. By the Pythagorean theorem, the adjacent side is \(\sqrt{9 - x^2}\) (Figure 7.2). From the triangle we can read off every other trigonometric function, for example \(\cot\theta = \frac{\sqrt{9-x^2}}{x}\).

What if it is not a perfect square? Take note that \(a\) does not have to be a whole number. In \(\sqrt{x^2 - 7}\) we have \(a^2 = 7\), so \(a = \sqrt7\) and we let \(x = \sqrt7\sec\theta\) (you will see this in Example 7.2). And if the quadratic is not in one of the three forms, complete the square first: \(x^2 + 2x + 5 = (x+1)^2 + 4\), and then \(x + 1 = 2\tan\theta\).

Common mistake Forgetting to change \(dx\). If \(x = 2\sin\theta\), then \(dx = 2\cos\theta\,d\theta\), not \(d\theta\). Another one: leaving the answer in terms of \(\theta\) for an indefinite integral. Always go back to \(x\) with the triangle. For definite integrals, change the limits to \(\theta\)-values instead, and you never need to go back.
Key equations
\[ \sqrt{a^2 - x^2}:\ x = a\sin\theta,\qquad \sqrt{a^2 + x^2}:\ x = a\tan\theta,\qquad \sqrt{x^2 - a^2}:\ x = a\sec\theta \]
\[ \int\frac{dx}{\sqrt{x^2 + a^2}} = \ln\left|x + \sqrt{x^2 + a^2}\right| + C \]

7.4Integration of Rational Functions by Partial Fractions

Now we move to rational functions, \(f(x) = \frac{P(x)}{Q(x)}\), where \(P\) and \(Q\) are polynomials. Before we bring out the heavy machinery, always check one thing first: is the numerator the derivative of the denominator? If it is, we can just let \(u\) be the denominator. For example, in \(\int\frac{2x - 1}{x^2 - x + 6}\,dx\), let \(u = x^2 - x + 6\), \(du = (2x - 1)\,dx\), and the integral becomes \(\int\frac{du}{u} = \ln|x^2 - x + 6| + C\).

However, there are instances where the derivative of your denominator is not your numerator. Then we use partial fractions: we break the rational function into simpler fractions that we already know how to integrate.

Step 0: Is the fraction improper? If \(\deg P \ge \deg Q\), the fraction is improper. Get the quotient first! By long division, \[\frac{P(x)}{Q(x)} = S(x) + \frac{R(x)}{Q(x)} \qquad (8)\] where \(S(x)\) is the quotient and \(R(x)\) is the remainder, with \(\deg R \lt \deg Q\). For example, \(\frac{x^3 + x}{x - 1} = x^2 + x + 2 + \frac{2}{x-1}\), so \(\int\frac{x^3+x}{x-1}\,dx = \frac{x^3}3 + \frac{x^2}2 + 2x + 2\ln|x - 1| + C\).

Step 1: Factor the denominator \(Q(x)\) as far as possible into linear factors \((ax + b)\) and irreducible quadratic factors \((ax^2 + bx + c\) with \(b^2 - 4ac \lt 0)\). Step 2: Write the proper fraction \(R(x)/Q(x)\) as a sum of partial fractions of the form \(\frac{A}{(ax+b)^i}\) or \(\frac{Ax + B}{(ax^2+bx+c)^j}\) (9). There are four cases you can encounter.

The four cases CASE 1. \(Q(x)\) is a product of distinct linear factors. Then \[\frac{R(x)}{Q(x)} = \frac{A_1}{a_1x + b_1} + \frac{A_2}{a_2x + b_2} + \cdots + \frac{A_k}{a_kx + b_k} \qquad (10)\] CASE 2. Some linear factor is repeated, say \((a_1x + b_1)^r\). Instead of a single term, use \[\frac{A_1}{a_1x + b_1} + \frac{A_2}{(a_1x + b_1)^2} + \cdots + \frac{A_r}{(a_1x + b_1)^r} \qquad (11)\] CASE 3. \(Q(x)\) contains an irreducible quadratic factor \(ax^2 + bx + c\), not repeated. It contributes a term \[\frac{Ax + B}{ax^2 + bx + c} \qquad (12)\] CASE 4. \(Q(x)\) contains a repeated irreducible quadratic factor \((ax^2 + bx + c)^r\). It contributes \[\frac{A_1x + B_1}{ax^2+bx+c} + \frac{A_2x + B_2}{(ax^2+bx+c)^2} + \cdots + \frac{A_rx + B_r}{(ax^2+bx+c)^r} \qquad (13)\]

Step 3: Find the constants. Multiply both sides by \(Q(x)\) so the denominators cancel. Then either (a) expand and equate the coefficients of each power of \(x\), which gives a system of equations, or (b) substitute convenient values of \(x\) (the roots of the linear factors) that make most terms vanish. Both give the same answer; often a mix of the two is fastest.

Example For \(\frac{1}{x^2 - a^2}\) with \(a \ne 0\): the denominator is a difference of squares, so \(\frac{1}{(x-a)(x+a)} = \frac{A}{x-a} + \frac{B}{x+a}\), or \(A(x + a) + B(x - a) = 1\). If \(x = a\), then \(A = \frac1{2a}\); if \(x = -a\), then \(B = -\frac1{2a}\). Thus \[\int\frac{dx}{x^2 - a^2} = \frac1{2a}\big(\ln|x - a| - \ln|x + a|\big) + C = \frac1{2a}\ln\left|\frac{x - a}{x + a}\right| + C.\]

Step 4: Integrate each piece. Linear pieces give logarithms (\(\int\frac{A}{x - r}\,dx = A\ln|x - r|\)) or powers (\(\int\frac{B}{(x-r)^2}\,dx = -\frac{B}{x - r}\)). Quadratic pieces split into a \(u\)-substitution part and an inverse tangent part, using \[\int\frac{dx}{x^2 + a^2} = \frac1a\tan^{-1}\left(\frac xa\right) + C.\] If the quadratic is not of the form \(x^2 + a^2\), complete the square first. Figures 7.3 and 7.4 show what a decomposition looks like: the complicated curve is just the sum of simple ones.

Before we integrate a Case 4 function, let's practice writing only the form of a decomposition. For \[\frac{x^3 + x^2 + 1}{x(x - 1)(x^2 + x + 1)(x^2 + 1)^3}\] we would write \(\frac{A}{x} + \frac{B}{x - 1} + \frac{Cx + D}{x^2 + x + 1} + \frac{Ex + F}{x^2 + 1} + \frac{Gx + H}{(x^2 + 1)^2} + \frac{Ix + J}{(x^2 + 1)^3}\). Each factor gets as many terms as its power.

Common mistake Using a constant numerator over a quadratic factor, like \(\frac{C}{x^2 + 5}\). A quadratic factor always needs a linear numerator \(Cx + D\). Also, do not forget to divide first when the fraction is improper; partial fractions only work for proper fractions.
Key equations
\[ \frac{P(x)}{Q(x)} = S(x) + \frac{R(x)}{Q(x)},\quad \deg R \lt \deg Q \]
\[ \int\frac{dx}{x^2 + a^2} = \frac1a\tan^{-1}\frac xa + C,\qquad \int\frac{dx}{x^2 - a^2} = \frac1{2a}\ln\left|\frac{x-a}{x+a}\right| + C \]

★Key takeaways

  • Trigonometric substitution removes a square root: \(\sqrt{a^2-x^2}\) → \(x = a\sin\theta\), \(\sqrt{a^2+x^2}\) → \(x = a\tan\theta\), \(\sqrt{x^2-a^2}\) → \(x = a\sec\theta\).
  • Always replace \(dx\) too, and go back to \(x\) with a reference triangle (or change the limits for a definite integral).
  • For a rational function, first check if the numerator is the derivative of the denominator; then check if the fraction is improper and divide.
  • Factor the denominator into linear and irreducible quadratic factors; each factor of power \(r\) gets \(r\) partial fractions.
  • Linear factors need constant numerators; quadratic factors need linear numerators \(Ax + B\).
  • Find the constants by equating coefficients or by substituting convenient values of \(x\), then integrate each piece.

Example 7.1 Trigonometric substitution with sine

Evaluate \(\displaystyle\int\frac{dx}{x^2\sqrt{4 - x^2}}\) using the substitution \(x = 2\sin\theta\).

(From the instructor's module)
Show solution (try it first)

Given: The expression \(\sqrt{4 - x^2} = \sqrt{a^2 - x^2}\) with \(a = 2\), and the substitution \(x = 2\sin\theta\).

Plan: Replace \(x\), \(x^2\), \(\sqrt{4 - x^2}\) and \(dx\) in terms of \(\theta\), simplify, integrate, then go back to \(x\) using a reference triangle.

Step 1. Write everything in terms of \(\theta\). Since \(x = 2\sin\theta\), we have \(dx = 2\cos\theta\,d\theta\) and \(x^2 = 4\sin^2\theta\).

\[\sqrt{4 - x^2} = \sqrt{4 - 4\sin^2\theta} = \sqrt{4(1 - \sin^2\theta)} = \sqrt{4\cos^2\theta} = 2\cos\theta\]

Step 2. Substitute. The \(2\cos\theta\) in \(dx\) cancels the \(2\cos\theta\) from the root.

\[\int\frac{dx}{x^2\sqrt{4 - x^2}} = \int\frac{2\cos\theta\,d\theta}{4\sin^2\theta\cdot2\cos\theta} = \frac14\int\frac{d\theta}{\sin^2\theta} = \frac14\int\csc^2\theta\,d\theta\]

Step 3. Integrate: recall that \(\frac{d}{d\theta}\cot\theta = -\csc^2\theta\).

\[= -\frac14\cot\theta + C\]

Step 4. Go back to \(x\). From \(\sin\theta = \frac x2\), draw a right triangle with opposite side \(x\), hypotenuse 2, and adjacent side \(\sqrt{4 - x^2}\). So \(\cot\theta = \frac{\text{adj}}{\text{opp}} = \frac{\sqrt{4 - x^2}}{x}\).

\[-\frac14\cot\theta + C = -\frac14\cdot\frac{\sqrt{4 - x^2}}{x} + C = -\frac{\sqrt{4 - x^2}}{4x} + C\]

Answer: \(\boxed{\displaystyle\int\frac{dx}{x^2\sqrt{4 - x^2}} = -\frac{\sqrt{4 - x^2}}{4x} + C}\). That is our answer.

Check: Differentiate with the quotient rule: \(\frac{d}{dx}\left[-\frac{\sqrt{4-x^2}}{4x}\right] = -\frac14\cdot\frac{x\cdot\frac{-x}{\sqrt{4-x^2}} - \sqrt{4-x^2}}{x^2} = \frac14\cdot\frac{x^2 + (4 - x^2)}{x^2\sqrt{4-x^2}} = \frac{1}{x^2\sqrt{4-x^2}}\). ✓

Example 7.2 When \(a^2\) is not a perfect square

Evaluate \(\displaystyle\int\frac{x}{\sqrt{x^2 - 7}}\,dx\) using a trigonometric substitution.

(From the instructor's module)
Show solution (try it first)

Given: The denominator has the form \(\sqrt{x^2 - a^2}\) with \(a^2 = 7\), so \(a = \sqrt7\).

Plan: From Table 1, use \(x = \sqrt7\sec\theta\). (A quicker way is \(u = x^2 - 7\); we will use it in the Check.)

Step 1. Let \(x = \sqrt7\sec\theta\), so \(dx = \sqrt7\sec\theta\tan\theta\,d\theta\). Simplify the root with \(\sec^2\theta - 1 = \tan^2\theta\).

\[\sqrt{x^2 - 7} = \sqrt{7\sec^2\theta - 7} = \sqrt{7(\sec^2\theta - 1)} = \sqrt{7\tan^2\theta} = \sqrt7\tan\theta\]

Step 2. Substitute everything.

\[\int\frac{x\,dx}{\sqrt{x^2 - 7}} = \int\frac{\sqrt7\sec\theta\cdot\sqrt7\sec\theta\tan\theta}{\sqrt7\tan\theta}\,d\theta\]

Step 3. Cancel \(\sqrt7\) and \(\tan\theta\). We are left with \(\sqrt7\sec^2\theta\), and \(\int\sec^2\theta\,d\theta = \tan\theta\).

\[= \sqrt7\int\sec^2\theta\,d\theta = \sqrt7\tan\theta + C\]

Step 4. Go back to \(x\). From Step 1 we already know that \(\sqrt7\tan\theta = \sqrt{x^2 - 7}\).

\[\sqrt7\tan\theta + C = \sqrt{x^2 - 7} + C\]

Answer: \(\boxed{\displaystyle\int\frac{x}{\sqrt{x^2 - 7}}\,dx = \sqrt{x^2 - 7} + C}\).

Check: With \(u = x^2 - 7\), \(du = 2x\,dx\): \(\int\frac{x\,dx}{\sqrt{x^2-7}} = \frac12\int u^{-1/2}\,du = u^{1/2} + C = \sqrt{x^2 - 7} + C\). ✓ Same answer, so always look for a simple substitution before using the heavy machinery.

Example 7.3 CASE 1: distinct linear factors

Evaluate \(\displaystyle\int\frac{x^2 + 2x - 1}{2x^3 + 3x^2 - 2x}\,dx\).

(From the instructor's module)
Show solution (try it first)

Given: A proper rational function (degree 2 over degree 3).

Plan: Factor the denominator, write the partial fractions (Case 1), find \(A\), \(B\), \(C\), then integrate each term.

Step 1. Factor the denominator.

\[2x^3 + 3x^2 - 2x = x(2x^2 + 3x - 2) = x(2x - 1)(x + 2)\]

Step 2. Write the form of the decomposition. All three factors are distinct and linear.

\[\frac{x^2 + 2x - 1}{x(2x - 1)(x + 2)} = \frac{A}{x} + \frac{B}{2x - 1} + \frac{C}{x + 2}\]

Step 3. Multiply both sides by \(x(2x-1)(x+2)\), expand, and combine like terms.

\[x^2 + 2x - 1 = A(2x-1)(x+2) + Bx(x+2) + Cx(2x-1) = (2A + B + 2C)x^2 + (3A + 2B - C)x - 2A\]

Step 4. Equate the coefficients of \(x^2\), \(x\) and the constants.

\[2A + B + 2C = 1,\qquad 3A + 2B - C = 2,\qquad -2A = -1\]

Step 5. Solve. The last equation gives \(A = \frac12\). Substituting into the first two: \(B + 2C = 0\) and \(2B - C = \frac12\). From the first, \(B = -2C\); then \(-4C - C = \frac12\), so \(C = -\frac1{10}\) and \(B = \frac15\).

\[A = \tfrac12,\qquad B = \tfrac15,\qquad C = -\tfrac1{10}\]

Step 6. Integrate each term. For the middle term, let \(u = 2x - 1\), \(du = 2\,dx\), so \(\int\frac{dx}{2x-1} = \frac12\ln|2x - 1|\).

\[\int\left[\frac{1/2}{x} + \frac{1/5}{2x - 1} - \frac{1/10}{x + 2}\right]dx = \frac12\ln|x| + \frac15\cdot\frac12\ln|2x - 1| - \frac1{10}\ln|x + 2| + K\]

Answer: \(\boxed{\displaystyle\frac12\ln|x| + \frac1{10}\ln|2x - 1| - \frac1{10}\ln|x + 2| + K}\). (We use \(K\) for the constant just to avoid confusion with the \(C\) we already used.)

Check: Put \(x = 1\) in the decomposition: the left side is \(\frac{1+2-1}{2+3-2} = \frac23\); the right side is \(\frac12 + \frac15 - \frac1{30} = \frac{15 + 6 - 1}{30} = \frac23\). ✓

Example 7.4 CASE 2: a repeated linear factor (divide first)

Find \(\displaystyle\int\frac{x^4 - 2x^2 + 4x + 1}{x^3 - x^2 - x + 1}\,dx\).

(From the instructor's module)
Show solution (try it first)

Given: An improper rational function (degree 4 over degree 3).

Plan: Divide first to get a proper remainder, factor the denominator (it has a repeated factor), decompose with Case 2, and integrate.

Step 1. Long division gives the quotient \(x + 1\) and remainder \(4x\).

\[\frac{x^4 - 2x^2 + 4x + 1}{x^3 - x^2 - x + 1} = x + 1 + \frac{4x}{x^3 - x^2 - x + 1}\]

Step 2. Factor the denominator by grouping.

\[x^3 - x^2 - x + 1 = x^2(x - 1) - (x - 1) = (x - 1)(x^2 - 1) = (x - 1)^2(x + 1)\]

Step 3. Since \((x - 1)\) is repeated, this is Case 2.

\[\frac{4x}{(x - 1)^2(x + 1)} = \frac{A}{x - 1} + \frac{B}{(x - 1)^2} + \frac{C}{x + 1}\]

Step 4. Multiply by \((x-1)^2(x+1)\): \(4x = A(x-1)(x+1) + B(x+1) + C(x-1)^2\). Substitute convenient values: \(x = 1\) gives \(4 = 2B\), so \(B = 2\); \(x = -1\) gives \(-4 = 4C\), so \(C = -1\). Comparing the \(x^2\) coefficients: \(0 = A + C\), so \(A = 1\).

\[A = 1,\qquad B = 2,\qquad C = -1\]

Step 5. Integrate every piece. Note \(\int\frac{2}{(x-1)^2}\,dx = -\frac{2}{x - 1}\).

\[\int\left[x + 1 + \frac{1}{x - 1} + \frac{2}{(x - 1)^2} - \frac{1}{x + 1}\right]dx = \frac{x^2}{2} + x + \ln|x - 1| - \frac{2}{x - 1} - \ln|x + 1| + K\]

Answer: \(\boxed{\displaystyle\frac{x^2}{2} + x - \frac{2}{x - 1} + \ln\left|\frac{x - 1}{x + 1}\right| + K}\).

Check: Check the constants at \(x = 0\): \(\frac{0}{1\cdot1} = 0\) and \(\frac{1}{-1} + \frac{2}{1} + \frac{-1}{1} = -1 + 2 - 1 = 0\). ✓ At \(x = 2\): \(\frac{8}{1\cdot3} = \frac83\) and \(1 + 2 - \frac13 = \frac83\). ✓

Example 7.5 CASE 3: an irreducible quadratic factor

Evaluate \(\displaystyle\int\frac{2x^2 - x + 4}{x^3 + 4x}\,dx\).

(From the instructor's module)
Show solution (try it first)

Given: A proper rational function whose denominator is \(x^3 + 4x = x(x^2 + 4)\).

Plan: \(x^2 + 4\) cannot be factored over the reals (\(b^2 - 4ac = -16 \lt 0\)), so it gets a linear numerator. Then split the quadratic piece into a log part and an inverse tangent part.

Step 1. Write the form of the decomposition.

\[\frac{2x^2 - x + 4}{x(x^2 + 4)} = \frac{A}{x} + \frac{Bx + C}{x^2 + 4}\]

Step 2. Multiply by \(x(x^2 + 4)\) and collect terms.

\[2x^2 - x + 4 = A(x^2 + 4) + (Bx + C)x = (A + B)x^2 + Cx + 4A\]

Step 3. Equate coefficients: \(A + B = 2\), \(C = -1\), \(4A = 4\).

\[A = 1,\qquad B = 1,\qquad C = -1\]

Step 4. Split the integral into three parts.

\[\int\frac{2x^2 - x + 4}{x^3 + 4x}\,dx = \int\frac{dx}{x} + \int\frac{x\,dx}{x^2 + 4} - \int\frac{dx}{x^2 + 4}\]

Step 5. Second term: let \(u = x^2 + 4\), \(du = 2x\,dx\), so it equals \(\frac12\ln(x^2 + 4)\). Third term: use \(\int\frac{dx}{x^2 + a^2} = \frac1a\tan^{-1}\frac xa\) with \(a = 2\).

\[= \ln|x| + \frac12\ln(x^2 + 4) - \frac12\tan^{-1}\left(\frac x2\right) + K\]

Answer: \(\boxed{\displaystyle\ln|x| + \frac12\ln(x^2 + 4) - \frac12\tan^{-1}\frac x2 + K}\).

Check: At \(x = 2\): the integrand is \(\frac{8 - 2 + 4}{8 + 8} = \frac{10}{16} = \frac58\), and the decomposition gives \(\frac12 + \frac{2 - 1}{8} = \frac58\). ✓
