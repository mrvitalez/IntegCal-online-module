7.3Trigonometric Substitution

Integrals containing \(\sqrt{a^2 - x^2}\), \(\sqrt{a^2 + x^2}\) or \(\sqrt{x^2 - a^2}\) usually resist ordinary substitution. Stewart §7.3 removes the square root by a clever change of variable: let \(x\) be a trigonometric function of a new variable \(\theta\), chosen so that a Pythagorean identity turns the expression under the root into a perfect square.

ExpressionSubstitutionIdentity used
\(\sqrt{a^2 - x^2}\)\(x = a\sin\theta,\ -\tfrac{\pi}{2} \le \theta \le \tfrac{\pi}{2}\)\(1 - \sin^2\theta = \cos^2\theta\)
\(\sqrt{a^2 + x^2}\)\(x = a\tan\theta,\ -\tfrac{\pi}{2} \lt \theta \lt \tfrac{\pi}{2}\)\(1 + \tan^2\theta = \sec^2\theta\)
\(\sqrt{x^2 - a^2}\)\(x = a\sec\theta,\ 0 \le \theta \lt \tfrac{\pi}{2}\) or \(\pi \le \theta \lt \tfrac{3\pi}{2}\)\(\sec^2\theta - 1 = \tan^2\theta\)

The restricted ranges make the substitution one-to-one, so you can undo it, and they make the root simplify without absolute values. For example, with \(x = a\sin\theta\), \(\sqrt{a^2 - a^2\sin^2\theta} = a\sqrt{\cos^2\theta} = a\cos\theta\), because \(\cos\theta \ge 0\) on \([-\pi/2, \pi/2]\).

Notice that this is an inverse substitution. In §5.5 you set \(u\) equal to a function of \(x\); here you set \(x\) equal to a function of \(\theta\). That is allowed because the substitution can be reversed: \(\theta = \sin^{-1}(x/a)\) on the stated interval.

Sometimes the radical only reveals its type after you complete the square. For \(\sqrt{x^2 + 2x + 5}\), write \(x^2 + 2x + 5 = (x + 1)^2 + 4\); this is \(\sqrt{a^2 + u^2}\) with \(u = x + 1\) and \(a = 2\), so let \(x + 1 = 2\tan\theta\).

The four-step routine.

  1. Pick the substitution from the table and compute \(dx\) (for \(x = a\sin\theta\), \(dx = a\cos\theta\,d\theta\)).
  2. Replace every \(x\), the root and \(dx\); simplify to a trigonometric integral.
  3. Integrate with the methods of §7.2.
  4. Return to \(x\) using a reference triangle.

Back-substitution with a triangle. If \(x = 3\sin\theta\), then \(\sin\theta = x/3\): draw a right triangle with angle \(\theta\), opposite side \(x\) and hypotenuse 3. The Pythagorean Theorem gives the adjacent side \(\sqrt{9 - x^2}\) (Figure 7.2). Now you can read off every other function: \(\cos\theta = \tfrac{\sqrt{9-x^2}}{3}\), \(\tan\theta = \tfrac{x}{\sqrt{9-x^2}}\), \(\cot\theta = \tfrac{\sqrt{9-x^2}}{x}\), and \(\theta = \sin^{-1}(x/3)\). For \(x = a\tan\theta\) the opposite side is \(x\), the adjacent side is \(a\) and the hypotenuse is \(\sqrt{a^2 + x^2}\); for \(x = a\sec\theta\) the hypotenuse is \(x\) and the adjacent side is \(a\).

Definite integrals are often easier: change the limits to \(\theta\)-values and skip the triangle. For the quarter circle of radius 3 (Figure 7.1), \(x = 3\sin\theta\) sends \(x = 0, 3\) to \(\theta = 0, \pi/2\), and

\[\int_0^3\sqrt{9 - x^2}\,dx = \int_0^{\pi/2} 9\cos^2\theta\,d\theta = \frac{9}{2}\Big[\theta + \tfrac12\sin 2\theta\Big]_0^{\pi/2} = \frac{9\pi}{4},\]

exactly one quarter of \(\pi r^2 = 9\pi\), as geometry predicts.

Common mistake Leaving the answer partly in \(\theta\), or writing \(\sin 2\theta\) in terms of \(x\) as \(\sin(2x/3)\). Expand first: \(\sin 2\theta = 2\sin\theta\cos\theta\), then use the triangle.
Note Do not reach for trigonometric substitution when a simple \(u\)-substitution works: \(\int x\sqrt{9 - x^2}\,dx\) needs only \(u = 9 - x^2\).
Key equations
\[ \sqrt{a^2 - x^2}:\ x = a\sin\theta, \qquad \sqrt{a^2 + x^2}:\ x = a\tan\theta, \qquad \sqrt{x^2 - a^2}:\ x = a\sec\theta \]
\[ \int_0^a \sqrt{a^2 - x^2}\,dx = \frac{\pi a^2}{4} \]

7.4Integration of Rational Functions by Partial Fractions

A rational function is a quotient of polynomials, \(f(x) = P(x)/Q(x)\). Stewart §7.4 shows that every rational function can be integrated by breaking it into simpler fractions, the reverse of adding fractions over a common denominator. For instance \(\tfrac{1}{x} - \tfrac{1}{x+1} = \tfrac{1}{x(x+1)}\), so \(\int\tfrac{dx}{x(x+1)} = \ln|x| - \ln|x+1| + C\) (Figure 7.3).

Why does this always work? A fact from algebra says that every polynomial with real coefficients factors into linear factors and irreducible quadratic factors. Each kind of factor produces a simple fraction, and each simple fraction has a known antiderivative. So the whole method is just careful algebra followed by three or four easy integrals.

Step 0: long division if needed. The method needs a proper fraction, where \(\deg P \lt \deg Q\). If not, divide first. Example: \(\tfrac{x^3 + x}{x - 1} = x^2 + x + 2 + \tfrac{2}{x-1}\), so \(\int\tfrac{x^3+x}{x-1}\,dx = \tfrac13x^3 + \tfrac12x^2 + 2x + 2\ln|x-1| + C\).

Step 1: factor the denominator completely into linear factors \(ax + b\) and irreducible quadratic factors \(ax^2 + bx + c\) (those with \(b^2 - 4ac \lt 0\)).

Step 2: write the decomposition. Each factor contributes terms with unknown constants:

  • Distinct linear factors: each \((x - r)\) gives \(\dfrac{A}{x - r}\).
  • Repeated linear factor \((x - r)^k\): gives \(\dfrac{A_1}{x-r} + \dfrac{A_2}{(x-r)^2} + \cdots + \dfrac{A_k}{(x-r)^k}\), one term for every power.
  • Irreducible quadratic factor \(ax^2 + bx + c\): gives \(\dfrac{Ax + B}{ax^2 + bx + c}\), with a linear numerator.

Step 3: find the constants. Multiply through by \(Q(x)\). Then either substitute convenient \(x\)-values (the roots of the linear factors make most terms vanish) or match coefficients of equal powers of \(x\). Often a mix of both is fastest. For example, \(\tfrac{3x+1}{(x-1)^2(x+1)} = \tfrac{A}{x-1} + \tfrac{B}{(x-1)^2} + \tfrac{C}{x+1}\) gives \(3x + 1 = A(x-1)(x+1) + B(x+1) + C(x-1)^2\). Setting \(x = 1\) gives \(B = 2\); \(x = -1\) gives \(C = -\tfrac12\); comparing \(x^2\) coefficients gives \(A + C = 0\), so \(A = \tfrac12\).

Step 4: integrate each piece. The building blocks are

  • \(\int\frac{dx}{x - r} = \ln|x - r| + C\) and \(\int\frac{dx}{(x-r)^k} = \frac{-1}{(k-1)(x-r)^{k-1}} + C\) for \(k \ge 2\);
  • \(\int\frac{Ax + B}{x^2 + a^2}\,dx = \frac{A}{2}\ln(x^2 + a^2) + \frac{B}{a}\tan^{-1}\frac{x}{a} + C\).

For a quadratic like \(x^2 + 2x + 5\), complete the square, \((x+1)^2 + 4\), and substitute \(u = x + 1\) to reach the second form.

Common mistake Using a constant numerator over an irreducible quadratic, or giving a repeated factor \((x-1)^2\) only one term. With too few unknowns the equations have no solution, which is a sign the set-up is wrong.
Key equations
\[ \frac{P(x)}{(x-r)(x-s)} = \frac{A}{x-r} + \frac{B}{x-s} \]
\[ \frac{P(x)}{(x-r)^2(x-s)} = \frac{A}{x-r} + \frac{B}{(x-r)^2} + \frac{C}{x-s} \]
\[ \int\frac{Ax + B}{x^2 + a^2}\,dx = \frac{A}{2}\ln(x^2 + a^2) + \frac{B}{a}\tan^{-1}\frac{x}{a} + C \]

★Key takeaways

  • Match the radical to the substitution: √(a² − x²) with x = a sin θ, √(a² + x²) with x = a tan θ, √(x² − a²) with x = a sec θ.
  • After integrating in θ, use a reference triangle built from the substitution to rewrite the answer in x; for definite integrals, change the limits instead.
  • Partial fractions need a proper fraction, so do long division first when the degree of the numerator is at least the degree of the denominator.
  • Each distinct linear factor gives A/(x − r), a repeated factor (x − r)^k gives one term for each power up to k, and an irreducible quadratic gives (Ax + B)/(quadratic).
  • Linear pieces integrate to logarithms or negative powers; quadratic pieces integrate to a logarithm plus an inverse tangent after completing the square.

Example 7.1 Sine substitution with a triangle

Find \(\displaystyle\int\frac{dx}{x^2\sqrt{9 - x^2}}\).

(Similar to Stewart §7.3, Example 1)
Show solution (try it first)

Strategy:

The root \(\sqrt{9 - x^2}\) has the form \(\sqrt{a^2 - x^2}\) with \(a = 3\), so let \(x = 3\sin\theta\), \(dx = 3\cos\theta\,d\theta\), and \(\sqrt{9 - x^2} = 3\cos\theta\).

Solution:

\[\int\frac{3\cos\theta\,d\theta}{9\sin^2\theta\cdot 3\cos\theta} = \frac19\int\csc^2\theta\,d\theta = -\frac19\cot\theta + C.\]

From the triangle with opposite side \(x\), hypotenuse 3 and adjacent side \(\sqrt{9 - x^2}\) (Figure 7.2), \(\cot\theta = \dfrac{\sqrt{9 - x^2}}{x}\). Therefore

\[\int\frac{dx}{x^2\sqrt{9 - x^2}} = -\frac{\sqrt{9 - x^2}}{9x} + C.\]

Check:

Differentiate \(-\tfrac19(9 - x^2)^{1/2}x^{-1}\) with the Product Rule: \(-\tfrac19\big[-x(9-x^2)^{-1/2}x^{-1} - (9-x^2)^{1/2}x^{-2}\big] = \tfrac19\cdot\frac{x^2 + (9 - x^2)}{x^2\sqrt{9-x^2}} = \frac{1}{x^2\sqrt{9-x^2}}\). Correct.

Example 7.2 Two distinct linear factors

Find \(\displaystyle\int\frac{x + 5}{x^2 + x - 2}\,dx\).

(Similar to Stewart §7.4, Example 2)
Show solution (try it first)

Strategy:

The fraction is proper (degree 1 over degree 2). Factor \(x^2 + x - 2 = (x - 1)(x + 2)\) and write \(\dfrac{x+5}{(x-1)(x+2)} = \dfrac{A}{x-1} + \dfrac{B}{x+2}\).

Solution:

Multiply by \((x-1)(x+2)\): \(x + 5 = A(x + 2) + B(x - 1)\).

  • \(x = 1\): \(6 = 3A\), so \(A = 2\).
  • \(x = -2\): \(3 = -3B\), so \(B = -1\).

\[\int\Big(\frac{2}{x-1} - \frac{1}{x+2}\Big)dx = 2\ln|x - 1| - \ln|x + 2| + C = \ln\frac{(x-1)^2}{|x+2|} + C.\]

Check:

Recombine: \(\dfrac{2(x+2) - (x-1)}{(x-1)(x+2)} = \dfrac{x + 5}{x^2 + x - 2}\). Matching the original fraction is a quick test of your constants before you integrate.

Example 7.3 A linear factor and an irreducible quadratic

Find \(\displaystyle\int\frac{3x^2 + 2x + 5}{(x - 1)(x^2 + 4)}\,dx\).

(Similar to Stewart §7.4, Example 4)
Show solution (try it first)

Strategy:

\(x^2 + 4\) cannot be factored over the reals, so it needs a linear numerator: \(\dfrac{3x^2 + 2x + 5}{(x-1)(x^2+4)} = \dfrac{A}{x-1} + \dfrac{Bx + C}{x^2 + 4}\).

Solution:

Multiply through: \(3x^2 + 2x + 5 = A(x^2 + 4) + (Bx + C)(x - 1)\).

  • \(x = 1\): \(10 = 5A\), so \(A = 2\).
  • \(x^2\) coefficients: \(3 = A + B\), so \(B = 1\).
  • Constant terms: \(5 = 4A - C\), so \(C = 3\). (Check with \(x\) coefficients: \(2 = C - B\). Yes.)

\[\int\Big(\frac{2}{x-1} + \frac{x}{x^2+4} + \frac{3}{x^2+4}\Big)dx = 2\ln|x - 1| + \tfrac12\ln(x^2 + 4) + \tfrac32\tan^{-1}\frac{x}{2} + C.\]

Check:

The middle term uses \(u = x^2 + 4\); the last uses \(\int\frac{dx}{x^2 + a^2} = \frac1a\tan^{-1}\frac xa\) with \(a = 2\). Differentiating the answer gives \(\frac{2}{x-1} + \frac{x}{x^2+4} + \frac{3}{x^2+4}\), which recombines to the original integrand.
