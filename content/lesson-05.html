5.3Volumes by Cylindrical Shells

In Module 4 we sliced solids into disks and washers. But try rotating the region under \(y = 3x - x^2\), from \(x = 0\) to \(3\), about the \(y\)-axis. With washers we would need horizontal slices, so we would have to solve \(y = 3x - x^2\) for \(x\), and that gives two messy square-root formulas. Is there an easier way? Yes: instead of slicing the solid, we peel it, like the layers of an onion.

Take a thin vertical strip of the region at \(x\), with height \(f(x)\) and width \(\Delta x\). When we rotate it about the \(y\)-axis, it sweeps out a thin cylindrical shell: a tube of radius \(x\), height \(f(x)\) and thickness \(\Delta x\). If we cut the tube and flatten it, we get almost a rectangular plate with length = circumference \(2\pi x\), height \(f(x)\) and thickness \(\Delta x\). So its volume is about \(2\pi x\,f(x)\,\Delta x\). Adding all the shells and taking the limit:

The shell method The volume of the solid obtained by rotating the region under \(y = f(x) \ge 0\), \(a \le x \le b\) (with \(0 \le a\)), about the \(y\)-axis is \[V = \int_a^b 2\pi x\,f(x)\,dx = \int_a^b 2\pi\,(\text{radius})(\text{height})\,dx.\]

The easiest way to remember it is the phrase "circumference × height × thickness". The radius is the distance from the strip to the axis, and the height is top minus bottom of the strip. For another vertical axis, such as \(x = -1\), only the radius changes: the strip at \(x\) is \(x - (-1) = x + 1\) away from it.

Shells or washers? Take note of this simple rule: with shells, the strips are parallel to the axis of rotation; with washers, they are perpendicular to it. Choose the method whose strips are easier to describe with the formulas we have. If the curves are given as \(y = f(x)\) and the axis is vertical, shells are usually easier.

Common mistake Using \(\pi x^2\) or \(\pi f(x)^2\) in a shell integral. There is no squaring in the shell method: it is \(2\pi\cdot\text{radius}\cdot\text{height}\). Also check that the radius is measured from the actual axis of rotation.
Key equations
\[ V = \int_a^b 2\pi x\,f(x)\,dx \]
\[ V = \int_a^b 2\pi\,(\text{radius})(\text{height})\,dx \]

5.4Work

Recall from our physics class that if a constant force \(F\) moves an object a distance \(d\) in the direction of the force, the work done is \(W = Fd\). In SI units, force is in newtons (N), distance in metres (m), and work in joules (J). But what if the force changes as the object moves, like when we stretch a spring or lift a satellite away from Earth? We again use our favourite idea: on a tiny interval of length \(\Delta x\), the force is almost constant, so the work is about \(F(x)\,\Delta x\). Adding and taking the limit:

Work done by a variable force If an object moves along the \(x\)-axis from \(x = a\) to \(x = b\) under a continuous force \(F(x)\), the work done is \[W = \int_a^b F(x)\,dx.\]

Springs. Hooke's Law says the force needed to hold a spring stretched \(x\) units beyond its natural length is \(F(x) = kx\), where \(k\) is the spring constant. Take note: \(x\) is measured from the natural length, not from where the spring happens to start.

Gravity. By Newton's Law of Gravitation, the force needed to lift a mass \(m\) at distance \(r\) from Earth's centre is \(F(r) = \frac{GMm}{r^2}\). Since it changes with \(r\), lifting a satellite from the surface \(r = R\) to an altitude \(h\) takes \(W = \int_R^{R+h} \frac{GMm}{r^2}\,dr\).

Pumping liquids. When we pump water out of a tank, each layer of water travels a different distance, so we slice the water into thin horizontal layers instead. Let \(x\) be the depth of a layer below the top (where the water exits) and \(\Delta x\) its thickness. Then:

  1. Volume of the layer: (area of the layer) × \(\Delta x\).
  2. Force on the layer = its weight = (density) × \(g\) × (volume). For water, \(\rho = 1000\) kg/m³ and \(g = 9.8\) m/s².
  3. Distance the layer must be lifted: \(x\).
  4. Work for the layer ≈ force × distance; add the layers and take the limit to get an integral in \(x\).
Common mistake Using mass instead of weight. In SI units the force on a layer of water is \(\rho g V\), not \(\rho V\). Forgetting \(g = 9.8\) makes the answer about ten times too small.
Key equations
\[ W = \int_a^b F(x)\,dx \]
\[ \text{Hooke's Law: } F(x) = kx \]
\[ \text{pumping: } W = \int_a^b \rho g\,A(x)\,(\text{distance lifted})\,dx \]

5.5Average Value of a Function

We know how to average finitely many numbers: add them up and divide by how many there are. But how do we find the average temperature over a whole day, when the temperature takes infinitely many values? Let's sample: divide \([a, b]\) into \(n\) equal parts and average the values \(f(x_1), \dots, f(x_n)\). Since \(n = \frac{b-a}{\Delta x}\), \[\frac{f(x_1) + \cdots + f(x_n)}{n} = \frac{1}{b-a}\sum_{i=1}^{n} f(x_i)\,\Delta x.\] Notice that this is a Riemann sum divided by \(b - a\). As \(n \to \infty\), it becomes an integral.

Average value The average value of \(f\) on \([a, b]\) is \[f_{\text{ave}} = \frac{1}{b-a}\int_a^b f(x)\,dx.\]

Geometric meaning. Multiply both sides by \(b - a\): \(f_{\text{ave}}\,(b - a) = \int_a^b f(x)\,dx\). So \(f_{\text{ave}}\) is the height of the rectangle on \([a, b]\) that has the same area as the region under the curve. Whatever area pokes above the rectangle fills the gaps below it.

The Mean Value Theorem for Integrals If \(f\) is continuous on \([a, b]\), then there is a number \(c\) in \([a, b]\) such that \(f(c) = f_{\text{ave}}\), that is, \(\int_a^b f(x)\,dx = f(c)\,(b - a)\).

This connects nicely to motion: the average velocity on \([t_1, t_2]\) is \(\frac{1}{t_2 - t_1}\int_{t_1}^{t_2} v(t)\,dt = \frac{s(t_2) - s(t_1)}{t_2 - t_1}\), exactly the "change in position over change in time" from our physics class.

Common mistake Averaging only the endpoint values, \(\frac{f(a) + f(b)}{2}\). That works for a straight line, but not for curves: for \(x^2\) on \([0, 3]\) it gives 4.5, while the true average is 3.
Key equations
\[ f_{\text{ave}} = \frac{1}{b-a}\int_a^b f(x)\,dx \]
\[ f(c) = f_{\text{ave}} \text{ for some } c \in [a, b] \]

★Key takeaways

  • Shell method: V = ∫ 2π (radius)(height) dx, with strips parallel to the axis of rotation.
  • Use shells when the strips are easier to describe parallel to the axis; use washers when they are easier perpendicular to it.
  • Work by a variable force: W = ∫ F(x) dx; for a spring F = kx with x measured from the natural length.
  • For pumping, slice the liquid into layers: work for a layer = (ρ g × volume) × (distance lifted).
  • The average value of f on [a, b] is (1/(b − a)) ∫ f(x) dx, the height of the rectangle with the same area.
  • A continuous function actually takes its average value at some point c (Mean Value Theorem for Integrals).

Example 5.1 Shells about the y-axis

The region under \(y = 3x - x^2\) and above the \(x\)-axis is rotated about the \(y\)-axis. Find the volume.

(Similar to Stewart §5.3, Example 1)
Show solution (try it first)

Given: the region under \(y = 3x - x^2\), axis = \(y\)-axis. Find: the volume.

Plan: Vertical strips are parallel to the \(y\)-axis, so use shells: radius \(x\), height \(3x - x^2\).

Step 1. Find where the curve meets the \(x\)-axis: \(3x - x^2 = x(3 - x) = 0\), so \(x = 0\) and \(x = 3\).

Step 2. Identify the radius and the height of a typical shell (Figure 5.1).

\[\text{radius} = x, \qquad \text{height} = 3x - x^2\]

Step 3. Set up the shell integral and multiply out.

\[V = \int_0^3 2\pi x\,(3x - x^2)\,dx = 2\pi\int_0^3 (3x^2 - x^3)\,dx\]

Step 4. Integrate and evaluate.

\[= 2\pi\left[x^3 - \frac{x^4}{4}\right]_0^3 = 2\pi\left(27 - \frac{81}{4}\right) = 2\pi\cdot\frac{27}{4} = \frac{27\pi}{2}\]

Answer: \(\boxed{V = \dfrac{27\pi}{2} \approx 42.41}\) cubic units.

Check: The solid fits inside a cylinder of radius 3 and height \(f(1.5) = 2.25\), volume \(\pi(9)(2.25) \approx 63.6\). Our answer is smaller, as it should be, since the solid has a dip in the middle.

Example 5.2 Shells about the line x = −1

Rotate the same region (under \(y = 3x - x^2\), \(0 \le x \le 3\)) about the line \(x = -1\). Find the volume.

(Similar to Stewart §5.3, Example 4)
Show solution (try it first)

Given: the same region, axis \(x = -1\). Find: the volume.

Plan: Same shells, same height; only the radius changes because the axis moved.

Step 1. The strip at \(x\) is at distance \(x - (-1) = x + 1\) from the axis (Figure 5.2).

\[\text{radius} = x + 1, \qquad \text{height} = 3x - x^2\]

Step 2. Set up and multiply out.

\[V = \int_0^3 2\pi(x+1)(3x - x^2)\,dx = 2\pi\int_0^3 (-x^3 + 2x^2 + 3x)\,dx\]

Step 3. Integrate.

\[= 2\pi\left[-\frac{x^4}{4} + \frac{2x^3}{3} + \frac{3x^2}{2}\right]_0^3\]

Step 4. Evaluate.

\[= 2\pi\left(-\frac{81}{4} + 18 + \frac{27}{2}\right) = 2\pi\cdot\frac{-81 + 72 + 54}{4} = 2\pi\cdot\frac{45}{4} = \frac{45\pi}{2}\]

Answer: \(\boxed{V = \dfrac{45\pi}{2} \approx 70.69}\) cubic units.

Check: Moving the axis farther from the region makes every shell wider, so the volume must be larger than \(\tfrac{27\pi}{2}\) from Example 5.1. It is.

Example 5.3 Stretching a spring

A force of 40 N is required to hold a spring stretched from its natural length of 10 cm to a length of 30 cm. How much work is done in stretching the spring from 20 cm to 40 cm?

(Similar to Stewart §5.4, Example 4)
Show solution (try it first)

Given: \(F = 40\) N at a stretch of \(30 - 10 = 20\) cm \(= 0.2\) m. Find: the work from a length of 20 cm to 40 cm.

Plan: Find \(k\) from Hooke's Law, convert the lengths to stretches beyond the natural length (in metres), then integrate \(F(x) = kx\).

Step 1. Find the spring constant: \(F = kx\) with \(x = 0.2\) m.

\[40 = k(0.2) \;\Rightarrow\; k = 200 \text{ N/m}, \qquad F(x) = 200x\]

Step 2. Convert the lengths to stretches beyond the natural length 10 cm: 20 cm → \(x = 0.1\) m; 40 cm → \(x = 0.3\) m.

Step 3. Integrate the force over the stretch.

\[W = \int_{0.1}^{0.3} 200x\,dx = \Big[100x^2\Big]_{0.1}^{0.3} = 100(0.09) - 100(0.01) = 9 - 1 = 8\]

Answer: \(\boxed{W = 8 \text{ J}}\).

Check: This is the trapezoid in Figure 5.3: width 0.2 m, parallel sides \(F(0.1) = 20\) N and \(F(0.3) = 60\) N, area \(\tfrac12(20 + 60)(0.2) = 8\) J. A common slip is to use 20 cm and 40 cm as the stretches, which gives 12 J.

Example 5.4 Pumping water out of a tank

A cylindrical tank of radius 1 m and height 3 m is full of water. How much work is needed to pump all of the water out over the top? (Use \(\rho = 1000\) kg/m³, \(g = 9.8\) m/s².)

(Similar to Stewart §5.4, Example 5)
Show solution (try it first)

Given: cylinder, radius 1 m, height 3 m, full. Find: the work to pump the water over the top.

Plan: Slice the water into horizontal layers at depth \(x\) below the top. Find the weight of one layer and how far it is lifted, then integrate from \(x = 0\) to \(3\).

Step 1. Volume of a layer at depth \(x\) with thickness \(\Delta x\): a disk of radius 1.

\[\Delta V = \pi(1)^2\,\Delta x = \pi\,\Delta x \ \text{m}^3\]

Step 2. Weight (force) of the layer.

\[\Delta F = \rho g\,\Delta V = 1000(9.8)\pi\,\Delta x = 9800\pi\,\Delta x \ \text{N}\]

Step 3. Distance this layer is lifted: \(x\) metres (Figure 5.4). So its work is about \(9800\pi x\,\Delta x\). Add the layers and take the limit.

\[W = \int_0^3 9800\pi x\,dx\]

Step 4. Integrate and evaluate.

\[W = 9800\pi\left[\frac{x^2}{2}\right]_0^3 = 9800\pi\cdot\frac92 = 44\,100\pi \approx 138\,544\]

Answer: \(\boxed{W = 44\,100\pi \text{ J} \approx 1.39 \times 10^5 \text{ J}}\).

Check: The total weight of the water is \(9800\pi(3) \approx 92\,363\) N, and on average it is lifted 1.5 m (its centre of mass is at mid-depth): \(92\,363 \times 1.5 \approx 138\,544\) J. Same answer.

Example 5.5 Lifting a satellite

How much work is needed to lift a 1000-kg satellite from Earth's surface to an altitude of 500 km? Use \(GM = 3.986 \times 10^{14}\) m³/s² and Earth's radius \(R = 6.371 \times 10^6\) m.

Show solution (try it first)

Given: \(m = 1000\) kg, from \(r = R\) to \(r = R + h\) with \(h = 5 \times 10^5\) m. Find: the work against gravity.

Plan: Gravity weakens with distance, so \(F(r) = \frac{GMm}{r^2}\) is a variable force. Integrate it from \(R\) to \(R + h\).

Step 1. Set up the work integral.

\[W = \int_R^{R+h}\frac{GMm}{r^2}\,dr = GMm\int_R^{R+h} r^{-2}\,dr\]

Step 2. Integrate with the power rule: \(\int r^{-2}\,dr = -r^{-1}\).

\[W = GMm\left[-\frac1r\right]_R^{R+h} = GMm\left(\frac1R - \frac{1}{R+h}\right)\]

Step 3. Substitute: \(\frac1R = 1.5696 \times 10^{-7}\) and \(\frac{1}{R+h} = \frac{1}{6.871 \times 10^6} = 1.4554 \times 10^{-7}\).

\[W = (3.986 \times 10^{14})(1000)\left(1.5696 - 1.4554\right)\times 10^{-7} \approx 4.55 \times 10^9\]

Answer: \(\boxed{W \approx 4.55 \times 10^9 \text{ J}}\).

Check: If we pretended gravity stayed at \(mg = 9800\) N all the way up, we would get \(9800 \times 5 \times 10^5 = 4.9 \times 10^9\) J. Our answer is a bit smaller, as it should be, because gravity gets weaker as the satellite rises.

Example 5.6 Average value

Find the average value of \(f(x) = x^2\) on \([0, 3]\), and find \(c\) such that \(f(c) = f_{\text{ave}}\).

(Similar to Stewart §5.5, Example 1)
Show solution (try it first)

Given: \(f(x) = x^2\), \(a = 0\), \(b = 3\). Find: \(f_{\text{ave}}\) and \(c\).

Plan: Apply the average value formula, then solve \(f(c) = f_{\text{ave}}\) for \(c\) in \([0, 3]\).

Step 1. Apply the formula.

\[f_{\text{ave}} = \frac{1}{3 - 0}\int_0^3 x^2\,dx = \frac13\left[\frac{x^3}{3}\right]_0^3 = \frac13\cdot 9 = 3\]

Step 2. Solve \(f(c) = 3\).

\[c^2 = 3 \;\Rightarrow\; c = \pm\sqrt3\]

Step 3. Keep only the value inside \([0, 3]\): \(c = \sqrt3 \approx 1.732\).

Answer: \(\boxed{f_{\text{ave}} = 3,\ c = \sqrt3}\).

Check: The rectangle of height 3 on \([0, 3]\) has area 9, which equals \(\int_0^3 x^2\,dx = 9\) (Figure 5.5). Averaging only the endpoints, \(\frac{0 + 9}{2} = 4.5\), would be wrong.
