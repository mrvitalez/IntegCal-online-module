5.1Areas Between Curves

Recall how we solved the area problem: we cut the region under \(y = f(x)\) into thin rectangles, added their areas, and took the limit. That limit is the definite integral \(\int_a^b f(x)\,dx\). Now let's ask a slightly bigger question. What if the region is not sitting on the \(x\)-axis, but is trapped between two curves? (Stewart §5.1)

We do exactly the same thing. Suppose \(f\) and \(g\) are continuous and \(f(x) \ge g(x)\) on \([a,b]\). Let's draw one thin vertical rectangle at \(x\). Its width is \(\Delta x\). What is its height? It is the distance from the lower curve to the upper curve, that is, \(f(x) - g(x)\). We add these rectangles and let \(n \to \infty\):

Definition The area of the region between \(y = f(x)\) and \(y = g(x)\) from \(a\) to \(b\), where \(f(x) \ge g(x)\), is \[A = \int_a^b \bigl[f(x) - g(x)\bigr]\,dx.\]

Take note that this works even if part of the region is below the \(x\)-axis. The height is always top minus bottom, and that is positive wherever \(f \ge g\).

Where are the limits? Many problems only say "the region enclosed by the curves". Then the limits are the points where the curves meet, so we set the two formulas equal. For \(y = 2x + 3\) and \(y = x^2\): \(x^2 = 2x + 3\) gives \(x = -1\) and \(x = 3\). Which one is on top? Let's test \(x = 0\): the line gives \(3\) and the parabola gives \(0\). So the line is on top, and

\[A = \int_{-1}^{3} \bigl(2x + 3 - x^2\bigr)\,dx = \Bigl[x^2 + 3x - \tfrac{x^3}{3}\Bigr]_{-1}^{3} = 9 - \Bigl(-\tfrac{5}{3}\Bigr) = \tfrac{32}{3}.\]

What if the curves cross? Then the curve on top changes. The area is \(\int_a^b |f(x) - g(x)|\,dx\), but in practice we find the crossing points, split the interval there, and use (top − bottom) on each piece. For \(y = \sin x\) and \(y = \cos x\) on \([0, \pi]\), they cross at \(x = \pi/4\). So the area is \(\int_0^{\pi/4} (\cos x - \sin x)\,dx + \int_{\pi/4}^{\pi} (\sin x - \cos x)\,dx = (\sqrt2 - 1) + (\sqrt2 + 1) = 2\sqrt2\).

Common mistake If we write \(\int_0^{\pi}(\sin x - \cos x)\,dx\) without splitting, we get \(2\), not \(2\sqrt2\). Does that mean the integral is wrong? No. The negative part simply cancelled some of the positive part. An area is never negative, so always check which curve is on top on each piece.

Integrating with respect to \(y\). Some regions are bounded by curves like \(x = f(y)\). For these, let's use horizontal strips instead. A horizontal strip has length (right − left) and thickness \(\Delta y\), so

\[A = \int_c^d \bigl[x_R(y) - x_L(y)\bigr]\,dy.\]

For the region between \(x = y^2\) and \(x = y + 2\), solving \(y^2 = y + 2\) gives \(y = -1\) and \(y = 2\). The line is on the right, so \(A = \int_{-1}^{2} (y + 2 - y^2)\,dy = \tfrac{9}{2}\). Notice that with vertical strips we would need two integrals, because the bottom boundary changes formula at \(x = 1\).

So here is a good habit: sketch first, decide which strips give one formula, then find the limits.

Key equations
\[ A = \int_a^b \bigl[f(x) - g(x)\bigr]\,dx \quad (f \ge g) \]
\[ A = \int_a^b \lvert f(x) - g(x)\rvert\,dx \]
\[ A = \int_c^d \bigl[x_R(y) - x_L(y)\bigr]\,dy \]

5.2Volumes

Now that we can find areas by slicing, let's use the same idea for volumes. We already know the volume of a simple solid like a cylinder: (area of the base) × (height). So, how do we find the volume of a solid that is not a cylinder? (Stewart §5.2)

Let's cut the solid into thin slabs with planes perpendicular to the \(x\)-axis. Each slab is almost a cylinder. If the cross-section at \(x\) has area \(A(x)\), the slab has volume about \(A(x)\,\Delta x\). We add the slabs and take the limit:

Definition If the cross-sectional area at \(x\) is \(A(x)\), for \(a \le x \le b\), then the volume of the solid is \[V = \int_a^b A(x)\,dx.\]

This works for any solid whose cross-sections we can describe. For example, let the base of a solid be the disk \(x^2 + y^2 \le 4\), and let every cross-section perpendicular to the \(x\)-axis be a square. The side of the square at \(x\) is the chord \(2\sqrt{4 - x^2}\), so \(A(x) = 4(4 - x^2)\) and \(V = \int_{-2}^{2} 4(4 - x^2)\,dx = \tfrac{128}{3}\).

Disks. When we rotate a region about a line, every cross-section perpendicular to that line is a circle. If the region under \(y = f(x)\) on \([a,b]\) is rotated about the \(x\)-axis, the slice at \(x\) is a disk of radius \(f(x)\). So \(A(x) = \pi [f(x)]^2\) and

\[V = \int_a^b \pi [f(x)]^2\,dx.\]

For example, rotating the region under \(y = \sqrt{x}\), \(0 \le x \le 4\), about the \(x\)-axis gives \(V = \int_0^4 \pi x\,dx = 8\pi\).

Washers. What if the region does not touch the axis? Then each slice is a disk with a hole, which we call a washer. If the outer radius is \(R\) and the inner radius is \(r\), its area is \(\pi R^2 - \pi r^2\). Let's rotate the region between \(y = x\) and \(y = x^2\) (\(0 \le x \le 1\)) about the \(x\)-axis. The line is farther from the axis, so \(R = x\) and \(r = x^2\), and \(V = \pi\int_0^1 (x^2 - x^4)\,dx = \tfrac{2\pi}{15}\).

Common mistake The washer area is \(\pi(R^2 - r^2)\), not \(\pi(R - r)^2\). Square each radius first, then subtract.

Other axes. Take note that a radius is always a distance from the axis of rotation. If we rotate the same region about the line \(y = -1\), every distance grows by 1: \(R = x + 1\) and \(r = x^2 + 1\). Then \(V = \pi\int_0^1 \bigl[(x+1)^2 - (x^2+1)^2\bigr]\,dx = \tfrac{7\pi}{15}\). For a horizontal axis \(y = k\), a radius is \(|y - k|\). For a vertical axis \(x = h\), we slice perpendicular to it (strips of thickness \(dy\)) and use radii \(|x - h|\), written in terms of \(y\).

Note Here is a recipe we can follow every time: (1) sketch the region and the axis; (2) draw one strip perpendicular to the axis; (3) rotate it and decide: disk or washer? (4) write \(R\) and \(r\) as distances to the axis; (5) integrate in the variable along the axis.
Key equations
\[ V = \int_a^b A(x)\,dx \]
\[ V = \int_a^b \pi [f(x)]^2\,dx \quad \text{(disks)} \]
\[ V = \int_a^b \pi\bigl(R^2 - r^2\bigr)\,dx \quad \text{(washers)} \]

★Key takeaways

  • Area between curves is \(\int (\text{top} - \text{bottom})\,dx\) or \(\int (\text{right} - \text{left})\,dy\); the integrand is always a positive length.
  • Set the curves equal to find where they meet; those intersections are usually our limits of integration.
  • If the curves cross inside the interval, split there so that we always subtract the lower curve from the upper one.
  • Volume by slicing is \(V = \int A(x)\,dx\), where \(A(x)\) is the area of the cross-section at \(x\).
  • Disks use \(\pi R^2\) and washers use \(\pi(R^2 - r^2)\); every radius is a distance from the axis of rotation.
  • For a vertical axis of rotation, slice horizontally and integrate in \(y\).

Example 4.1 Area enclosed by a parabola and a line

Find the area of the region enclosed by \(y = x^2 - 4x\) and \(y = 2x\).

(Similar to Stewart §5.1, Example 2)
Show solution (try it first)
Given
  • Curves: \(y = x^2 - 4x\) (parabola) and \(y = 2x\) (line).
  • The region is enclosed, so no limits are given.
  • Asked: the area \(A\).
Step 1: Find where the curves meet

The limits are the intersection points, so let's set the two formulas equal.

\[x^2 - 4x = 2x\]

\[x^2 - 6x = 0\]

\[x(x - 6) = 0\]

So \(x = 0\) and \(x = 6\).

Step 2: Decide which curve is on top

Let's test a number between 0 and 6, say \(x = 1\).

\[\text{line: } 2(1) = 2, \qquad \text{parabola: } 1^2 - 4(1) = -3\]

Since \(2 \gt -3\), the line is on top.

Step 3: Set up top minus bottom

The height of a strip is (top − bottom).

\[A = \int_0^6 \bigl[2x - (x^2 - 4x)\bigr]\,dx\]

\[A = \int_0^6 (6x - x^2)\,dx\]

Step 4: Integrate and substitute the limits

Use the power rule on each term, then substitute 6 and 0.

\[A = \Bigl[3x^2 - \tfrac{x^3}{3}\Bigr]_0^6\]

\[A = \Bigl(3(36) - \tfrac{216}{3}\Bigr) - 0\]

\[A = 108 - 72 = 36\]

Answer

So the area of the enclosed region is \(36\) square units.

Check

The answer is positive, as an area must be. Notice that part of the region is below the \(x\)-axis (the parabola dips to \(-4\) at \(x = 2\)), but (top − bottom) takes care of that for us.

Example 4.2 When the curves cross

Find the total area of the region enclosed by \(y = x^3\) and \(y = x\).

(Similar to Stewart §5.1)
Show solution (try it first)
Given
  • Curves: \(y = x^3\) and \(y = x\).
  • Asked: the total enclosed area.
Step 1: Find where the curves meet

Set the formulas equal.

\[x^3 = x\]

\[x^3 - x = 0\]

\[x(x - 1)(x + 1) = 0\]

So \(x = -1\), \(x = 0\) and \(x = 1\). There are two pieces: \([-1, 0]\) and \([0, 1]\).

Step 2: Check which curve is on top on each piece

On \([-1, 0]\), test \(x = -\tfrac12\): \(x^3 = -\tfrac18\) and \(x = -\tfrac12\). Since \(-\tfrac18 \gt -\tfrac12\), the cubic is on top.

On \([0, 1]\), test \(x = \tfrac12\): \(x^3 = \tfrac18\) and \(x = \tfrac12\). Now the line is on top.

Step 3: Integrate on the left piece

Use (top − bottom) = \(x^3 - x\).

\[\int_{-1}^{0} (x^3 - x)\,dx = \Bigl[\tfrac{x^4}{4} - \tfrac{x^2}{2}\Bigr]_{-1}^{0}\]

\[= 0 - \Bigl(\tfrac14 - \tfrac12\Bigr) = \tfrac14\]

Step 4: Integrate on the right piece

Use (top − bottom) = \(x - x^3\).

\[\int_{0}^{1} (x - x^3)\,dx = \Bigl[\tfrac{x^2}{2} - \tfrac{x^4}{4}\Bigr]_{0}^{1}\]

\[= \tfrac12 - \tfrac14 = \tfrac14\]

Step 5: Add the pieces

\[A = \tfrac14 + \tfrac14 = \tfrac12\]

Answer

So the total enclosed area is \(\tfrac12\) square unit.

Check

What if we had written \(\int_{-1}^{1} (x - x^3)\,dx\) without splitting? We would get \(0\), because the two equal pieces cancel. That is why we always split where the curves cross.

Example 4.3 Choosing horizontal strips

Find the area of the region in the first quadrant bounded by \(y = \sqrt{x}\), \(y = x - 6\) and the \(x\)-axis.

(Similar to Stewart §5.1, Example 6)
Show solution (try it first)
Given
  • Boundaries: \(y = \sqrt{x}\), \(y = x - 6\), and \(y = 0\).
  • Asked: the area \(A\).
Step 1: Decide which strips to use

With vertical strips the bottom is the \(x\)-axis for \(0 \le x \le 6\) but the line for \(6 \le x \le 9\), so we would need two integrals. With horizontal strips the left side is always the curve and the right side is always the line. So let's use horizontal strips.

Step 2: Write the curves as x in terms of y

\[y = \sqrt{x} \;\Rightarrow\; x = y^2 \quad \text{(left)}\]

\[y = x - 6 \;\Rightarrow\; x = y + 6 \quad \text{(right)}\]

Step 3: Find the limits in y

The curves meet where

\[y^2 = y + 6\]

\[y^2 - y - 6 = 0\]

\[(y - 3)(y + 2) = 0\]

In the first quadrant we keep \(y = 3\). The bottom of the region is \(y = 0\).

Step 4: Integrate right minus left

\[A = \int_0^3 \bigl[(y + 6) - y^2\bigr]\,dy\]

\[A = \Bigl[\tfrac{y^2}{2} + 6y - \tfrac{y^3}{3}\Bigr]_0^3\]

\[A = \tfrac92 + 18 - 9 = \tfrac{27}{2}\]

Answer

So the area is \(\tfrac{27}{2} = 13.5\) square units.

Check

The long way with vertical strips, \(\int_0^6 \sqrt{x}\,dx + \int_6^9 \bigl[\sqrt{x} - (x - 6)\bigr]\,dx\), also gives \(13.5\). Same answer, twice the work.

Example 4.4 The volume of a sphere by disks

Rotate the region under the semicircle \(y = \sqrt{9 - x^2}\), \(-3 \le x \le 3\), about the \(x\)-axis. This gives a sphere of radius 3. Use disks to find its volume.

(Similar to Stewart §5.2, Example 1)
Show solution (try it first)
Given
  • Curve: \(y = \sqrt{9 - x^2}\) on \([-3, 3]\).
  • Axis of rotation: the \(x\)-axis.
  • Asked: the volume \(V\).
Step 1: Describe one slice

A vertical strip at \(x\) touches the axis, so it sweeps out a disk. Its radius is the height of the curve.

\[R = \sqrt{9 - x^2}\]

Step 2: Write the cross-sectional area

The area of a disk is \(\pi R^2\). Squaring removes the square root.

\[A(x) = \pi\bigl(\sqrt{9 - x^2}\bigr)^2 = \pi(9 - x^2)\]

Step 3: Integrate

\[V = \int_{-3}^{3} \pi(9 - x^2)\,dx = \pi\Bigl[9x - \tfrac{x^3}{3}\Bigr]_{-3}^{3}\]

\[V = \pi\bigl[(27 - 9) - (-27 + 9)\bigr]\]

\[V = \pi(18 + 18) = 36\pi\]

Answer

So the volume of the sphere is \(36\pi \approx 113.1\) cubic units.

Check

The familiar formula \(V = \tfrac43\pi r^3\) with \(r = 3\) gives \(\tfrac43\pi(27) = 36\pi\). It agrees.

Example 4.5 Washers about a vertical line

The region bounded by \(y = x^2\) and \(y = 2x\) is rotated about the line \(x = -1\). Find the volume of the solid.

(Similar to Stewart §5.2, Example 6)
Show solution (try it first)
Given
  • Curves: \(y = x^2\) and \(y = 2x\).
  • Axis of rotation: the vertical line \(x = -1\).
  • Asked: the volume \(V\).
Step 1: Choose the strips

The axis is vertical, so we slice perpendicular to it: horizontal strips of thickness \(dy\). Each strip sweeps out a washer, and we integrate in \(y\).

Step 2: Write the curves in terms of y and find the limits

\[y = 2x \;\Rightarrow\; x = \tfrac{y}{2}, \qquad y = x^2 \;\Rightarrow\; x = \sqrt{y}\]

The curves meet at \((0, 0)\) and \((2, 4)\), so \(0 \le y \le 4\). For \(0 < y < 4\), \(\sqrt{y} > \tfrac{y}{2}\), so the parabola is farther from the axis.

Step 3: Measure the radii from x = −1

A radius is a distance from the axis, so we subtract \(-1\).

\[R = \sqrt{y} - (-1) = \sqrt{y} + 1\]

\[r = \tfrac{y}{2} - (-1) = \tfrac{y}{2} + 1\]

Step 4: Simplify R² − r²

\[R^2 = y + 2\sqrt{y} + 1\]

\[r^2 = \tfrac{y^2}{4} + y + 1\]

\[R^2 - r^2 = 2\sqrt{y} - \tfrac{y^2}{4}\]

Step 5: Integrate

\[V = \pi\int_0^4 \Bigl(2\sqrt{y} - \tfrac{y^2}{4}\Bigr)dy = \pi\Bigl[\tfrac43 y^{3/2} - \tfrac{y^3}{12}\Bigr]_0^4\]

\[V = \pi\Bigl(\tfrac43 \cdot 8 - \tfrac{64}{12}\Bigr)\]

\[V = \pi\Bigl(\tfrac{32}{3} - \tfrac{16}{3}\Bigr) = \tfrac{16\pi}{3}\]

Answer

So the volume is \(\tfrac{16\pi}{3} \approx 16.76\) cubic units.

Check

In Module 5 we will meet cylindrical shells, and \(2\pi\int_0^2 (x + 1)(2x - x^2)\,dx\) also gives \(\tfrac{16\pi}{3}\). The usual mistake here is \(R = \sqrt{y}\) and \(r = y/2\), which measures from the \(y\)-axis instead of from \(x = -1\).
