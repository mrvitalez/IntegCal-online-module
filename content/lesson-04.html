5.1Areas Between Curves

In Module 1 we asked how to find the area under one curve. Now let's ask a slightly bigger question: what is the area of the region between two curves, \(y = f(x)\) on top and \(y = g(x)\) below, from \(x = a\) to \(x = b\)? We do exactly what we did before. Divide the region into thin vertical strips, approximate each one by a rectangle, add, and take the limit.

What is the height of each rectangle now? It is no longer \(f(x_i)\); it is the distance from the bottom curve to the top curve, \(f(x_i) - g(x_i)\). So the Riemann sum is \(\sum [f(x_i^*) - g(x_i^*)]\,\Delta x\), and in the limit:

Area between curves The area \(A\) of the region bounded by \(y = f(x)\), \(y = g(x)\), \(x = a\) and \(x = b\), where \(f\) and \(g\) are continuous and \(f(x) \ge g(x)\) on \([a, b]\), is \[A = \int_a^b \big[f(x) - g(x)\big]\,dx = \int_a^b (y_{\text{top}} - y_{\text{bottom}})\,dx.\]

Take note that this works even if part of the region is below the \(x\)-axis: the height "top minus bottom" is always positive. A good habit is to always sketch the region and draw one typical strip. The sketch tells us which curve is on top.

Where are the limits? Often the problem does not give \(a\) and \(b\); the region is enclosed by the curves themselves. Then the limits are the \(x\)-coordinates of the intersection points: set \(f(x) = g(x)\) and solve.

What if the curves cross? Then "top" and "bottom" switch places. We split the interval at each crossing and integrate \(|f(x) - g(x)|\), that is, top minus bottom on each piece.

Horizontal strips. Some regions are described more easily with \(x\) as a function of \(y\), for example the region between the sideways parabola \(x = y^2\) and the line \(x = y + 2\). With vertical strips the bottom boundary changes formula halfway across. With horizontal strips it does not: each strip has length right minus left and thickness \(\Delta y\), so \[A = \int_c^d (x_{\text{right}} - x_{\text{left}})\,dy.\]

Common mistake Integrating \(f(x) - g(x)\) across a point where the curves cross. Then the two pieces partly cancel and the answer is too small (it can even be 0 or negative). Find every intersection inside \([a, b]\) first, and keep "top minus bottom" positive on each piece.
Key equations
\[ A = \int_a^b \big(y_{\text{top}} - y_{\text{bottom}}\big)\,dx \]
\[ A = \int_c^d \big(x_{\text{right}} - x_{\text{left}}\big)\,dy \]
\[ A = \int_a^b \big|f(x) - g(x)\big|\,dx \]

5.2Volumes

Recall how we get the volume of a cylinder: (area of the base) × (height). A loaf of bread is not a cylinder, but if we slice it, each thin slice is almost a cylinder. So again we approximate and take a limit. If a solid lies between \(x = a\) and \(x = b\), and the cross-section perpendicular to the \(x\)-axis at \(x\) has area \(A(x)\), then a slice of thickness \(\Delta x\) has volume about \(A(x)\,\Delta x\). Adding the slices and letting \(\Delta x \to 0\):

Volume by slicing \[V = \int_a^b A(x)\,dx,\] where \(A(x)\) is the area of the cross-section at \(x\). (For slices perpendicular to the \(y\)-axis, \(V = \int_c^d A(y)\,dy\).)

Solids of revolution: disks. If we rotate the region under \(y = f(x)\) about the \(x\)-axis, every cross-section is a disk of radius \(R = f(x)\), so \(A(x) = \pi R^2\) and \[V = \int_a^b \pi\,[R(x)]^2\,dx.\] This is how, for example, we can prove the volume of a planet modelled as a sphere: rotating the semicircle \(y = \sqrt{r^2 - x^2}\) about the \(x\)-axis gives \(V = \int_{-r}^{r}\pi(r^2 - x^2)\,dx = \tfrac43\pi r^3\).

Washers. If the region being rotated does not touch the axis, each cross-section is a washer (a disk with a hole). With outer radius \(R\) and inner radius \(r\), the area is \(\pi R^2 - \pi r^2\), so \[V = \int_a^b \pi\big([R(x)]^2 - [r(x)]^2\big)\,dx.\]

Other axes. Each radius is a distance from the axis of rotation. For a horizontal axis \(y = k\), a radius is \(|y_{\text{curve}} - k|\). For example, rotating about \(y = -1\), a curve \(y = x\) is at distance \(x - (-1) = x + 1\) from the axis. For rotation about a vertical axis, use horizontal slices and write everything in \(y\).

Common mistake Writing \(\pi(R - r)^2\) for a washer. The area of a washer is \(\pi R^2 - \pi r^2\), which is not the same thing. Also, when the axis is not the \(x\)-axis, the radius is not just "the \(y\)-value"; measure it from the axis.
Key equations
\[ V = \int_a^b A(x)\,dx \]
\[ \text{disk: } V = \int_a^b \pi R^2\,dx, \qquad \text{washer: } V = \int_a^b \pi\left(R^2 - r^2\right)dx \]

★Key takeaways

  • Area between curves: integrate (top − bottom) with vertical strips, or (right − left) with horizontal strips.
  • When no limits are given, the limits are the intersection points of the curves.
  • If the curves cross, split the interval so that the height stays positive on each piece.
  • Volume by slicing: V = ∫ A(x) dx, where A(x) is the area of the cross-section.
  • Disk method: V = ∫ πR² dx; washer method: V = ∫ π(R² − r²) dx.
  • Every radius is a distance from the axis of rotation, so it changes when the axis moves.

Example 4.1 Area enclosed by a line and a parabola

Find the area of the region enclosed by \(y = 2x + 3\) and \(y = x^2\).

(Similar to Stewart §5.1, Example 2)
Show solution (try it first)

Given: the curves \(y = 2x + 3\) and \(y = x^2\). Find: the enclosed area.

Plan: No limits are given, so first find the intersection points. Then decide which curve is on top and integrate top minus bottom.

Step 1. Find the intersections by setting the two equal.

\[x^2 = 2x + 3 \;\Rightarrow\; x^2 - 2x - 3 = 0 \;\Rightarrow\; (x - 3)(x + 1) = 0 \;\Rightarrow\; x = -1,\ 3\]

Step 2. Decide which curve is on top with a test point between them, say \(x = 0\): the line gives \(3\), the parabola gives \(0\). So the line is on top (Figure 4.1).

Step 3. Set up the integral: top minus bottom.

\[A = \int_{-1}^{3}\big[(2x + 3) - x^2\big]\,dx\]

Step 4. Integrate term by term.

\[= \left[x^2 + 3x - \frac{x^3}{3}\right]_{-1}^{3}\]

Step 5. Substitute the limits.

\[= \left(9 + 9 - 9\right) - \left(1 - 3 + \frac13\right) = 9 - \left(-\frac53\right) = \frac{32}{3}\]

Answer: \(\boxed{A = \dfrac{32}{3} \approx 10.67}\) square units.

Check: The region fits inside a box 4 units wide (from \(-1\) to 3) and at most 4 units tall (the gap is largest at \(x = 1\): \(5 - 1 = 4\)). A parabolic segment fills two-thirds of its box: \(\tfrac23 \cdot 4 \cdot 4 = \tfrac{32}{3}\). It matches.

Example 4.2 Horizontal strips

Find the area of the region enclosed by \(x = y^2\) and \(x = y + 2\).

(Similar to Stewart §5.1, Example 6)
Show solution (try it first)

Given: the curves \(x = y^2\) and \(x = y + 2\). Find: the enclosed area.

Plan: Both curves are already solved for \(x\), so use horizontal strips: right minus left, integrated in \(y\).

Step 1. Find the intersections in \(y\).

\[y^2 = y + 2 \;\Rightarrow\; y^2 - y - 2 = 0 \;\Rightarrow\; (y - 2)(y + 1) = 0 \;\Rightarrow\; y = -1,\ 2\]

Step 2. Decide which curve is on the right. At \(y = 0\): the line gives \(x = 2\), the parabola gives \(x = 0\). The line is on the right.

Step 3. Set up and integrate right minus left.

\[A = \int_{-1}^{2}\big[(y + 2) - y^2\big]\,dy = \left[\frac{y^2}{2} + 2y - \frac{y^3}{3}\right]_{-1}^{2}\]

Step 4. Substitute the limits.

\[= \left(2 + 4 - \frac83\right) - \left(\frac12 - 2 + \frac13\right) = \frac{10}{3} - \left(-\frac76\right) = \frac{20}{6} + \frac76 = \frac{27}{6} = \frac92\]

Answer: \(\boxed{A = \dfrac92 = 4.5}\) square units.

Check: With vertical strips we would need two integrals (the bottom boundary is the parabola for \(0 \le x \le 1\) and the line for \(1 \le x \le 4\)): \(\int_0^1 2\sqrt x\,dx + \int_1^4 (\sqrt x - x + 2)\,dx = \tfrac43 + \tfrac{19}{6} = \tfrac92\). Same area, more work.

Example 4.3 Curves that cross

Find the area of the region bounded by \(y = \sin x\), \(y = \cos x\), \(x = 0\) and \(x = \pi/2\).

(Similar to Stewart §5.1, Example 5)
Show solution (try it first)

Given: \(y = \sin x\), \(y = \cos x\) on \([0, \pi/2]\). Find: the area.

Plan: The curves cross inside the interval, so split the interval there and use top minus bottom on each piece.

Step 1. Find the crossing: \(\sin x = \cos x \Rightarrow \tan x = 1 \Rightarrow x = \pi/4\).

Step 2. On \([0, \pi/4]\), \(\cos x \ge \sin x\) (at \(x = 0\): \(1 \gt 0\)). On \([\pi/4, \pi/2]\), \(\sin x \ge \cos x\).

\[A = \int_0^{\pi/4}(\cos x - \sin x)\,dx + \int_{\pi/4}^{\pi/2}(\sin x - \cos x)\,dx\]

Step 3. Integrate each piece.

\[= \Big[\sin x + \cos x\Big]_0^{\pi/4} + \Big[-\cos x - \sin x\Big]_{\pi/4}^{\pi/2}\]

Step 4. Evaluate. Use \(\sin\frac\pi4 = \cos\frac\pi4 = \frac{\sqrt2}{2}\).

\[= \left(\sqrt2 - 1\right) + \left(-1 + \sqrt2\right) = 2\sqrt2 - 2\]

Answer: \(\boxed{A = 2\sqrt2 - 2 \approx 0.828}\) square units.

Check: By symmetry about \(x = \pi/4\), the two pieces are equal, each \(\sqrt2 - 1 \approx 0.414\). If we had integrated \(\cos x - \sin x\) across the whole interval, the pieces would cancel and give 0, which is clearly not an area.

Example 4.4 Disks: the volume of a sphere

Use the disk method to show that a sphere of radius \(r\) (for example, a planet) has volume \(\tfrac43\pi r^3\).

(Similar to Stewart §5.2, Example 1)
Show solution (try it first)

Given: a sphere of radius \(r\), made by rotating the semicircle \(y = \sqrt{r^2 - x^2}\) about the \(x\)-axis. Find: its volume.

Plan: Each slice perpendicular to the \(x\)-axis is a disk whose radius is the height of the semicircle.

Step 1. Find the radius of the disk at \(x\).

\[R(x) = \sqrt{r^2 - x^2}, \qquad -r \le x \le r\]

Step 2. Area of the cross-section.

\[A(x) = \pi R^2 = \pi\left(r^2 - x^2\right)\]

Step 3. Integrate from \(-r\) to \(r\). The integrand is even, so we can double the integral from 0 to \(r\).

\[V = \int_{-r}^{r}\pi(r^2 - x^2)\,dx = 2\pi\int_0^r (r^2 - x^2)\,dx = 2\pi\left[r^2x - \frac{x^3}{3}\right]_0^r\]

Step 4. Evaluate.

\[= 2\pi\left(r^3 - \frac{r^3}{3}\right) = 2\pi\cdot\frac{2r^3}{3} = \frac43\pi r^3\]

Answer: \(\boxed{V = \tfrac43\pi r^3}\). That is the formula we memorized in high school, and now we know where it comes from.

Check: Units: \(r^3\) is a volume. Size: the sphere fits in a cube of side \(2r\), volume \(8r^3\), and \(\tfrac43\pi \approx 4.19\) is about half of 8, which is reasonable for a ball in a box.

Example 4.5 Washers about the line y = −1

The region enclosed by \(y = x\) and \(y = x^2\) is rotated about the line \(y = -1\). Find the volume.

(Similar to Stewart §5.2, Example 5)
Show solution (try it first)

Given: the region between \(y = x\) (top) and \(y = x^2\) (bottom), axis \(y = -1\). Find: the volume.

Plan: The region does not touch the axis, so each slice is a washer. Both radii are distances from the line \(y = -1\).

Step 1. Find the intersections: \(x^2 = x \Rightarrow x(x - 1) = 0 \Rightarrow x = 0, 1\). On \([0, 1]\), \(x \ge x^2\).

Step 2. Find the radii (distance from \(y = -1\)): the far curve is \(y = x\), the near curve is \(y = x^2\).

\[R(x) = x - (-1) = x + 1, \qquad r(x) = x^2 - (-1) = x^2 + 1\]

Step 3. Set up the washer integral.

\[V = \pi\int_0^1\left[(x+1)^2 - (x^2+1)^2\right]dx\]

Step 4. Expand and simplify the integrand.

\[(x^2 + 2x + 1) - (x^4 + 2x^2 + 1) = -x^4 - x^2 + 2x\]

Step 5. Integrate and evaluate.

\[V = \pi\left[-\frac{x^5}{5} - \frac{x^3}{3} + x^2\right]_0^1 = \pi\left(-\frac15 - \frac13 + 1\right) = \frac{7\pi}{15}\]

Answer: \(\boxed{V = \dfrac{7\pi}{15} \approx 1.466}\) cubic units.

Check: The integrand \(-x^4 - x^2 + 2x\) is positive on \((0, 1)\) (at \(x = \tfrac12\) it is \(0.6875\)), so \(R \gt r\) everywhere, as it must be. Using \(\pi(R - r)^2\) by mistake would give a much smaller number.
