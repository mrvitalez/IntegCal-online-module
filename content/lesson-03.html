4.5The Substitution Rule: Indefinite Integrals

Now that we have an idea of how to get the area of a region through integration, let's dive into one strategy for solving integrals, the Substitution Rule (Stewart §4.5). Why do we need a strategy? Our table from Module 2 handles powers and basic trig functions, but look at this one: \[\int 2x\sqrt{1 + x^2}\,dx.\] This is a little more complicated than what we had in our activities and examples. It is not in the table, and there is no "product rule" for integrals. So, what do we do here?

Notice that \(1 + x^2\) sits inside the root, and its derivative, \(2x\), is sitting right outside. So we let \[u = 1 + x^2, \qquad du = 2x\,dx.\] Now the whole integral is written in \(u\): \(\int \sqrt{u}\,du = \int u^{1/2}\,du = \tfrac23 u^{3/2} + C = \tfrac23(1 + x^2)^{3/2} + C\). We can double check with the Chain Rule: \(\frac{d}{dx}\,\tfrac23(1+x^2)^{3/2} = \tfrac23\cdot\tfrac32(1+x^2)^{1/2}\cdot 2x = 2x\sqrt{1+x^2}\). (Example 1 writes out every step.)

Where does it come from? The Chain Rule says \(\frac{d}{dx}F(g(x)) = F'(g(x))\,g'(x)\). Reading this backwards, with \(F' = f\), gives \(\int f(g(x))\,g'(x)\,dx = F(g(x)) + C\). If we name the inner function \(u = g(x)\), then \(du = g'(x)\,dx\), and the left side becomes \(\int f(u)\,du\).

The Substitution Rule If \(u = g(x)\) is differentiable and \(f\) is continuous on the range of \(g\), then \[\int f(g(x))\,g'(x)\,dx = \int f(u)\,du.\]

The procedure.

  1. Let \(u\) be an inner function (inside a power, root or trig function) whose derivative appears, up to a constant factor, elsewhere in the integrand.
  2. Compute \(du = g'(x)\,dx\) and solve for the piece you need, for example \(x^3\,dx = \tfrac14\,du\).
  3. Rewrite the entire integral in \(u\) and \(du\). No \(x\) may be left over.
  4. Integrate in \(u\), then substitute back \(u = g(x)\). Double check by differentiating.

Fixing constant factors. Take note that the derivative of \(u\) only has to appear up to a constant. For \(\int \cos 5x\,dx\), let \(u = 5x\); then \(du = 5\,dx\), so \(dx = \tfrac15\,du\), and \(\int \cos 5x\,dx = \tfrac15\int \cos u\,du = \tfrac15\sin 5x + C\). The same idea gives \(\int \cos(kx)\,dx = \tfrac1k \sin(kx) + C\), and likewise for \(\sin(kx)\) and \(\sec^2(kx)\).

When an extra \(x\) is left over. Sometimes, after choosing \(u\), some \(x\) remains. Then we solve the substitution for \(x\) and replace it. In \(\int x^5\sqrt{1 + x^2}\,dx\), the choice \(u = 1 + x^2\) uses up one \(x\) (in \(x\,dx = \tfrac12\,du\)), and the leftover \(x^4\) becomes \((u - 1)^2\). See Example 5.

Common mistake Writing \(\int \cos(x^2)\,dx = \frac{\sin(x^2)}{2x} + C\). We cannot divide by a non-constant to "fix" a missing factor. Differentiate the answer and you will see it is wrong. Substitution works only when the needed factor \(g'(x)\) is really there, up to a constant.
Key equations
\[ \int f(g(x))\,g'(x)\,dx = \int f(u)\,du, \qquad u = g(x),\ du = g'(x)\,dx \]
\[ \int \cos(kx)\,dx = \frac{1}{k}\sin(kx) + C \]

4.5Substitution in Definite Integrals and Symmetry

So, what changes when the integral has limits? We have two options. We can find the indefinite integral first (back in terms of \(x\)) and then use FTC2 with the original limits. Or, often faster, we can change the limits along with the variable.

Substitution Rule for Definite Integrals If \(g'\) is continuous on \([a,b]\) and \(f\) is continuous on the range of \(u = g(x)\), then \[\int_a^b f(g(x))\,g'(x)\,dx = \int_{g(a)}^{g(b)} f(u)\,du.\]

The new limits are the values of \(u\) at the old limits. Once we have switched to \(u\), we never go back to \(x\).

Example. Let's evaluate \(\int_0^{\sqrt{\pi/2}} 2x\cos(x^2)\,dx\). With \(u = x^2\), \(du = 2x\,dx\). When \(x = 0\), \(u = 0\); when \(x = \sqrt{\pi/2}\), \(u = \pi/2\). So the integral equals \(\int_0^{\pi/2}\cos u\,du = \big[\sin u\big]_0^{\pi/2} = 1\). Notice in Figure 3.2 that the substitution reshapes the region into the region under \(\cos u\) on \([0, \pi/2]\) without changing its area.

Another. \(\int_0^1 \frac{x^2}{(x^3 + 1)^2}\,dx\): let \(u = x^3 + 1\), \(du = 3x^2\,dx\), so the limits become \(1\) to \(2\). Then \(\tfrac13\int_1^2 u^{-2}\,du = \tfrac13\big[-u^{-1}\big]_1^2 = \tfrac13\left(-\tfrac12 + 1\right) = \tfrac16\).

Common mistake Changing the variable but keeping the old limits, e.g. writing \(\int_0^1 \ldots\,du\) when \(u\) actually runs from 1 to 2. Either change the limits, or substitute back to \(x\) before evaluating. Never mix the two.

Symmetry. Substitution also gives us two facts that save a lot of work. Suppose \(f\) is continuous on \([-a, a]\).

  • If \(f\) is even (\(f(-x) = f(x)\), graph symmetric about the \(y\)-axis), then \(\int_{-a}^{a} f(x)\,dx = 2\int_0^{a} f(x)\,dx\).
  • If \(f\) is odd (\(f(-x) = -f(x)\), graph symmetric about the origin), then \(\int_{-a}^{a} f(x)\,dx = 0\).

Why? Split \(\int_{-a}^{a} = \int_{-a}^{0} + \int_0^{a}\) and let \(u = -x\) in the first piece: \(\int_{-a}^{0} f(x)\,dx = \int_0^{a} f(-u)\,du\). For an even \(f\) this equals \(\int_0^a f(u)\,du\); for an odd \(f\) it equals \(-\int_0^a f(u)\,du\), which cancels the second piece. In Figure 3.3, the area of an odd function on the left of the axis is the negative of the area on the right.

Example. \(\int_{-2}^{2}\big(x^4 + x^5\sqrt{1 + x^2}\big)\,dx\). The term \(x^5\sqrt{1+x^2}\) is odd (odd × even), so it contributes 0, and \(x^4\) is even. The integral is \(2\int_0^2 x^4\,dx = 2\cdot\tfrac{32}{5} = \tfrac{64}{5}\). We did not even need an antiderivative of the messy term.

Recall the products: odd × odd = even, even × even = even, odd × even = odd. So \(x^3\cos x\) is odd and \(x\sin x\) is even. Take note: symmetry only works on an interval centred at 0.

Key equations
\[ \int_a^b f(g(x))\,g'(x)\,dx = \int_{g(a)}^{g(b)} f(u)\,du \]
\[ f \text{ even: } \int_{-a}^{a} f(x)\,dx = 2\int_0^{a} f(x)\,dx \]
\[ f \text{ odd: } \int_{-a}^{a} f(x)\,dx = 0 \]

★Key takeaways

  • Substitution reverses the Chain Rule: ∫ f(g(x)) g′(x) dx = ∫ f(u) du with u = g(x) and du = g′(x) dx.
  • Choose u as an inner function whose derivative appears in the integrand, up to a constant factor (for ∫2x√(1 + x²) dx, u = 1 + x²).
  • After substituting, every x (including dx) must be replaced; solve u = g(x) for x if an extra x is left over.
  • Double check an indefinite integral by differentiating the answer with the Chain Rule.
  • In a definite integral, change the limits to u-values and never return to x, or else substitute back before evaluating.
  • Over [−a, a], an odd function integrates to 0 and an even function gives twice the integral over [0, a].

Example 3.1 A first substitution

Find \(\displaystyle\int 2x\sqrt{1 + x^2}\,dx\).

(Instr. Vitalez's notes, Example #5 (compare Stewart §4.5, Example 1))
Show solution (try it first)
Given
  • \(\int 2x\sqrt{1 + x^2}\,dx\)
  • Find: the general antiderivative
Step 1: choose u and find du

The inner function \(1 + x^2\) sits under the root, and its derivative \(2x\) is a factor outside. So we let

\[u = 1 + x^2\]

\[du = 2x\,dx\]

Step 2: substitute so the integral is in u only

The factor \(2x\,dx\) becomes \(du\) and \(\sqrt{1+x^2}\) becomes \(\sqrt u\).

\[\int 2x\sqrt{1 + x^2}\,dx = \int \sqrt{u}\,du = \int u^{1/2}\,du\]

Step 3: integrate with the power rule

\[= \frac{u^{3/2}}{3/2} + C = \frac23\,u^{3/2} + C\]

Step 4: substitute back u = 1 + x²

\[= \frac23\left(1 + x^2\right)^{3/2} + C\]

Answer

\(\displaystyle\int 2x\sqrt{1 + x^2}\,dx = \frac23\left(1 + x^2\right)^{3/2} + C\).

Check

We can double check with the Chain Rule:

\[\frac{d}{dx}\left[\frac23\left(1 + x^2\right)^{3/2} + C\right] = \frac23\cdot\frac32\left(1 + x^2\right)^{1/2}(2x) = 2x\sqrt{1 + x^2}\]

Example 3.2 Substitution inside a cosine

Find \(\displaystyle\int x^3\cos\left(x^4 + 2\right)dx\).

(Instr. Vitalez's notes, Example #6 (compare Stewart §4.5, Example 1))
Show solution (try it first)
Given
  • \(\int x^3\cos(x^4 + 2)\,dx\)
  • Find: the general antiderivative
Step 1: choose u and find du

The inner function is \(x^4 + 2\); its derivative \(4x^3\) matches the factor \(x^3\) up to the constant 4.

\[u = x^4 + 2\]

\[du = 4x^3\,dx \quad\Longrightarrow\quad x^3\,dx = \frac14\,du\]

Step 2: substitute

\[\int x^3\cos\left(x^4 + 2\right)dx = \int \cos u\cdot\frac14\,du = \frac14\int \cos u\,du\]

Step 3: integrate

\[= \frac14\sin u + C\]

Step 4: substitute back u = x⁴ + 2

\[= \frac14\sin\left(x^4 + 2\right) + C\]

Answer

\(\displaystyle\int x^3\cos\left(x^4 + 2\right)dx = \frac14\sin\left(x^4 + 2\right) + C\).

Check

\(\dfrac{d}{dx}\left[\tfrac14\sin(x^4 + 2)\right] = \tfrac14\cos(x^4 + 2)\cdot 4x^3 = x^3\cos(x^4 + 2)\). ✔

Example 3.3 Fixing a constant factor

Evaluate \(\displaystyle\int \sqrt{2x + 1}\,dx\).

(Instr. Vitalez's notes, Example #7 (compare Stewart §4.5, Example 2))
Show solution (try it first)
Given
  • \(\int \sqrt{2x + 1}\,dx\)
  • Find: the general antiderivative
Step 1: choose u and find du

Let the expression under the root be \(u\).

\[u = 2x + 1\]

\[du = 2\,dx \quad\Longrightarrow\quad dx = \frac12\,du\]

The factor 2 is missing from the integrand, but it is only a constant, so we can fix it.

Step 2: substitute

\[\int \sqrt{2x + 1}\,dx = \int \sqrt{u}\cdot\frac12\,du = \frac12\int u^{1/2}\,du\]

Step 3: integrate with the power rule

\[= \frac12\cdot\frac{u^{3/2}}{3/2} + C = \frac12\cdot\frac23\,u^{3/2} + C = \frac13\,u^{3/2} + C\]

Step 4: substitute back u = 2x + 1

\[= \frac13\,(2x + 1)^{3/2} + C\]

Answer

\(\displaystyle\int \sqrt{2x + 1}\,dx = \frac13\,(2x + 1)^{3/2} + C\).

Check

\(\dfrac{d}{dx}\left[\tfrac13(2x+1)^{3/2}\right] = \tfrac13\cdot\tfrac32(2x+1)^{1/2}\cdot 2 = \sqrt{2x+1}\). ✔

Example 3.4 A root in the denominator, and cos 5x

Find (a) \(\displaystyle\int \frac{x}{\sqrt{1 - 4x^2}}\,dx\)   (b) \(\displaystyle\int \cos 5x\,dx\).

(Instr. Vitalez's notes, Activity #4, items 1 and 2 (compare Stewart §4.5))
Show solution (try it first)
Given
  • (a) \(\int x\,(1 - 4x^2)^{-1/2}\,dx\)
  • (b) \(\int \cos 5x\,dx\)
  • Find: the general antiderivative of each
Step 1: in (a), choose u and solve for x dx

\[u = 1 - 4x^2\]

\[du = -8x\,dx \quad\Longrightarrow\quad x\,dx = -\frac18\,du\]

Step 2: substitute and integrate

\[\int \frac{x}{\sqrt{1 - 4x^2}}\,dx = -\frac18\int u^{-1/2}\,du = -\frac18\cdot\frac{u^{1/2}}{1/2} + C = -\frac14\,u^{1/2} + C\]

Step 3: substitute back

\[= -\frac14\sqrt{1 - 4x^2} + C\]

Step 4: in (b), let u = 5x

\[u = 5x, \qquad du = 5\,dx \quad\Longrightarrow\quad dx = \frac15\,du\]

\[\int \cos 5x\,dx = \frac15\int \cos u\,du = \frac15\sin u + C = \frac15\sin 5x + C\]

Answer

(a) \(-\dfrac14\sqrt{1 - 4x^2} + C\)   (b) \(\dfrac15\sin 5x + C\).

Check

(a) \(\dfrac{d}{dx}\left[-\tfrac14(1-4x^2)^{1/2}\right] = -\tfrac14\cdot\tfrac12(1-4x^2)^{-1/2}(-8x) = \dfrac{x}{\sqrt{1-4x^2}}\). (b) \(\dfrac{d}{dx}\left[\tfrac15\sin 5x\right] = \cos 5x\). ✔

Example 3.5 Substitution with a leftover x

Find \(\displaystyle\int \sqrt{1 + x^2}\;x^5\,dx\).

(Instr. Vitalez's notes, Activity #4, item 3 (compare Stewart §4.5, Example 5))
Show solution (try it first)
Given
  • \(\int \sqrt{1 + x^2}\,x^5\,dx\)
  • Find: the general antiderivative
Step 1: choose u and find du

\[u = 1 + x^2\]

\[du = 2x\,dx \quad\Longrightarrow\quad x\,dx = \frac12\,du\]

Step 2: rewrite the leftover x⁴ in terms of u

We split \(x^5 = x^4\cdot x\). The \(x\) goes with \(dx\). For the rest, solve \(u = 1 + x^2\) for \(x^2\):

\[x^2 = u - 1 \quad\Longrightarrow\quad x^4 = (u - 1)^2\]

Step 3: substitute and expand

\[\int \sqrt{1 + x^2}\,x^4\cdot x\,dx = \int u^{1/2}(u - 1)^2\cdot\frac12\,du\]

\[= \frac12\int u^{1/2}\left(u^2 - 2u + 1\right)du = \frac12\int \left(u^{5/2} - 2u^{3/2} + u^{1/2}\right)du\]

Step 4: integrate term by term

\[= \frac12\left[\frac27 u^{7/2} - 2\cdot\frac25 u^{5/2} + \frac23 u^{3/2}\right] + C = \frac17 u^{7/2} - \frac25 u^{5/2} + \frac13 u^{3/2} + C\]

Step 5: substitute back u = 1 + x²

\[= \frac17\left(1 + x^2\right)^{7/2} - \frac25\left(1 + x^2\right)^{5/2} + \frac13\left(1 + x^2\right)^{3/2} + C\]

Answer

\(\displaystyle\int \sqrt{1 + x^2}\,x^5\,dx = \frac17\left(1 + x^2\right)^{7/2} - \frac25\left(1 + x^2\right)^{5/2} + \frac13\left(1 + x^2\right)^{3/2} + C\).

Check

Differentiating gives \(x(1+x^2)^{1/2}\big[(1+x^2)^2 - 2(1+x^2) + 1\big] = x(1+x^2)^{1/2}\,x^4 = x^5\sqrt{1+x^2}\). ✔

Example 3.6 A definite integral with new limits

Evaluate \(\displaystyle\int_0^4 \sqrt{2x + 1}\,dx\).

(Instr. Vitalez's notes, Activity #4, item 4 (compare Stewart §4.5, Example 6))
Show solution (try it first)
Given
  • \(\int_0^4 \sqrt{2x + 1}\,dx\)
  • Find: its exact value
Step 1: choose u as in Example 3

\[u = 2x + 1, \qquad du = 2\,dx \quad\Longrightarrow\quad dx = \frac12\,du\]

Step 2: change the limits to u-values

When \(x = 0\): \(u = 2(0) + 1 = 1\).

When \(x = 4\): \(u = 2(4) + 1 = 9\).

Step 3: substitute and integrate

\[\int_0^4 \sqrt{2x + 1}\,dx = \frac12\int_1^9 u^{1/2}\,du = \frac12\left[\frac23 u^{3/2}\right]_1^9 = \frac13\left[u^{3/2}\right]_1^9\]

Step 4: evaluate at the new limits

\[= \frac13\left(9^{3/2} - 1^{3/2}\right) = \frac13\,(27 - 1) = \frac{26}{3}\]

Answer

\(\displaystyle\int_0^4 \sqrt{2x + 1}\,dx = \frac{26}{3} \approx 8.667\).

Check

Using the antiderivative from Example 3 with the original limits: \(\tfrac13(9)^{3/2} - \tfrac13(1)^{3/2} = 9 - \tfrac13 = \tfrac{26}{3}\). Same answer. Also, \(\sqrt{2x+1}\) runs from 1 to 3 on an interval of length 4, so the value must lie between 4 and 12. ✔
