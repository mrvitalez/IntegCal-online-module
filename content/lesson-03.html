4.5The Substitution Rule: Indefinite Integrals

Now that we have an idea of how to get the area through integration, let's dive into our first real strategy for solving integrals: the Substitution Rule. Our table of integrals from Module 2 handles \(\int x^5\,dx\) or \(\int \cos x\,dx\) easily. But what about \[\int 2x\sqrt{1 + x^2}\,dx\ ?\] This is a little more complicated than anything in our table. So, what do we do here? Notice that the derivative of the inside, \(1 + x^2\), is \(2x\), and \(2x\) is sitting right there in front. That is the clue.

Where it comes from. Recall the Chain Rule: \(\frac{d}{dx} F\big(g(x)\big) = F'\big(g(x)\big)\,g'(x)\). Reading it backwards as an integral, \[\int F'\big(g(x)\big)\,g'(x)\,dx = F\big(g(x)\big) + C.\] If we let \(u = g(x)\), then \(du = g'(x)\,dx\), and the left side becomes simply \(\int F'(u)\,du\). So the Substitution Rule is the Chain Rule in reverse.

The Substitution Rule If \(u = g(x)\) is a differentiable function whose range is an interval and \(f\) is continuous on that interval, then \[\int f\big(g(x)\big)\,g'(x)\,dx = \int f(u)\,du.\]

The procedure.

  1. Choose \(u\): usually the "inside" function, the one whose derivative (up to a constant) also appears.
  2. Compute \(du\): differentiate, \(du = g'(x)\,dx\). If the integrand has only a constant multiple of \(g'(x)\,dx\), solve for it, for example \(x\,dx = \tfrac12\,du\).
  3. Rewrite everything in \(u\): no \(x\) may remain. If a stray \(x\) is left, solve \(u = g(x)\) for \(x\) and substitute that too.
  4. Integrate in \(u\) with the table.
  5. Substitute back \(u = g(x)\), and add \(+C\).

And as always, we can double check our answer by differentiating it with the Chain Rule. If we get the integrand back, we are correct.

Some patterns appear again and again: \(\int \cos(kx)\,dx = \frac1k\sin(kx) + C\), \(\int e^{kx}\,dx = \frac1k e^{kx} + C\), \(\int \frac{g'(x)}{g(x)}\,dx = \ln|g(x)| + C\). Each of these is a substitution with \(u = kx\) or \(u = g(x)\).

Common mistake Leaving an \(x\) or a \(dx\) inside a \(u\)-integral, such as \(\int u\,x\,dx\). Once you substitute, every part of the integrand, including \(dx\), must be written in terms of \(u\) and \(du\). You also cannot pull a variable out like a constant: \(\int x\cos(x^2)\,dx \ne x\int\cos(x^2)\,dx\).
Key equations
\[ \int f\big(g(x)\big)\,g'(x)\,dx = \int f(u)\,du, \qquad u = g(x),\ du = g'(x)\,dx \]
\[ \int \cos(kx)\,dx = \frac1k\sin(kx) + C, \qquad \int e^{kx}\,dx = \frac1k e^{kx} + C \]

4.5Substitution in Definite Integrals and Symmetry

For a definite integral that needs substitution, we have two choices. We can find the indefinite integral first, substitute back to \(x\), and then use the original limits. Or, which is usually faster, we can change the limits to \(u\)-values and never go back to \(x\).

Substitution Rule for definite integrals If \(g'\) is continuous on \([a, b]\) and \(f\) is continuous on the range of \(u = g(x)\), then \[\int_a^b f\big(g(x)\big)\,g'(x)\,dx = \int_{g(a)}^{g(b)} f(u)\,du.\]

Notice that the new limits are found by putting the old limits into \(u = g(x)\). For example, in \(\int_0^4 \sqrt{2x+1}\,dx\) with \(u = 2x + 1\), the lower limit \(x = 0\) becomes \(u = 1\) and the upper limit \(x = 4\) becomes \(u = 9\).

Symmetry. Suppose \(f\) is continuous on \([-a, a]\).

  • If \(f\) is even (\(f(-x) = f(x)\), symmetric about the \(y\)-axis), the left half has the same area as the right half: \(\int_{-a}^{a} f(x)\,dx = 2\int_0^a f(x)\,dx\).
  • If \(f\) is odd (\(f(-x) = -f(x)\), symmetric about the origin), the left half cancels the right half: \(\int_{-a}^{a} f(x)\,dx = 0\).

This is very useful in physics: the net effect of an odd quantity over a symmetric interval is zero. And it can save us from integrals we could not even do, like \(\int_{-1}^{1} \frac{\tan x}{1 + x^2 + x^4}\,dx\). Is the integrand odd? Replace \(x\) by \(-x\): the numerator changes sign and the denominator does not, so yes, and the integral is 0.

Common mistake Changing to \(u\) but keeping the old \(x\)-limits, as in \(\int_0^4 u^{1/2}\,du\) when \(u = 2x + 1\). Either change the limits, or substitute back to \(x\) before using the original limits. Never mix the two.
Key equations
\[ \int_a^b f\big(g(x)\big)\,g'(x)\,dx = \int_{g(a)}^{g(b)} f(u)\,du \]
\[ f \text{ even: } \int_{-a}^{a} f(x)\,dx = 2\int_0^a f(x)\,dx, \qquad f \text{ odd: } \int_{-a}^{a} f(x)\,dx = 0 \]

★Key takeaways

  • The Substitution Rule is the Chain Rule in reverse: look for a function together with its derivative.
  • Choose u as the inside function, find du, and rewrite the whole integral, including dx, in terms of u.
  • If an extra x is left over, solve u = g(x) for x and substitute it as well.
  • Always check an indefinite integral by differentiating the answer with the Chain Rule.
  • For definite integrals, change the limits to u = g(a) and u = g(b) and never return to x.
  • Over [−a, a], an even function gives twice the integral over [0, a] and an odd function gives 0.

Example 3.1 A first substitution

Find \(\displaystyle\int 2x\sqrt{1 + x^2}\,dx\).

(From the instructor's module)
Show solution (try it first)

Given: the integrand \(2x\sqrt{1+x^2}\). Find: the indefinite integral.

Plan: The derivative of the inside function \(1 + x^2\) is \(2x\), which is already in the integrand. So we let \(u = 1 + x^2\).

Step 1. Choose \(u\) and compute \(du\).

\[u = 1 + x^2, \qquad du = 2x\,dx\]

Step 2. Substitute: \(\sqrt{1+x^2}\) becomes \(\sqrt u\) and \(2x\,dx\) becomes \(du\).

\[\int 2x\sqrt{1+x^2}\,dx = \int \sqrt{u}\,du = \int u^{1/2}\,du\]

Step 3. Integrate with the power rule: \(\frac12 + 1 = \frac32\).

\[= \frac{u^{3/2}}{3/2} + C = \frac23 u^{3/2} + C\]

Step 4. Substitute back \(u = 1 + x^2\).

\[= \frac23\left(1 + x^2\right)^{3/2} + C\]

Answer: \(\boxed{\dfrac23\left(1 + x^2\right)^{3/2} + C}\). That is our answer.

Check: We can double check using the Chain Rule: \(\frac{d}{dx}\left[\frac23(1+x^2)^{3/2}\right] = \frac23\cdot\frac32(1+x^2)^{1/2}\cdot 2x = 2x\sqrt{1+x^2}\), which is the integrand.

Example 3.2 When the derivative is off by a constant

Find (a) \(\displaystyle\int x^3\cos(x^4 + 2)\,dx\) and (b) \(\displaystyle\int \sqrt{2x + 1}\,dx\).

(From the instructor's module)
Show solution (try it first)

Given: two integrands whose inside derivative is present only up to a constant factor. Find: both indefinite integrals.

Plan: Let \(u\) be the inside function. Its derivative appears up to a constant, so solve \(du\) for the piece we have.

Step 1. (a) Let \(u = x^4 + 2\). Then \(du = 4x^3\,dx\), but we only have \(x^3\,dx\), so divide by 4.

\[x^3\,dx = \tfrac14\,du\]

Step 2. Substitute and integrate (\(\int\cos u\,du = \sin u\)).

\[\int x^3\cos(x^4+2)\,dx = \int \cos u\cdot\tfrac14\,du = \tfrac14\sin u + C\]

Step 3. Substitute back.

\[= \tfrac14\sin(x^4 + 2) + C\]

Step 4. (b) Let \(u = 2x + 1\). Then \(du = 2\,dx\), so \(dx = \tfrac12\,du\).

\[\int \sqrt{2x+1}\,dx = \int u^{1/2}\cdot\tfrac12\,du = \tfrac12\cdot\frac{u^{3/2}}{3/2} + C = \tfrac13 u^{3/2} + C\]

Step 5. Substitute back.

\[= \tfrac13(2x+1)^{3/2} + C\]

Answer: (a) \(\boxed{\tfrac14\sin(x^4 + 2) + C}\) (b) \(\boxed{\tfrac13(2x+1)^{3/2} + C}\).

Check: (a) \(\frac{d}{dx}\left[\tfrac14\sin(x^4+2)\right] = \tfrac14\cos(x^4+2)\cdot 4x^3 = x^3\cos(x^4+2)\). (b) \(\frac{d}{dx}\left[\tfrac13(2x+1)^{3/2}\right] = \tfrac13\cdot\tfrac32(2x+1)^{1/2}\cdot 2 = \sqrt{2x+1}\).

Example 3.3 Two quick substitutions

Find (a) \(\displaystyle\int \frac{x}{\sqrt{1 - 4x^2}}\,dx\) and (b) \(\displaystyle\int \cos 5x\,dx\).

(From the instructor's module)
Show solution (try it first)

Given: two integrands. Find: both indefinite integrals.

Plan: (a) The inside of the root is \(1 - 4x^2\), whose derivative \(-8x\) is a constant times the \(x\) on top. (b) The inside is \(5x\).

Step 1. (a) Let \(u = 1 - 4x^2\), so \(du = -8x\,dx\) and \(x\,dx = -\tfrac18\,du\).

\[\int \frac{x\,dx}{\sqrt{1-4x^2}} = \int \frac{-\tfrac18\,du}{\sqrt u} = -\tfrac18\int u^{-1/2}\,du\]

Step 2. Power rule: \(-\tfrac12 + 1 = \tfrac12\).

\[= -\tfrac18\cdot\frac{u^{1/2}}{1/2} + C = -\tfrac14\sqrt{u} + C = -\tfrac14\sqrt{1 - 4x^2} + C\]

Step 3. (b) Let \(u = 5x\), so \(du = 5\,dx\) and \(dx = \tfrac15\,du\).

\[\int\cos 5x\,dx = \tfrac15\int\cos u\,du = \tfrac15\sin u + C = \tfrac15\sin 5x + C\]

Answer: (a) \(\boxed{-\tfrac14\sqrt{1 - 4x^2} + C}\) (b) \(\boxed{\tfrac15\sin 5x + C}\).

Check: (a) \(\frac{d}{dx}\left[-\tfrac14(1-4x^2)^{1/2}\right] = -\tfrac14\cdot\tfrac12(1-4x^2)^{-1/2}(-8x) = \frac{x}{\sqrt{1-4x^2}}\). (b) \(\frac{d}{dx}\tfrac15\sin 5x = \cos 5x\).

Example 3.4 A leftover x: solve the substitution for x

Find \(\displaystyle\int \sqrt{1 + x^2}\,x^5\,dx\).

(From the instructor's module)
Show solution (try it first)

Given: the integrand \(x^5\sqrt{1+x^2}\). Find: the indefinite integral.

Plan: Let \(u = 1 + x^2\), so \(du = 2x\,dx\). We use one \(x\) for \(du\); the remaining \(x^4\) must also be written in \(u\), using \(x^2 = u - 1\).

Step 1. Choose \(u\) and split \(x^5\,dx = x^4\cdot x\,dx\).

\[u = 1 + x^2, \quad du = 2x\,dx \;\Rightarrow\; x\,dx = \tfrac12\,du, \qquad x^4 = (x^2)^2 = (u-1)^2\]

Step 2. Substitute everything.

\[\int \sqrt{1+x^2}\,x^4\cdot x\,dx = \int \sqrt u\,(u-1)^2\cdot\tfrac12\,du = \tfrac12\int u^{1/2}(u^2 - 2u + 1)\,du\]

Step 3. Multiply out so we have plain powers of \(u\).

\[= \tfrac12\int\left(u^{5/2} - 2u^{3/2} + u^{1/2}\right)du\]

Step 4. Integrate each power.

\[= \tfrac12\left[\frac{u^{7/2}}{7/2} - 2\cdot\frac{u^{5/2}}{5/2} + \frac{u^{3/2}}{3/2}\right] + C = \tfrac17 u^{7/2} - \tfrac25 u^{5/2} + \tfrac13 u^{3/2} + C\]

Step 5. Substitute back \(u = 1 + x^2\).

\[= \tfrac17(1+x^2)^{7/2} - \tfrac25(1+x^2)^{5/2} + \tfrac13(1+x^2)^{3/2} + C\]

Answer: \(\boxed{\tfrac17(1+x^2)^{7/2} - \tfrac25(1+x^2)^{5/2} + \tfrac13(1+x^2)^{3/2} + C}\).

Check: Differentiating gives \((1+x^2)^{1/2}\,x\left[(1+x^2)^2 - 2(1+x^2) + 1\right] = x\sqrt{1+x^2}\,(x^2)^2 = x^5\sqrt{1+x^2}\), the integrand. (Inside the bracket, \((u-1)^2 = x^4\).)

Example 3.5 A definite integral: change the limits

Evaluate \(\displaystyle\int_0^4 \sqrt{2x + 1}\,dx\).

(From the instructor's module)
Show solution (try it first)

Given: the integrand \(\sqrt{2x+1}\) on \([0, 4]\). Find: the definite integral.

Plan: Use \(u = 2x + 1\) as in Example 3.2(b), and change the limits to \(u\)-values so we never need to go back to \(x\).

Step 1. Substitution and differential.

\[u = 2x + 1, \qquad du = 2\,dx \;\Rightarrow\; dx = \tfrac12\,du\]

Step 2. Change the limits by putting \(x = 0\) and \(x = 4\) into \(u = 2x + 1\).

\[x = 0 \Rightarrow u = 1, \qquad x = 4 \Rightarrow u = 9\]

Step 3. Rewrite the integral entirely in \(u\), new limits included.

\[\int_0^4\sqrt{2x+1}\,dx = \int_1^9 u^{1/2}\cdot\tfrac12\,du = \tfrac12\left[\frac{u^{3/2}}{3/2}\right]_1^9 = \tfrac13\Big[u^{3/2}\Big]_1^9\]

Step 4. Evaluate: \(9^{3/2} = (\sqrt9)^3 = 27\) and \(1^{3/2} = 1\).

\[= \tfrac13(27 - 1) = \frac{26}{3}\]

Answer: \(\boxed{\dfrac{26}{3} \approx 8.67}\).

Check: Using the antiderivative from Example 3.2(b) with the original limits: \(\tfrac13(9)^{3/2} - \tfrac13(1)^{3/2} = 9 - \tfrac13 = \tfrac{26}{3}\). Same answer. Also, the integrand goes from 1 to 3 on an interval of length 4, so the answer must be between 4 and 12.

Example 3.6 Symmetry

Evaluate (a) \(\displaystyle\int_{-2}^{2} (x^6 + 1)\,dx\) and (b) \(\displaystyle\int_{-1}^{1} \frac{\tan x}{1 + x^2 + x^4}\,dx\).

(Similar to Stewart §4.5, Examples 10 and 11)
Show solution (try it first)

Given: two integrals over symmetric intervals. Find: their values.

Plan: Test each integrand for symmetry by replacing \(x\) with \(-x\), then use the even or odd rule.

Step 1. (a) Test: \((-x)^6 + 1 = x^6 + 1\). The integrand is even, so we double the integral over \([0, 2]\).

\[\int_{-2}^{2}(x^6+1)\,dx = 2\int_0^2 (x^6+1)\,dx = 2\left[\frac{x^7}{7} + x\right]_0^2\]

Step 2. Evaluate.

\[= 2\left(\frac{128}{7} + 2\right) = 2\cdot\frac{142}{7} = \frac{284}{7}\]

Step 3. (b) Test: \(\tan(-x) = -\tan x\), while \(1 + (-x)^2 + (-x)^4 = 1 + x^2 + x^4\). So \(f(-x) = -f(x)\): the integrand is odd, and the interval \([-1, 1]\) is symmetric.

\[\int_{-1}^{1}\frac{\tan x}{1 + x^2 + x^4}\,dx = 0\]

Answer: (a) \(\boxed{\dfrac{284}{7} \approx 40.57}\) (b) \(\boxed{0}\).

Check: (a) Without symmetry: \(\left[\frac{x^7}{7} + x\right]_{-2}^{2} = \left(\frac{128}{7} + 2\right) - \left(-\frac{128}{7} - 2\right) = \frac{284}{7}\). (b) We could not have found an antiderivative here; symmetry did all the work.
