4.3The Fundamental Theorem of Calculus

Recall Example 6 of Module 1. To get \(\int_0^3 (x^3 - 6x)\,dx = -6.75\) from the definition, we needed \(\Delta x\), the right endpoints, two summation formulas and a limit. Is there a shorter way? Yes. This long solution can be done in two lines with the Fundamental Theorem of Calculus (FTC), Stewart §4.3.

The power rule. Let's start with the most common integral, \(\int x^n\,dx\). We are looking for a function whose derivative is \(x^n\). Since \(\frac{d}{dx}\,x^{n+1} = (n+1)x^n\), we add one to the power and divide by the new power: \[\int x^n\,dx = \frac{x^{n+1}}{n+1} + C \qquad (n \ne -1).\] The \(+C\) is there because adding a constant does not change the derivative.

Putting in the limits. Now, if there is an interval, say from \(a\) to \(b\), we write the antiderivative in brackets and substitute: the value at \(b\) minus the value at \(a\). \[\int_a^b x^n\,dx = \left[\frac{x^{n+1}}{n+1}\right]_a^b = \frac{b^{n+1}}{n+1} - \frac{a^{n+1}}{n+1}.\] If we take Module 1's example: \(\int_0^3 (x^3 - 6x)\,dx = \left[\tfrac{x^4}{4} - 3x^2\right]_0^3 = \tfrac{81}{4} - 27 = -6.75\). Same answer, far less work. (Example 1 shows every step.)

FTC, Part 2 If \(f\) is continuous on \([a,b]\) and \(F\) is any antiderivative of \(f\) (that is, \(F' = f\)), then \[\int_a^b f(x)\,dx = F(b) - F(a) = \big[F(x)\big]_a^b.\]

Take note that any antiderivative works, because the constant \(C\) cancels in \(F(b) - F(a)\). For instance, \(\int_0^{\pi} \sin x\,dx = \big[-\cos x\big]_0^{\pi} = 1 - (-1) = 2\): one arch of the sine curve has area exactly 2.

Why does this work? Let's look at the area function \(g(x) = \int_a^x f(t)\,dt\), the area under \(f\) from \(a\) up to a moving right end \(x\) (Figure 2.1). If we push \(x\) a tiny step \(h\) to the right, we add a thin strip of width \(h\) and height about \(f(x)\), so \(g(x+h) - g(x) \approx f(x)\,h\). Dividing by \(h\) and letting \(h \to 0\) gives \(g'(x) = f(x)\).

FTC, Part 1 If \(f\) is continuous on \([a,b]\), then \(g(x) = \int_a^x f(t)\,dt\) is continuous on \([a,b]\), differentiable on \((a,b)\), and \[\frac{d}{dx}\int_a^x f(t)\,dt = f(x).\]

So \(\frac{d}{dx}\int_2^x \sqrt{1 + t^4}\,dt = \sqrt{1 + x^4}\): we just replace \(t\) by \(x\). If the upper limit is a function \(h(x)\), the Chain Rule adds a factor: \(\frac{d}{dx}\int_a^{h(x)} f(t)\,dt = f\big(h(x)\big)\,h'(x)\). If \(x\) is in the lower limit, flip the limits first: \(\int_x^a f(t)\,dt = -\int_a^x f(t)\,dt\).

Put together: integrate and then differentiate, and we get \(f\) back (Part 1); differentiate and then integrate, and we get the change \(F(b) - F(a)\) (Part 2). Differentiation and integration are inverse processes.

Common mistake FTC2 needs \(f\) to be continuous on all of \([a,b]\). Writing \(\int_{-1}^{1} x^{-2}\,dx = \big[-x^{-1}\big]_{-1}^{1} = -2\) gives a negative answer for a positive integrand. Do you know why? The function blows up at 0, so the theorem does not apply.
Key equations
\[ \frac{d}{dx}\int_a^x f(t)\,dt = f(x) \]
\[ \frac{d}{dx}\int_a^{h(x)} f(t)\,dt = f\big(h(x)\big)\,h'(x) \]
\[ \int_a^b f(x)\,dx = F(b) - F(a), \quad F' = f \]

4.4Indefinite Integrals and the Net Change Theorem

Since FTC2 turns every definite integral into "find an antiderivative", we need a good notation and a table (Stewart §4.4). The indefinite integral \[\int f(x)\,dx = F(x) + C \quad\text{means}\quad F'(x) = f(x).\] Take note of the difference: a definite integral \(\int_a^b f(x)\,dx\) is a number, while an indefinite integral \(\int f(x)\,dx\) is a family of functions, one for each value of \(C\).

A short table. We can check each line by differentiating the right side.

IntegralResult
\(\int c f(x)\,dx\)\(c\int f(x)\,dx\)
\(\int [f(x) + g(x)]\,dx\)\(\int f(x)\,dx + \int g(x)\,dx\)
\(\int k\,dx\)\(kx + C\)
\(\int x^n\,dx\) \((n \ne -1)\)\(\dfrac{x^{n+1}}{n+1} + C\)
\(\int \sin x\,dx\)\(-\cos x + C\)
\(\int \cos x\,dx\)\(\sin x + C\)
\(\int \sec^2 x\,dx\)\(\tan x + C\)
\(\int \csc^2 x\,dx\)\(-\cot x + C\)
\(\int \sec x\tan x\,dx\)\(\sec x + C\)
\(\int \csc x\cot x\,dx\)\(-\csc x + C\)

So, what do we do with roots and quotients? We rewrite them as powers first: \(\int \frac{x + 2}{\sqrt{x}}\,dx = \int (x^{1/2} + 2x^{-1/2})\,dx = \tfrac23 x^{3/2} + 4x^{1/2} + C\). There is no "quotient rule" for integrals. Trig identities do the same job: \(\frac{\sin x}{\cos^2 x} = \sec x\tan x\), so \(\int \frac{\sin x}{\cos^2 x}\,dx = \sec x + C\). Always finish by differentiating your answer. If you get the integrand back, you are right.

Common mistake The integral of a product is not the product of the integrals: \(\int x\cdot x\,dx = \tfrac{x^3}{3} + C\), not \(\tfrac{x^2}{2}\cdot\tfrac{x^2}{2}\). Multiply out first.

The Net Change Theorem. What does FTC2 say when the integrand is a rate of change \(F'\)? \[\int_a^b F'(x)\,dx = F(b) - F(a).\] The integral of a rate of change is the net change. If \(V'(t)\) is the rate (L/min) at which water enters a tank, \(\int_{t_1}^{t_2} V'(t)\,dt\) is the change in volume. If \(C'(x)\) is the marginal cost, \(\int_{100}^{200} C'(x)\,dx\) is the extra cost of raising production from 100 to 200 units. Notice the units: (units of the rate) × (units of the variable), for example (L/min) × min = L.

Displacement versus distance. For a particle with velocity \(v(t)\):

  • displacement \(= \int_{t_1}^{t_2} v(t)\,dt\) (the net change in position; moving backward cancels moving forward);
  • total distance \(= \int_{t_1}^{t_2} |v(t)|\,dt\). To compute it, we find where \(v(t) = 0\), split the interval there, and add the pieces as positive numbers.

For \(v(t) = t^2 - 4t + 3 = (t-1)(t-3)\) on \([0,4]\), the three pieces are \(\tfrac43, -\tfrac43, \tfrac43\). The displacement is \(\tfrac43\), but the distance is \(4\) (Figure 2.3).

Key equations
\[ \int f(x)\,dx = F(x) + C \iff F'(x) = f(x) \]
\[ \int x^n\,dx = \frac{x^{n+1}}{n+1} + C \quad (n \ne -1) \]
\[ \int_a^b F'(x)\,dx = F(b) - F(a) \]
\[ \text{distance} = \int_{t_1}^{t_2} |v(t)|\,dt \]

★Key takeaways

  • Power rule: add one to the power and divide by the new power, ∫xⁿ dx = xⁿ⁺¹/(n + 1) + C for n ≠ −1.
  • FTC Part 2: if F′ = f and f is continuous on [a, b], then ∫ₐᵇ f(x) dx = F(b) − F(a); for example ∫₀³ (x³ − 6x) dx = 81/4 − 27 = −6.75.
  • FTC Part 1: the derivative of an area function is the integrand, d/dx ∫ₐˣ f(t) dt = f(x); with a variable limit h(x), multiply by h′(x).
  • An indefinite integral is a family of antiderivatives F(x) + C; a definite integral is a single number.
  • Rewrite roots and quotients as powers before integrating, and check every antiderivative by differentiating.
  • The integral of a rate of change is the net change; for velocity, ∫v dt is displacement and ∫|v| dt is total distance.

Example 2.1 Module 1's integral in two lines

Use the Fundamental Theorem of Calculus to evaluate \(\displaystyle\int_0^3 (x^3 - 6x)\,dx\).

(Instr. Vitalez's notes, Example #4(b) by the FTC (compare Stewart §4.3))
Show solution (try it first)
Given
  • \(\int_0^3 (x^3 - 6x)\,dx\)
  • Find: its exact value using antiderivatives
Step 1: split the integral into two simpler ones

The integral of a difference is the difference of the integrals.

\[\int_0^3 (x^3 - 6x)\,dx = \int_0^3 x^3\,dx - \int_0^3 6x\,dx\]

Step 2: find the antiderivatives with the power rule

Add one to the power and divide by the new power.

\[= \left[\frac{x^4}{4}\right]_0^3 - \left[6\cdot\frac{x^2}{2}\right]_0^3 = \left[\frac{x^4}{4}\right]_0^3 - \left[3x^2\right]_0^3\]

Step 3: substitute the upper limit minus the lower limit

\[= \frac{(3)^4 - (0)^4}{4} - 3\left[(3)^2 - (0)^2\right] = \frac{81}{4} - 27\]

Step 4: simplify

\[= \frac{81}{4} - \frac{108}{4} = -\frac{27}{4} = -6.75\]

Answer

\(\displaystyle\int_0^3 (x^3 - 6x)\,dx = -\frac{27}{4} = -6.75\).

Check

This is exactly the value we got from the limit of Riemann sums in Module 1, Example 6, but without any summation formulas.

Example 2.2 Indefinite integrals with the power rule

Evaluate: (a) \(\displaystyle\int x^3\,dx\)   (b) \(\displaystyle\int t^5\,dt\)   (c) \(\displaystyle\int \frac16 g^2\,dg\).

(Instr. Vitalez's notes, Activity #3, items 1 to 3 (compare Stewart §4.4))
Show solution (try it first)
Given
  • Three indefinite integrals of powers (the variables are \(x\), \(t\), \(g\))
  • Find: the general antiderivative of each
Step 1: recall the power rule

\[\int x^n\,dx = \frac{x^{n+1}}{n+1} + C \qquad (n \ne -1)\]

The letter of the variable does not matter; it works the same for \(t\) and \(g\).

Step 2: apply it to (a) with n = 3

\[\int x^3\,dx = \frac{x^{3+1}}{3+1} + C = \frac{x^4}{4} + C\]

Step 3: apply it to (b) with n = 5

\[\int t^5\,dt = \frac{t^{5+1}}{5+1} + C = \frac{t^6}{6} + C\]

Step 4: take the constant out in (c), then use n = 2

\[\int \frac16 g^2\,dg = \frac16\int g^2\,dg = \frac16\cdot\frac{g^3}{3} + C = \frac{g^3}{18} + C\]

Answer

(a) \(\dfrac{x^4}{4} + C\)   (b) \(\dfrac{t^6}{6} + C\)   (c) \(\dfrac{g^3}{18} + C\).

Check

Differentiate each answer: \(\tfrac{4x^3}{4} = x^3\), \(\tfrac{6t^5}{6} = t^5\), \(\tfrac{3g^2}{18} = \tfrac16 g^2\). We get the integrands back.

Example 2.3 Definite integrals of polynomials

Evaluate: (a) \(\displaystyle\int_0^2 y^3\,dy\)   (b) \(\displaystyle\int_1^6 \left(s^2 + 4s^3\right)ds\).

(Instr. Vitalez's notes, Activity #3, items 4 and 5 (compare Stewart §4.3))
Show solution (try it first)
Given
  • (a) \(f(y) = y^3\) on \([0, 2]\)
  • (b) \(f(s) = s^2 + 4s^3\) on \([1, 6]\)
  • Find: the value of each integral
Step 1: find an antiderivative for (a) and substitute the limits

\[\int_0^2 y^3\,dy = \left[\frac{y^4}{4}\right]_0^2 = \frac{(2)^4}{4} - \frac{(0)^4}{4} = \frac{16}{4} - 0 = 4\]

Step 2: find an antiderivative for (b), term by term

\[\int \left(s^2 + 4s^3\right)ds = \frac{s^3}{3} + 4\cdot\frac{s^4}{4} = \frac{s^3}{3} + s^4\]

So we let \(F(s) = \dfrac{s^3}{3} + s^4\).

Step 3: evaluate F at the upper and lower limits

\[F(6) = \frac{216}{3} + 1296 = 72 + 1296 = 1368\]

\[F(1) = \frac13 + 1 = \frac43\]

Step 4: subtract

\[\int_1^6 \left(s^2 + 4s^3\right)ds = F(6) - F(1) = 1368 - \frac43 = \frac{4104}{3} - \frac{4}{3} = \frac{4100}{3}\]

Answer

(a) \(\displaystyle\int_0^2 y^3\,dy = 4\). (b) \(\displaystyle\int_1^6 \left(s^2 + 4s^3\right)ds = \frac{4100}{3} \approx 1366.667\).

Check

Both integrands are positive on their intervals, so both answers should be positive, and they are. For (b), \(4s^3\) alone goes up to 864 at \(s = 6\) over an interval of length 5, so a value in the thousands is reasonable.

Example 2.4 Derivatives of integrals with variable limits

Find the derivative: (a) \(\displaystyle y = \int_1^{x^3} \sqrt{1 + t^2}\,dt\)   (b) \(\displaystyle y = \int_x^{2} \cos(t^2)\,dt\).

(Similar to Stewart §4.3, Examples 3 and 4)
Show solution (try it first)
Given
  • (a) upper limit \(x^3\), integrand \(\sqrt{1+t^2}\)
  • (b) lower limit \(x\), integrand \(\cos(t^2)\)
  • Find: \(dy/dx\) in each case (FTC Part 1)
Step 1: in (a), name the upper limit u

The upper limit is not just \(x\), so let \(u = x^3\). Then \(\dfrac{du}{dx} = 3x^2\) and

\[y = \int_1^{u} \sqrt{1 + t^2}\,dt.\]

Step 2: use FTC1 with the Chain Rule

\[\frac{dy}{dx} = \frac{d}{du}\left[\int_1^{u} \sqrt{1+t^2}\,dt\right]\cdot\frac{du}{dx} = \sqrt{1 + u^2}\cdot 3x^2\]

Substitute \(u = x^3\) back:

\[= 3x^2\sqrt{1 + (x^3)^2} = 3x^2\sqrt{1 + x^6}\]

Step 3: in (b), flip the limits so x is on top

\[y = \int_x^{2} \cos(t^2)\,dt = -\int_2^{x} \cos(t^2)\,dt\]

Step 4: use FTC1

\[\frac{dy}{dx} = -\cos(x^2)\]

Answer

(a) \(\dfrac{dy}{dx} = 3x^2\sqrt{1 + x^6}\). (b) \(\dfrac{dy}{dx} = -\cos(x^2)\).

Check

A frequent error in (a) is to forget the factor \(3x^2\). In (b), think about the sign: as \(x\) increases, the interval \([x, 2]\) shrinks, so near \(x = 0\) (where \(\cos(t^2) \gt 0\)) \(y\) should decrease, and indeed \(y' = -\cos(x^2) \lt 0\) there.

Example 2.5 Displacement and total distance

A particle moves along a line with velocity \(v(t) = t^2 - 2t - 3\) m/s for \(0 \le t \le 5\). Find (a) its displacement and (b) the total distance it travels.

(Similar to Stewart §4.4, Example 6)
Show solution (try it first)
Given
  • \(v(t) = t^2 - 2t - 3\) m/s, \(0 \le t \le 5\) s
  • Find: displacement \(\int_0^5 v\,dt\) and distance \(\int_0^5 |v|\,dt\)
Step 1: find an antiderivative of v

\[F(t) = \frac{t^3}{3} - t^2 - 3t\]

Step 2: compute the displacement

\[\int_0^5 v(t)\,dt = F(5) - F(0) = \left(\frac{125}{3} - 25 - 15\right) - 0 = \frac{125}{3} - \frac{120}{3} = \frac53\]

Step 3: find where the particle changes direction

\[v(t) = t^2 - 2t - 3 = (t - 3)(t + 1) = 0 \implies t = 3 \quad (t = -1 \text{ is outside } [0,5])\]

\(v < 0\) on \([0, 3)\) (moving backward) and \(v > 0\) on \((3, 5]\) (moving forward).

Step 4: integrate each piece

\[\int_0^3 v\,dt = F(3) - F(0) = (9 - 9 - 9) - 0 = -9\]

\[\int_3^5 v\,dt = F(5) - F(3) = \frac53 - (-9) = \frac{32}{3}\]

Step 5: add the pieces as positive numbers

\[\text{distance} = |-9| + \frac{32}{3} = \frac{27}{3} + \frac{32}{3} = \frac{59}{3}\]

Answer

(a) The displacement is \(\tfrac53 \approx 1.67\) m. (b) The total distance is \(\tfrac{59}{3} \approx 19.7\) m.

Check

The two signed pieces add back to the displacement: \(-9 + \tfrac{32}{3} = \tfrac53\). The particle goes 9 m backward, then \(\tfrac{32}{3}\) m forward, ending \(\tfrac53\) m ahead of where it started.
